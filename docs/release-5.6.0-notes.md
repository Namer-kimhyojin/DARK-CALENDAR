# Air Calendar 5.6.0

- 달력·목록·오늘의 일정 어디서나 일정이 반투명한 일정 색과 왼쪽 색 막대로 같은 모양으로 보입니다.
- 중요도·상태를 선명한 벡터 아이콘으로 표시하고 모양을 직접 고를 수 있습니다. 완료된 항목은 흐리게 취소선으로, 기한이 지난 지시는 빨간 경고로 표시합니다.
- 시간표에서 여러 날 종일 일정을 하나의 막대로 보여 줍니다.
- 다이얼로그와 라이트·다크 테마를 정돈하고 대비를 높였으며, 바탕화면 고정과 트레이 아이콘을 개선했습니다.

대상: Windows x64, MSIX 5.6.0.0. 게시 상태는 배포 확인표에서 별도로 추적합니다.
