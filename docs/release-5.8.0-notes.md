# Air Calendar 5.8.0

5.7.0은 공개하지 않았으므로 그 내용도 이 버전에 함께 담았습니다.

- 위젯 전용 모드의 날짜 선택 창을 새로 만들었습니다. 제목을 누르면 월, 한 번 더 누르면 연도로 올라가서 어느 날짜든 세 번 안에 고릅니다. 툴바에 이전·다음 버튼도 생겼습니다.
- 위젯 창의 네 변과 네 모서리 어디서든 크기를 바꿀 수 있습니다. 모니터를 뺐다가 다시 꽂으면 원래 자리로 돌아오고, 더 보기 ▸ 창 관리에서 다른 모니터로 옮길 수 있습니다.
- 툴바·하단 버튼에 아이콘과 하는 일을 알려 주는 툴팁을 넣었습니다. 시계는 24/12시간, 초 표시, 크게/작게, 날짜 함께 표시를 고를 수 있습니다.
- 위젯의 투명도가 메인 창과 똑같이 맞춰집니다.
- 꾸미기의 '배치' 탭에서 배치와 그 옵션을 한곳에서 고르고, 카드에 마우스를 올려 미리 봅니다. 지금 설정을 '내 배치'로 저장하고, 위젯 창에서 Ctrl+1~9로 바로 바꿀 수 있습니다.
- 위젯 오른쪽 클릭 메뉴와 트레이 메뉴를 짧게 정리했고, 트레이에서 위젯 전용 모드를 바로 열 수 있습니다.
- (5.7.0 내용) 중요도·상태에 '미지정'과 라벨 색·아이콘(80종), 위젯 배치 4종·표면 4종 정리와 설정 자동 이관, 달력 표시·성능 개선.

대상: Windows x64, MSIX 5.8.0.0. 게시 상태는 배포 확인표에서 별도로 추적합니다.
