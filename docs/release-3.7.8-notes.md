# Air Calendar 3.7.8

**출시일:** 2026-10-01 · **채널:** Stable

위젯 전용 모드의 목록·주간 보기와 구성 편집을 개선한 Windows x64 릴리스입니다.

## 주요 변경 사항

- 목록 필터·완료 표시·상태 안내와 키보드 이동을 개선하고, 항목 갱신 시 선택과 스크롤 위치를 유지합니다.
- 주간 보기를 새 카드 디자인으로 정리하고, 주간·월간 달력과 날짜·시계 표시를 각 배치에 맞게 조절할 수 있습니다.
- 구성 요소를 자유롭게 이동·크기 조절하고 선택적으로 격자·요소에 맞출 수 있습니다. 여러 요소 선택, 정렬·간격 맞춤, 순서·잠금, 확대·화면 맞춤, 실행 취소·다시 실행을 지원합니다.
- 실제 위젯 렌더러로 현재 항목과 예시 일정을 미리 보면서 글꼴·크기·색상·투명도를 편집합니다. 적용하기 전까지 기존 위젯과 사용자 데이터는 유지합니다.
- 사용자 배치를 프리셋으로 저장·선택·수정·이름 변경·삭제하고, 구성 파일을 불러오거나 내보낼 수 있습니다. 꾸미기 화면의 ‘내 배치’에서도 관리할 수 있습니다.
- 신규 안내와 편집 문구를 19개 번들 언어에 반영했습니다.

## 호환성과 배포

기존 기본 배치 5종과 설정 저장 방식을 유지합니다. 프리셋은 구성 요소의 배치를 저장하며, 배치를 선택할 때 현재 모양 설정을 유지합니다. 꾸미기와 프리셋 관리의 변경은 적용할 때 저장하며, 취소하면 기존 설정을 유지합니다.

Store 제품 식별자 `Kimhyojin.DarkCalendar`, 게시자 표시 이름 `Kim,hyojin`, 실행 파일 `DarkCalendar.exe`, 시작 작업 `DarkCalendarStartup`은 기존 설치의 업데이트 호환성을 위해 유지합니다.

이 릴리스의 배포 대상은 x64입니다.

- `DarkCalendar-3.7.8-x64.msix`
- `DarkCalendar-3.7.8.0-x64.msixupload`
- `DarkCalendar-3.7.8-corresponding-source.zip`
- 각 배포 파일의 SHA-256 체크섬

라이선스는 `GPL-3.0-only`입니다. 전체 대응 소스에는 해당 버전의 앱 소스, 빌드 스크립트, 의존성 잠금 파일과 필요한 upstream 소스를 포함합니다. 기준 파일은 `requirements-runtime.lock`과 `requirements-build.lock`입니다.
