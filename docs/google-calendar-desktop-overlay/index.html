SETUP OUTLINE

Connect with your own Google credential.

Google requires a desktop OAuth client. The detailed home-page guide covers each screen.

01

Enable Google Calendar API

Create or choose a Google Cloud project, then enable Google Calendar API for that project.

02

Create a Desktop app OAuth client

Prepare the consent screen, add your Google account as a test user when required, and download the JSON credential for a Desktop app.

03

Authorize inside Air Calendar

Open Calendar & Sync settings, choose the JSON file, start authorization, and approve access in the browser.

04

Select calendars, test, and save

Choose the calendars to use, run the access test, and save only after the connection succeeds.

A Web application credential will not work.

Choose the Google OAuth client type “Desktop app.” Credentials and tokens stay on your PC; Air Calendar does not send them to a developer server.
