# Air Calendar 5.7.0

- 중요도·상태에 '미지정'을 고를 수 있고, 표시 라벨마다 색과 아이콘(80종)을 지정할 수 있습니다.
- 위젯 전용 모드를 단순하게 정리했습니다. 배치는 세로형·좌우형·보드형·목록형 4가지, 모양은 표면 4가지로 줄였고, 달력 형태·요약 줄·검색창은 배치마다 고릅니다. 기존 설정은 자동으로 옮겨집니다.
- 위젯 구성 편집기와 위젯 스타일 만들기는 없어졌습니다. 만들어 둔 내 배치는 계속 쓸 수 있습니다.
- 드래그 범위에서도 오늘 날짜가 잘 보이고, 편집 창을 취소할 때 화면을 다시 그리지 않아 더 빨라졌습니다.

대상: Windows x64, MSIX 5.7.0.0. 게시 상태는 배포 확인표에서 별도로 추적합니다.
