# Air Calendar 4.9.1 배포 확인표

**미공개 실패 후보.** CI 빌드는 성공했으나 실제 정상 종료 검증에서 접근 위반이 발생했다. 원본과 추가 진단을 보존했고, SIP 런타임 갱신과 Qt 문구 수정을 포함한 [4.9.2 새 후보](release-4.9.2-checklist.md)에서 계속 진행한다. [진단 기록](maintenance/native-shutdown-20261102.md)을 참고한다. 4.9.1 태그·파일은 바꾸지 않았으며 GitHub 공개·Store 제출은 하지 않았다.

사용자의 2026-11-02 통합 배포 요청으로, 4.8.0 공개 이후의 현재 개발 입력 전체를 포함한다. 기존 4.8.0은 GitHub·Store 게시와 공식 설치 업데이트가 확인되어 있으며 불변 패키지를 보존한다.
