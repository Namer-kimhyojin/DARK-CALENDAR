# Air Calendar 5.3.0

- KeyDeck가 터치에 바로 반응합니다. 손가락이 닿는 순간 소리가 나고, 키 사이 틈·가장자리·두 번째 손가락 입력도 받습니다. 덱이 보이는 동안 오디오 장치를 열어 두어 첫 타 지연이 사라졌습니다.
- 루프 믹서가 다른 작업 중에도 끊기지 않고, 녹음 시작 때 끊김을 없앴으며, 장치 오류가 나도 그때까지 녹음한 부분을 저장합니다. 녹음 위치를 출력 지연만큼 보정합니다.
- 프로세스형 체크리스트를 순서대로 완료하면 일정이 완료되고 반복 루틴은 다음 회차가 만들어집니다. 집중 모드에서 업무지시를 다시 선택할 수 있습니다.
- 창 표시/숨김 단축키(Ctrl+Alt+Shift+F1)가 창을 트레이로 숨긴 뒤에도 동작합니다. Esc로 명령 팔레트와 집중 모드 전체 화면을 닫을 수 있습니다.
- 외부 캘린더 동기화가 PC 시간대를 따릅니다. 빈 구독 피드는 확인 후에만 비우고, 다른 곳에서 수정된 일정의 삭제는 다시 가져오기·그래도 삭제 중에 고릅니다. 읽기 전용 캘린더의 일정은 앱에서 삭제하지 않습니다.
- 자리비움 잠금 비밀번호를 안전하게 저장하고 우회 경로를 막았습니다. 반복 루틴 날짜, 월간 보기 날짜 위치, 빠른 입력 해석, 절전 후 뽀모도로 기록을 바로잡았습니다.

빌드 대상: Windows x64 / MSIX 5.3.0.0. 빌드·검사·게시는 아직 진행하지 않았습니다.
