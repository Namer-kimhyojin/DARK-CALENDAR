QUICK START

Build a calmer desktop in three steps.

Start with only the information you need every day. Add more later.

01

Choose the calendar and panels you use

Start with the monthly calendar, then keep today’s schedule, weekly items, routines, or directives visible where they help.

02

Add only useful desktop widgets

Choose from clocks, stopwatch, date card, countdown, D-Day, text, and weather widgets. Multiple instances of the same type are supported.

03

Arrange the workspace around your screen

Move and resize widgets, tune colors, and keep the center of the desktop clear for the work that needs it.
