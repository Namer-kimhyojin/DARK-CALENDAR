## 화면 확인과 검증 한계

합성 연결 상태의 계정/가져오기 화면을 밝음·어두움 각각 **768×680 / 740×560**으로 캡처하고 확인했다. 복구 안내·왼쪽 탐색·가져오기 선택과 하단 저장/닫기가 보이며 작은 창에서는 본문을 스크롤한다. 실제 계정이나 설치판의 화면을 조작한 결과는 아니다.

첫 합성 화면은 글자 테마만 바꿔 배경과 맞지 않았으므로 배경색도 대응시켰다. 별도 크기 확인 시 980px 창을 가정한 2개 검사는 오프스크린 800px 화면에 맞춘 기존 768px 상한 때문에 실패했다. 이를 제품 오류로 처리하지 않고 지원되는 화면 범위로 검사 조건을 바로잡아 최종 4건을 통과시켰다. 초기 캡처·크기 실패 XML/로그는 증거 폴더에 보존했다.

모든 자동 검사는 임시 DB·INI 설정·앱 데이터/공유 DB·합성 토큰을 사용하고 외부 소켓을 차단했다. OAuth localhost callback만 합성 응답으로 검사했다. 실제 Google 로그인·원격 일정 쓰기·물리 DPI·스크린리더·설치판 사용자 데이터와 정상 재시작은 별도 미검증이다. 진행 중인 네트워크 요청의 즉시 중단을 보장한다는 결론도 내리지 않았다.
