# 2026-10-16 12일차 Google 동기화·인증·오프라인 점검

예정 시각은 03:00 KST, 실제 heartbeat는 09:07:47 KST에 도착했다. 실제 배타적 실행 잠금을 획득해 저장된 1~11일차 완료 기록을 보존하고 12일차부터 이어갔다. 검토 범위는 Google OAuth/재인증, 서비스 재시도·오프라인, pull/push/삭제·이동·충돌, 공통 상태와 사용자 문제 해결 흐름이다.

## Google 워커 시작 실패 복구(P2)

Google 동기화·인증·캘린더 목록 워커의 생성/신호 연결/시작 예외가 Qt 진입점 밖으로 전파되는 경로를 재현했다. 시작되지 않은 객체의 참조·목록 항목이 남거나 실패 진단을 저장하지 못해 사용자가 원인을 확인·재시도하기 어려웠다. 생성된 QThread는 원래 `finished`에서 정리하지만 시작되지 못하면 그 신호가 오지 않으므로 별도 정리가 필요했다.

시작 경계에 오류 처리를 추가했다. 실행되지 않은 객체는 해당 참조·목록에서 제거하고 지연 삭제한다. 이미 실행된 스레드는 소유 참조를 유지하고 협력 중단을 요청하며 강제 종료하거나 실행 중 객체를 삭제하지 않는다. 안전 코드 `operation_failed`를 기존 진단 경로에 기록한다. 자동 실행에서는 모달을 띄우지 않고, 수동 동기화에서는 기존 실패 안내를 재사용한다. 예외 원문·인증 정보를 기록하거나 표시하지 않는다.

동기화 자체가 시작되지 않았다면 이번 결과만 실패로 초기화해 과거 성공의 변경 플래그·통계가 섞이지 않게 한다. 반면 인증/목록 조회는 다른 동기화와 겹칠 수 있어 그 작업의 변경 플래그·통계·마지막 성공 시각을 보존한다. 새 앱 상태 변수·계정 초기화·DB 변경·권한 우회는 추가하지 않았다.

수정 전 새 동기화 시작 검사 15개 중 12개 실패·3개 통과, 인증/목록 시작 검사 8개는 모두 실패했다. 수정 후 23개 모두 통과했다. 자동·명시적 silent·수동 호출, 생성·연결·시작 실패, 재시도와 실행 중 참조 보존을 확인했다. 합성 토큰 파일의 바이트가 유지되는 것도 검사했다.

## 영역 검증과 보존 경계

기존 Google/공통 19개 검사 파일의 372개 사례가 이번 실행에서 통과했다. 이 결과를 바탕으로 수정 후 직접 영향을 받는 기존 6개 파일 105개와 신규 23개를 재검증했다. 서로 다른 기능 사례는 총 395개다. 변경하지 않은 OAuth·서비스·엔진의 267개 사례 결과는 이번 실행의 최초 통과 결과를 재사용했으며 수정 후 전체 395개를 다시 실행했다는 뜻은 아니다.

인증 loopback state·취소/시간 초과·후보 token 보존, 일시적 403/429와 영구 권한 오류의 구분, 제한된 Retry-After 재시도, 전체 페이지 실패 시 부분 반영 금지, 계정/캘린더 복합 identity, 명시적 이동·원격 충돌·부분 실패 표시와 기존 로컬 데이터 보존을 확인했다. 메타데이터/공개 버전 계약 5개·인코딩 12개·컴파일 가드·Ruff·diff 검사도 통과했다.

DB·QSettings·인증·공유 DB를 임시 경로로 격리한 실행기를 사용했고 실제 사용자 설정 보존을 확인했다. OAuth callback 검사는 합성 loopback으로 수행했으며 실제 Google 로그인·캘린더 쓰기·계정 설정 변경을 하지 않았다. 격리 Qt UI/콜백 검사는 설치된 Store 앱의 실제 계정 동기화 검증과 구분한다.
