## 2. KeyDeck 터치 반응 수정

하위 점검에서 측정한 원인과 이번 수정은 다음과 같다.

- **소리가 늦게 남:** 자동 스위치 소리는 화면 속 키 애니메이션이 바닥에 닿을 때(약 38ms 뒤) 재생됐다. 이제 손가락이 닿는 순간 주 효과음을 재생하고, 애니메이션은 같은 소리를 다시 내지 않는다.
- **입력이 무시됨:**
  - 덱이 뜬 직후 0.35초 안의 터치가 버려졌다. 이 지연은 이제 마우스에만 적용한다.
  - 키 사이 틈(6px)과 가장자리 바로 밖을 누르면 무시됐다. 이제 틈의 절반 + 8px 이내는 가장 가까운 키로 본다.
  - 매크로 키는 두 번째 손가락을 버렸다. 길게 누르기 동작이 없는 키는 손가락마다 따로 처리한다.
  - 손가락이 가장자리에서 조금만 미끄러져도 실행이 취소됐다. 같은 여유 범위를 적용했다.
- **오디오:**
  - 무작위 음량 때문에 소리 데이터를 매번 새로 계산했다. 음량을 반올림해 미리 계산한 값을 재사용한다.
  - 루프 믹서가 0.1초 넘게 늦은 키 소리를 버렸다. 이 기준을 0.25초로 늘렸다(절전 뒤 밀린 소리를 한꺼번에 재생하지 않는 동작은 유지).
- **테스트:** `tests/test_keydeck_multitouch.py`에 실패 재현 테스트 5건을 추가했다. `tests/test_keydeck_render.py`의 소리 시점 테스트는 새 동작에 맞게 바꿨다.

남은 KeyDeck 보완(실기 확인 필요):

1. 실제 터치 모니터에서 체감 확인. 오프스크린 테스트는 Qt 형태의 가짜 터치 이벤트만 검증했다.
2. 배포판 WinMM 경로에서 첫 타 지연(`waveOutOpen` 57–79ms, 패드별 첫 타 11–19ms)이 남아 있다. 지금은 "미리 불러오기 때 장치를 열지 않는다"는 테스트(`test_preload_reads_assets_without_opening_audio_device`)로 정한 설계다. 미리 여는 방식으로 바꿀지 결정해야 한다(M).
3. 탭 한 번에 60fps 다시 그리기가 1.75초 이어지며 오디오 스레드와 GIL을 다툰다. LED만 흐려지는 구간은 30fps로 낮추거나 시간을 줄인다(S).
4. 루프 믹서 경로는 20ms 블록·버퍼 3개·2ms 폴링(실제 약 10ms)으로 40–90ms가 더해진다. 블록 10ms·버퍼 2개·이벤트 기반 깨우기를 검토한다(M).
5. 이 터치 지원 코드(`canvas.py`, `tests/test_keydeck_multitouch.py`)는 4.9.2 배포판에 없고 작업 트리에만 있다. 배포에 포함돼야 사용자 기기에서 효과가 난다.

## 3. 보류했던 항목의 처리

- **pywin32:** 앱 코드는 더 이상 쓰지 않으므로 다음 빌드에는 묶이지 않는다. `scripts/native_release_smoke.py`와 `tests/release_qa/`의 배포 검사 도구는 계속 쓴다. 다음 배포 준비 때 `requirements.txt`·`requirements-runtime.lock`의 런타임 목록에서 검사 도구 목록으로 옮기고, 라이선스 고지·`release-compliance.json`에서 빼고, 빌드 결과에 없는지 확인한다.
- **process형 체크리스트:** 복구했다(5절).
- **집중 모드의 지시사항:** 목록에서 뺀 상태를 유지한다. 다시 넣으려면 종류(type)를 기록·조회·체크리스트까지 전달해야 한다.
- **사용하지 않는 번역 키:** 지웠다(5절 15번).
- **로케일 형식 테스트:** `en.json` 등 19개 파일의 GIF 키(`choices`/`choose`) 순서 때문에 실패한다. 다른 세션의 진행 중 작업이다.

## 4. 감사에서 읽지 않았던 영역의 추가 점검과 보완 계획

크기: S(반나절 이내), M(하루 안팎). 순서대로 진행한다.

### 선행

0. **`tests/conftest.py` 커밋(S):** 테스트를 임시 LOCALAPPDATA와 임시 QSettings로 격리하는 파일인데 아직 추적되지 않는다. 새 클론·워크트리에서는 테스트가 실제 사용자 DB와 레지스트리를 건드린다.

### 동작 오류

1. **외부 동기화 시간대 기본값이 Asia/Seoul(S):**
   - 위치: `outlook_sync_controller.py`, `caldav_sync_controller.py`, `calendar_sync_coordinator.py`(ICS), `calendar_sync_hub.py`.
   - 문제: 설정이 없으면 한국 시간으로 해석한다. 베를린 PC에서 09:00 회의가 17:00으로 저장된다.
   - 고칠 방법: 설정이 없으면 `QTimeZone.systemTimeZoneId()`를 쓰는 도우미 하나를 만들어 모든 호출부에서 쓴다.
   - 테스트: 설정 없음 + 베를린 시간대에서 각 워커가 받는 시간대 확인.
2. **전역 Esc 단축키가 Esc를 가로챔(S):**
   - 문제: 명령 팔레트가 Esc로 닫히지 않고, 집중 모드 전체 화면도 Esc로 풀리지 않는다.
   - 고칠 방법: 전역 Escape 등록을 빼고, 메인 창 `keyPressEvent`에서 집중 모드 처리 → 선택 해제 순서로 처리한다.
3. **메인 창이 숨으면 모든 단축키가 멈춤(S–M):**
   - 문제: F12(위젯 모드)와 Ctrl+F1(창 표시)로 창을 숨긴 뒤 같은 키로 되돌아오지 못한다.
   - 고칠 방법: 통합 위젯 창에도 두 키를 `WindowShortcut`으로 등록한다.
4. **달력 칸 클릭 한 번에 떠 있던 달력이 메인 창에 다시 붙음(S):**
   - 위치: `month_renderer.py` `_CalendarSurfaceFrame`.
   - 고칠 방법: 누른 위치를 저장하고, `startDragDistance` 이상 움직였을 때만 다시 붙인다.
5. **빈 ICS 피드가 미러 일정을 모두 지움(S):**
   - 고칠 방법: 받은 행이 0개인데 기존 행이 있으면 `empty_feed` 오류로 돌려보내고 삭제하지 않는다.
6. **Retry-After 하나로 동기화가 최대 24.8일 막힘(S):**
   - 문제: 수동 "지금 동기화"까지 막힌다.
   - 고칠 방법: `http_retry.MAX_RETRY_AFTER_SECONDS`를 3600으로 낮춘다.
7. **루프 믹서 자동 저장이 약 128회 녹음 뒤 영구 실패(S):**
   - 문제: 참조되지 않는 옛 WAV를 지우지 않는다.
   - 고칠 방법: 프로젝트 저장 뒤 참조되지 않는 digest WAV를 삭제한다.
8. **루프 덱 녹음이 앱 데이터 폴더 밖에 저장됨(S):**
   - 문제: `%LOCALAPPDATA%\DarkCalendar\loop-mixer`에 저장되어 백업·삭제 안내에서 빠진다.
   - 고칠 방법: `APP_DATA_DIR/loop-mixer`로 옮긴다. 아직 배포 전이라 이전 작업은 필요 없다.

### 결정이 필요한 항목

- **버전 이력 크기:** change 기록마다 전체 입력 해시(약 88KB)가 계속 쌓인다. 줄이려면 `scripts/manage_version.py`를 고치고, 5.0.0 후보 재검증 정책(`tests/release_qa/native-final-5.0.0.json`)의 도구 해시를 새 QA 커밋 기준으로 갱신해야 한다.

- **빈 ICS 피드:** 원본에서 실제로 모두 비운 캘린더도 미러가 남고 오류가 계속 보인다. "비어 있음 수락" 동작을 둘지, 일정 기간 뒤 비울지 정한다.
- **삭제 충돌 재시도:** `delete_conflict`(CalDAV는 `event_read_only` 포함) 행은 재시도해도 같은 etag로 계속 실패한다. 명시적 재시도 때 원격 변경을 무시하고 지울지, 재시도를 막을지 정한다.
- **KeyDeck 첫 타 지연:** 덱을 열 때 오디오 장치를 미리 열면 첫 타 57–79ms 지연이 사라지지만, 덱이 보이는 동안 장치를 잡고 있다.
- **루프 믹서 이벤트 기반 깨우기:** UI가 바쁠 때 재생률 46% → 100%(측정값). 장치 핸들 수명이 바뀌어 실제 기기 확인(분리·절전 포함)이 필요하다.
- **루프 믹서 녹음:** 재생 중 녹음을 시작하면 마이크를 열며 끊길 수 있다. 장치 오류 때 진행 중 녹음을 버린다. 녹음한 타격은 재생 지연만큼 늦게 기록된다.
- **Outlook(Graph) 종일 일정:** 일정의 시간대와 동기화 시간대가 다르면 하루 밀릴 수 있다. 실제 계정으로 Graph 응답 형식을 확인해야 한다.

- `ics/subscription_http.py`의 DNS 조회가 45초 제한·취소를 따르지 않는다.
