# 외국어 지원 점검·보완 — 2026-11-01

19개 번들 로케일(선택 가능한 18개 언어와 중국어 레거시 별칭)을 점검했다. 기본 4,496개 키에서
실제 코드가 호출하지만 어느 언어에도 없던 10개 키를 추가해 모든 번들이 4,506개 키를 갖는다.
구조가 일치해도 영어 대체 문구가 많았으므로, 구조 정상과 현지어 번역 완료를 구분한다.

이번 작업의 문자열 변경은 기존 값 15,418곳, 신규 키 190곳(10개 × 19파일)이다.

## 반영한 내용

- 위젯 관리 `widget_hub` 50개와 작업 공간 `widget_studio` 107개 문구를 모든 지원 언어에 보완했다.
  공용 단어인 `Animation`·`Auto`, 제품명·키 이름은 언어에 따라 같은 표기를 유지한다.
- 기본 버튼·이름·집중 통계·글꼴 목록·재시작 실패·자유 구성 등 누락 10개를 추가했다.
- 영어 잔존 문구에 확보한 번역 초안을 적용하고, 기존 현지어와 동일한 영어 원문의 번역을 재사용했다.
  `states`를 국가의 ‘주’로, `skin`을 신체의 ‘피부’로, `lock`을 자물쇠 사물로 옮긴 관리 화면 오역은 문맥에 맞게 별도 수정했다.
- 기존 템플릿 도움말 50곳의 서식 불일치를 수정했다. `{time:%H:%M}`, `{if ...}`, `|italic`, `|size=N` 등의 실행 문법은 그대로 보존한다.
- import 시 앱이 없어 누락되던 아랍어 RTL을 `QApplication` 생성 직후 적용한다.
  `zh-Hant-TW`·`zh_HK`·`pt_BR` 등의 별칭을 정규화하고 저장된 언어와 메뉴 선택 상태를 맞춘다.
- Qt 카탈로그와 공통 버튼 7종(확인·취소·저장·적용·닫기·예·아니오)을 적용한다.
  Qt가 번역 카탈로그를 제공하지 않는 언어에도 이 7종은 앱 번역을 사용한다.
- 월 이름과 텍스트 위젯의 요일·날짜 템플릿을 `QLocale().toString()`으로 표시한다. 명시적인 `weekday:en`은 기존 의미를 유지한다.
- 사용자 번역 우선순위를 유지한다. 누락·깨짐·키워드 형식화 오류는 같은 언어 번들, 영어, 코드 기본값 순서로 대체한다.
  레거시 별칭도 각 단계에서 해석한다. 사용자 파일은 덮어쓰지 않는다.
- 새 캘린더 선택의 기본 이름을 번역하되 `local::기본` 내부 ID와 기존 캘린더 이름은 유지한다.
- 화면 확인 중 발견한 밝은 테마의 스크롤 본문 배경을 의미 토큰에 연결했다. 작업 공간 카드의 크기를 고정하고 전체 이름 툴팁을 제공한다.

## 언어별 잔여 상태

아래 수치는 영어와 같은 값을 가진 **검토 후보**다. 공용 단어·기술 용어도 포함하므로 확정 미번역 수나 번역 완료율이 아니다.
이번 작업으로 전체 앱의 모든 문구가 현지어 번역 완료된 것은 아니다. 기존 영어 대체 문구가 특히 위젯 세부 디자인·이전 동기화 화면 등에 남아 있다.
대량 문구에는 자동 번역 초안이 포함되며, 전체 문구의 원어민 감수는 수행하지 않았다.
자동 번역 서비스의 요청 제한 이후 네트워크 작업을 중단하고, 확보한 결과·기존 번역 재사용·핵심 관리 화면의 별도 문구 보완을 적용했다.
새 문구의 변수·문법·깨짐과 핵심 UI 문맥은 검사했으며, 향후 잔여 번역을 이 표와 상세 JSON으로 이어서 검토할 수 있다.

## 재점검

```powershell
.venv/Scripts/python.exe scripts/audit_i18n.py --json artifacts/i18n-audit.json
.venv/Scripts/python.exe scripts/i18n_sync.py --base ko --limit 3
.venv/Scripts/python.exe scripts/validate_i18n_ui.py
.venv/Scripts/python.exe scripts/validate_i18n_ui.py --theme light --scale 2 --locales ar de fr hi ja zh-TW
```

`audit_i18n.py`는 파일을 수정하지 않는다. 영문 후보는 경고 자료이며 구조·문법 오류만 실패 종료한다.
소스 키 점검은 리터럴 `t()`/`_t()` 호출 범위이며, 동적 키·사용자 콘텐츠 전체를 자동 판정하는 검사는 아니다.
UI 캡처 도구는 사용자 상태를 바꾸지 않고 임시 설정과 빈 예시 구성으로 관리 컨트롤을 검토한다.
추가로 실제 예시 위젯을 넣은 아랍어·독일어·일본어 소스 화면도 `artifacts/widget-studio-20261101/screens/i18n-*`에 보관했다.

개발 소스에 반영했으며 제품 버전은 **4.8.0 유지**. 설치판·GitHub 릴리스·Store 제출·홈페이지는 이번 작업에서 교체하지 않았다.
