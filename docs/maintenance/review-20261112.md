# 2026-11-12 정기 점검 — DB·공유 DB·ICS

11/02~11/15 주기 11일차에 SQLite 이관, 백업·복원, 공유 DB, ICS 가져오기와 데이터 보존을 점검했다.

백업 복원 중 파일 이동이나 교체가 실패하면 이미 옮긴 원본 DB·WAL·SHM이 기존 경로에서 사라지는 경우를 재현했다. 이제 실패하면 옮긴 파일을 역순으로 제자리로 돌려보낸다. 운영체제가 되돌리기도 막으면 보존본을 남기고 해당 경로를 로그에 기록한다. 같은 시각의 복원 기록이 있으면 새 이름을 사용해 앞선 보존본을 유지한다.

격리 DB의 파일 이동·교체 실패와 동일 시각 보존본 충돌 3건을 수정 전 재현했고, 수정 후 통과했다. 앱 객체를 모의한 시작 오류 테스트의 실제 Qt 아이콘 로딩도 격리했다. 초기 합동 실행은 이 테스트에서 네이티브 종료됐으며, 수정 후 현재 개발용 프라이빗 SQLite 3.54.1에서 22개 파일 456건이 통과했다. 인코딩·Ruff·서식·diff 검사도 통과했다. 실제 사용자 DB와 외부 계정은 검증에 사용하지 않았다.

변경 ID는 `maintenance-20261112-db-restore-file-rollback`과 `maintenance-20261112-bootstrap-test-icon-isolation`이다. 개발 5.2.0의 변경 이력에 등록했으며 읽기 전용 검사에서 미등록 실행 입력은 0개다. 이번 수정은 11/16 통합 검증 후보다.
