# 2026-10-28 NLP·계산/정렬/갱신·성능 점검

10/19~11/01 주기의 **10일차**를 02:59 KST 정기 실행에서 시작했다. 앞선 1~9일차는
완료 증거가 있어 반복하지 않았다. 통합 배포 목표는 **11/02 03:00 KST**다.

## 자연어 입력의 날짜 일부 오인식 수정

`10/280 검토 회의`를 입력하면 `10/28`만 날짜로 소비해 제목이 `0 검토 회의`로 바뀌었다.
`111/2`, `1/234`, 한국어 긴 숫자 날짜와 지원하지 않는 연도 포함 표현에서도
날짜 일부를 잘라 제목과 날짜를 바꾸는 문제가 **6개 표현에서 재현**됐다.

월/일 인식에 숫자·날짜 구분자 경계를 적용해 잘못된 긴 표현은 제목에 그대로 남긴다.
기존 `10/28`, `10.28`, `10월28일`, `10월 28일`과 상대 날짜·한영 시각 인식은 보존했다.
연도 포함 날짜 인식 같은 신규 문법은 추가하지 않았다.

변경 ID: `maintenance-20261028-nlp-date-token-boundaries`.

## 오전 9시 미리보기와 자정 저장 불일치 수정

명령 팔레트에서 시각 없이 `+내일 검토 회의`를 입력하면 미리보기에는 `09:00 default`가
표시되지만, 전달 인자는 시각이 비어 있어 실제 DB에는 **00:00:00**으로 저장됐다.
미리보기 → 명령 실행 → 격리 DB 저장 경로에서 실패를 재현했다.

팔레트가 보여준 기본 시각 **09:00:00을 명시적으로 전달**하도록 수정했다.
직접 지정한 시각과 다른 호출 경로의 기존 기본값은 바꾸지 않았다.

변경 ID: `maintenance-20261028-nlp-preview-default-time`.

## 검증과 성능 확인

- 관련 **8개 테스트 파일 103건** 통과. 자연어 날짜/시각 경계·명령 팔레트 생성/실행·검색과 태그·
  날짜 범위·렌더링 서명·드래그/종료 중 갱신 보류·중복 갱신 억제를 확인했다.
  수정 후 NLP와 팔레트 파일을 다시 실행했으며 중복 실행은 합산하지 않았다.
- 추가 격리 검사 **14건** 통과. 밝은/어두운 팔레트의 정상/잘못된 날짜 **화면 4개**,
  취소 시 미저장, 위젯 빠른 입력, 중첩 다이얼로그 갱신 보류, 윤년·연말 주기 계산을 확인했다.
- 1,000회 패널 갱신 요청은 각 패널 1회와 데이터 소비자 1회 갱신으로 합쳐졌다.
  50,009자 숫자 입력은 약 **23ms**, 일반 입력 1,000회는 총 약 **32ms**에 처리됐다.
  이 수치는 이번 PC의 격리 개발 코드 진단값이며 설치 앱 응답 시간 보장은 아니다.
- 인코딩 가드 **12건**, 수정 파일 Ruff·diff·버전 일치 검사 통과. 미등록 실행 입력은 없다.

일반업무/지시사항의 우선순위·마감일·ID 정렬 키와 검색 결과의 순위/제목 결합을 코드로 검토했다.
전체 사용자 데이터의 정렬 화면이나 설치판 대량 데이터 성능을 확인한 것으로 표현하지 않는다.
격리된 어두운 팔레트의 기본 아이콘 색상은 실제 앱 테마와의 대비를 10/31 테마 영역에서 추가 확인한다.
