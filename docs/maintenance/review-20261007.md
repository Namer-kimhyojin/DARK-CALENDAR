## 수정과 검증

**Esc를 눌러도 지시사항 선택이 남는 오류(P2)**를 재현했다. 지시사항만 선택하거나 일정과 함께 선택한 경우 선택이 남아 후속 Delete 대상이 될 수 있었다. `TaskActionsMixin.clear_task_selection()`이 두 종류의 선택을 함께 비우고 표시를 갱신하도록 수정했다. 사용자 DB 변경이나 새 설정 항목은 없다.

실제 키 입력을 사용하는 신규 회귀 테스트는 수정 전 2개 실패·3개 통과, 수정 후 5개 통과했다. Esc 이후 Delete 무동작, 삭제 취소 시 선택 보존, 텍스트 입력 중 Delete의 문자 편집을 확인했다. 기존 단축키 테스트의 창/전역 단축키 잔류를 정리해 관련 파일 통합 실행도 22개 통과했다. 최초 통합 실행 실패를 누락하지 않고 `selection-validation.json`에 원인과 재검증을 기록했다.
