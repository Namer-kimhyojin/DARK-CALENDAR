## 릴리스 경로·전체 입력

릴리스 입력 수집·컴플라이언스 경로·CI 단일 빌드/별도 검증·동일 후보 재검증·SQLite 게이트·버전 예약/잠금 관련 **10개 파일 552건 중 548건 통과, 실패·오류 0건, 4건 건너뜀**이다. 4건은 Windows의 파일 심볼릭 링크 생성 권한 부족(WinError 1314)으로 캐시 탈출 검사를 실행하지 못한 경우다. 권한을 바꾸거나 검사를 삭제하지 않았으며, 링크 생성이 가능한 CI에서 해당 4건을 확인해야 한다. 기존 GitHub 후보의 6회 기동 증거를 새 후보의 결과로 재사용하지 않는다.

검증된 SQLite **3.54.1** 프라이빗 Python과 임시 DB·설정·앱/공유 경로, 외부 소켓 차단을 사용했다. 사용자 DB나 실제 동기화 계정은 열지 않았다. 테스트는 배포 도구의 소스 수준 회귀이며 새 패키지를 만들거나 실행한 검사가 아니다.

- 관리 실행 입력 **680개**는 점검 시작 때와 같고 미등록 입력은 없다. 미배포 구현 후보 **9건**과 원래 이력을 유지했다. 후속 날씨 번역·검색 아이콘 변경으로 겹친 파일은 후속 이벤트 ID와 연결하며, 원래 등록 해시로 되돌리지 않는다.
- Git 미추적 실행 파일 **6개**와 새 테스트 **7개**를 별도 목록에 남겼다. 빌드 정리기·루트 아이콘·라이선스·소스 제공 안내·CI 등 지원 파일 **10개**도 10/29 대조 이후 바뀌지 않았다. 최종 커밋에 현재 전체 입력과 관련 테스트를 포함하고 원격 입력을 다시 대조해야 한다.
