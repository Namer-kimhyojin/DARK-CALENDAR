# 2026-11-13 정기 점검 — 캘린더 동기화

11/02~11/15 주기 12일차에 Google·Outlook·CalDAV의 동기화, 인증, 오프라인 및 오류 복구 흐름을 점검했다.

Outlook 인증 서버가 일시적으로 응답하지 않으면 기존 세션을 갱신할 수 없는 상황을 재로그인으로 안내했다. 접속이 끊겼을 때는 일부 인증 경로에서 연결 오류가 일반 작업 실패로 표시됐다. 이제 인증 서버 정보 조회와 토큰 요청의 연결 오류에는 네트워크 확인과 재시도를 안내한다. 토큰 갱신에서 서버가 일시 장애를 반환해도 재시도 안내를 유지하고, 만료·권한 취소 등으로 인증을 갱신할 수 없으면 기존 재로그인 안내를 사용한다. 이를 위해 캐시 미적중과 갱신 응답 오류를 구별하는 [MSAL 토큰 조회 API](https://learn.microsoft.com/en-us/entra/msal/python/getting-started/acquiring-tokens)를 사용했다.

수정 전 신규 재현 검사 5건 중 4건이 실패했다. 수정 후 47개 파일의 동기화·설정·오류 처리 회귀 **1,102건**이 모두 통과했다. Ruff, 서식, 인코딩 검사도 통과했다. 격리 데이터와 모의 인증·네트워크로 확인했으며 실제 계정 로그인, 사용자 DB, 설치판은 검사에 사용하지 않았다. 증거는 `artifacts/maintenance/20261113-0300/`에 보존했다.

변경 ID는 `maintenance-20261113-outlook-auth-transient-retry`다. 개발 버전 5.2.0은 유지하고 11/16 통합 검증 후보에 등록했다. 읽기 전용 검사 시 별도 미등록 실행 입력 65개를 확인했다. 변경을 보존했으며 범위 대조·이력 등록·영향 검증이 끝나야 통합 배포 버전을 예약할 수 있다.
