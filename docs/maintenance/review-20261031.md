## 재현과 수정

Windows/Qt의 기본 글자색과 앱 테마가 다르면 명령 검색창의 검색·결과 아이콘과 모양 설정의 일부 동작 아이콘이 배경과 구분되지 않았다. 앱은 자체 스타일시트로 색상을 정하지만 해당 아이콘은 qtawesome 기본색을 사용했다. 실제 앱의 전역 스타일 생성 함수를 적용한 격리 호스트에서도 어두운 모드 대비가 약 **1.23:1**로 재현됐다. 10/28의 확인 필요 항목을 제품 코드의 오류로 확인했다.

- **명령 검색창:** 검색·결과 아이콘에 현재 앱의 글자색 토큰을 명시한다. 같은 검색창을 다시 열 때 검색 아이콘도 다시 만들어 밝음/어두움 전환을 반영한다. 검색·일정 생성·실행·키보드 탐색은 보존한다.
- **모양 설정:** 고급 사용자 설정·읽기 편하게 자동 보정·권장 글자색·직접 색상 버튼의 기본 아이콘 4개에 해당 창의 글자색 토큰을 적용한다. 테마 초안·미리보기·적용/취소·설정 저장 방식은 바꾸지 않는다.
- 앱 전체나 Windows의 팔레트를 수정하지 않는다. 이번 두 화면의 호출부만 보완했다. 실제 설치판은 교체하지 않았다.

새 회귀는 Windows와 앱 모드가 다른 상태 및 검색창 재열기에서 실제 아이콘 픽셀의 대비 **3:1 이상**을 검사한다. 수정 전 검색창 16개·모양 설정 4개 하위 검사가 실패했고, 수정 후 신규 두 파일의 **56개 사례(5개 검사와 51개 하위 검사)**가 통과했다. 모양 설정의 최초 밝은 모드 보조 검사는 생성자에 모드를 넘기지 않아 어두운 창을 흰 배경 기준으로 판정했다. 생성자에 모드·배경을 명시해 검사 조건을 바로잡았으며 중간 XML/로그를 보존했다.
