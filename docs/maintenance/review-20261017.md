## 확인 결과

관련 회귀 20개 파일의 **199개 사례**가 파일별 격리 프로세스에서 통과했다. 모양 설정의 적용/취소·섹션 되돌리기·고급 편집 초안 보존, 시스템 모드 변경과 사용자 색상 보존, 테마 갱신 병합, 라이트 모드 읽기 표면·색상 대비, 다이얼로그 필드 이름·기본 버튼·키보드 선택을 확인했다.

19개 번들 언어의 키·형식·치환자·손상 문자열 검사도 통과했다. 이전 기록의 로케일 구조 실패는 현재 검사에서는 재현되지 않았다. 기존 번역을 일괄 덮어쓰거나 자동 번역하지 않았다.

19개 언어와 두 화면 작업 영역(1024×640, 1280×800)의 **38개 조합**에서 모양 설정 창 크기, 적용·취소 버튼의 창 내부 배치와 접근성 이름, 변경 전 적용 비활성/변경 후 활성, 아랍어 RTL을 확인했다. 한국어·독일어·아랍어 캡처를 확인했다. 최초 기본 오프스크린 글꼴에서는 일부 문자가 표시되지 않아 Windows 글꼴 디렉터리를 지정한 뒤 38개 조합을 다시 검사했다. 최초 실행은 최종 237개 사례에 중복 합산하지 않았다.

최종 고유 기능 검사는 **237개**, 별도 인코딩 정책 검사는 **12개** 통과했다. 인코딩/컴파일 가드, 검사 실행기 Ruff와 diff 검사도 통과했다. 임시 INI QSettings·개인/공유 DB·인증 경로를 사용했고 실제 사용자 설정이 변하지 않았음을 확인했다. 오프스크린 화면과 모의 작업 영역 검사는 실제 혼합 DPI·스크린리더·설치판 UI 검증과 구분한다. 키와 치환자 일치가 모든 번역의 언어 품질까지 보장하지는 않는다.

## 버전·배포 후보 정합성

별도 예외/동기화 점검 작업이 등록한 18개 이벤트를 공용 배포 후보에 연결하고, 공용 개발 버전을 원본 이력의 **4.1.0 Dev**로 맞췄다. 이들은 오늘 추가 구현한 변경이 아니다. 각 후보에는 등록 버전과 현재 입력 일치 여부를 기록하고, 이후 변경된 파일은 과거 검증 결과로 전체 통과 처리하지 않았다. 기존 두 점검 보고서와 증거는 보존하며 **전체 실행 입력의 통합 검증 대기**로 관리한다.

종료 전 `manage_version.py scan`은 `changed=false / 4.1.0`을 반환했다. 오늘 검토·문서·상태 갱신만으로 중복 버전을 부여하지 않았다. 새 패키지 빌드, Git 커밋/푸시, Store 제출·설치는 수행하지 않았다.
