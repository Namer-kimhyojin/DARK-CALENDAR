# 위젯 구성 편집기 고도화 결과

2026-10-01 · 로컬 소스 구현 및 검증 기록

## 화면과 조작

실제 위젯 렌더링 위에서 요소를 선택하고 이동·크기를 조절하는 WYSIWYG 화면으로 변경했습니다. 현재 위젯의 캐시 항목, 선택 날짜, 필터, 시계 표시를 읽기 전용으로 반영합니다. 빈 캐시는 빈 목록으로 표시하며, 캐시가 없는 호출만 예시 일정을 사용합니다.

- 왼쪽: 구성 요소 / 위치·크기 / 캔버스 / 모양 탭, 작은 화면에서는 세로 스크롤
- 오른쪽: 실제 미리보기, 선택·호버 요소에만 윤곽 표시, 선택 이름·잠금 배지
- Ctrl·Shift 다중 선택, 빈 영역 드래그 선택, 그룹 이동, 8방향 크기 조절
- 선택적 격자·요소 맞춤, 정렬 6종, 가로·세로 간격 맞춤
- 요소 앞뒤 순서, 잠금, Delete 숨기기, 1px·10px 키보드 이동
- 글꼴·크기·굵기·색상 스킨·글자/배경 불투명도 즉시 미리보기
- 배치와 모양을 함께 실행 취소/다시 실행, 적용·취소 전 사용자 설정과 실제 창 좌표 보존
- 10~200% 확대, 화면 맞춤, 큰 캔버스 스크롤
- 배치 구성 불러오기/내보내기: `.airlayout.json`, 모양 설정은 파일에 포함하지 않음

프리셋과 version 1 저장 호환을 유지했습니다. `order`, `locked`는 선택 필드이며 이전 파일은 기본 순서·잠금 해제로 읽습니다. 런타임과 미리보기의 요소 순서도 함께 적용합니다. 필터에서 섹션 제목이 없는 항목이 빠지던 문제를 회귀 테스트와 함께 수정했습니다.

## 후속: 사용자 배치 프리셋

구성 편집의 배치를 이름을 붙여 저장·선택·수정·삭제할 수 있도록 추가했습니다.

1. 구성 편집 → **내 배치 → 새 프리셋으로 저장…** → 이름 입력 → **적용**
2. 꾸미기 → 배치 → **내 배치**에서 썸네일 선택 → 미리보기 확인 → **적용**
3. 저장한 배치 선택 → **배치 수정…** → 구성 편집 → **적용** → 꾸미기에서도 **적용**하면 영구 저장
4. 이름 변경·삭제도 적용 전에 취소할 수 있습니다. 구성 편집에서는 덮어쓰기와 프리셋 변경도 실행 취소/다시 실행합니다.

더 보기 → 배치 메뉴에서도 저장한 배치를 바로 선택합니다. 기본 배치를 골라도 사용자 목록은 유지됩니다. 배치의 구성 요소·좌표·크기·달력 보기·순서·잠금을 저장하며 색상/글꼴은 현재 설정을 유지합니다. 사용자 프리셋 삭제는 현재 표시 중인 자유 구성 좌표를 지우지 않습니다.

저장은 기존 QSettings를 사용하며, UUID ID와 version 1 JSON 목록을 기본 배치 레지스트리와 분리합니다. 이름·중복·배치·개수·크기를 검증하며 손상되거나 미래 버전인 설정은 읽기만으로 덮어쓰지 않습니다.

사용자 프리셋 화면·상호작용과 임시 INI 재시작 검증은 100%·200%에서 104개 검사, 실패 0입니다. 한국어·독일어 화면 8개를 `artifacts/widget-layout-presets-20261001/`에 기록했습니다. 실제 사용자 설정·DB는 사용하지 않았으며 빌드·설치·배포는 수행하지 않았습니다.

관련 테스트 25파일 368개가 실패·오류·건너뜀 없이 통과했습니다. 최종 인코딩 guard와 Ruff가 통과했으며, 새 문구 18개를 19개 로케일에 반영하고 번역 구조·플레이스홀더를 확인했습니다. 기록: `artifacts/widget-layout-presets-20261001/tests/summary.json`.
