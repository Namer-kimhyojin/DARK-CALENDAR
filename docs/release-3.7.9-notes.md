# Air Calendar 3.7.9

**출시일:** 2026-10-02 · **채널:** Stable · **배포 대상:** Windows x64

개발 폴더의 `run.bat`이 실행하는 현재 앱 소스·번역·리소스를 함께 반영한 릴리스입니다. 이전 배포에서 제외됐던 앱 변경사항을 통합했습니다.

- 위젯 전용 모드의 개선된 목록·주간 보기, 자유 이동·크기 조절, 실제 렌더링을 사용하는 WYSIWYG 구성 편집기, 사용자 배치 프리셋 저장·수정·삭제를 유지합니다.
- Air KeyDeck v4와 KeyDeck Studio, 페이지·키보드 배열·레이아웃 갤러리, 그림·소리가 내장된 `.keydeck` 공유를 포함합니다.
- 스위치 물리·타건음, 키캡 모양·각인·파노라마 배치와 관련 번역·리소스를 포함합니다.
- 앱 종료·재시작 안정화, 종료 확인창 표시, Google 로그인이 필요한 경우 자동 동기화 대기, 잠금 오버레이 포커스 처리를 반영합니다.

기존 Store 식별자 `Kimhyojin.DarkCalendar`와 사용자 설정·데이터의 호환성을 유지합니다. 로컬 사용자 DB·로그·Google 인증 정보는 배포 파일에 포함하지 않습니다.

배포 파일은 x64 MSIX, Microsoft Store 업로드용 MSIXUPLOAD, 전체 대응 소스 ZIP 및 각 SHA-256 체크섬입니다. Microsoft Store 업로드·인증 제출은 별도 절차입니다.
