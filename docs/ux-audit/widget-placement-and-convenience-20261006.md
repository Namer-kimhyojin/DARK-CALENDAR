# 위젯 배치 및 개별 사용성 개선 — 2026-10-06

## 적용한 방향

위젯 콘텐츠를 읽거나 사용하는 중에는 조작 표시를 최소화하고, 사용자가 실제로 이동·크기를 변경할 때만 필요한 피드백을 제공합니다. 마우스와 정확한 수치 입력을 함께 지원하며, 배치 고정은 위젯의 콘텐츠 기능을 막지 않습니다.

## 시작 요약정보의 우선 표시

요약창은 일반 모달이었고, 복원되는 위젯은 별도의 `항상 위` 창이어서 요약정보와 닫기 버튼을 가릴 수 있었습니다.

- 요약창에 `WindowStaysOnTopHint`와 앱 모달 우선순위를 적용했습니다. 처음 표시할 때 창을 앞으로 가져오고 닫기 버튼에 키보드 초점을 둡니다.
- 개별 오버레이·위젯 전용 화면·기존 분리형 패널이 뒤늦게 표시되거나 앞으로 올라오는 이벤트를 감지해 요약창을 다시 앞에 둡니다. 연속 이벤트는 한 번의 대기 작업으로 합칩니다.
- 요약창을 숨기거나 닫으면 이벤트 감시와 대기 작업을 해제합니다. 위젯의 `항상 위`, 배치, 표시 설정은 변경하지 않습니다.
- 실제 Windows 창에서 숨겨진 메인 창을 부모로 둔 요약정보 위에 시계와 위젯 전용 화면을 순서대로 복원했습니다. 네이티브 창 순서, 닫기 버튼 위치의 실제 입력 대상, 닫은 뒤 위젯 조작 복구를 확인했습니다.
- 검증 기록: `artifacts/widget-ux-20261006/summary-priority-windows.json`. 모든 항목이 통과했고 사용자 설정 보존도 확인했습니다.

## 위젯별 개선

| 위젯 | 확인한 불편 | 구현한 개선 |
|---|---|---|
| 시계 | 시간대를 변경하려면 설정창을 거쳐야 하고 더블클릭 설정 진입이 없음 | 기존 시간대 설정을 사용하는 빠른 선택 메뉴, 더블클릭 설정 |
| 스톱워치 | 초기화하면 이전 시간·실행 상태를 복구할 수 없음 | 초기화 되돌리기, 원래 실행 기준 시각 복원, 초기 상태에서는 불필요한 초기화 비활성화 |
| 날짜 카드 | 더블클릭 설정 진입과 날짜 복사 없음 | 더블클릭 설정, ISO 형식의 오늘 날짜 복사 |
| 카운트다운 | 목표 지우기 실수 시 복구 불가 | 목표 지우기 되돌리기, 목표가 없을 때 지우기 비활성화 |
| D-Day | 날짜·이름을 초기화하면 복구 불가 | 날짜와 이름을 함께 복구, 외관·일러스트 설정 보존 |
| 텍스트/메모 | 표시된 템플릿 결과를 쉽게 복사할 수 없음 | 실제 표시 내용의 일반 텍스트 복사. 별도 템플릿 재계산으로 실제 값이 사라지지 않도록 현재 표시를 사용 |
| 날씨 | 설정 진입 방식이 다른 위젯과 일관되지 않음 | 더블클릭 설정. 기존 로딩·캐시·재시도·요청 제한·새로고침 흐름 유지 |
| 키덱 | 이동·크기 변경과 키 누르기의 구분 및 복구가 필요 | 키 입력 우선순위 유지, 배치 고정 상태에서도 키 사용, 배치 되돌리기 시 배율 복원. 키 구성은 덮어쓰지 않음 |

## 공통 배치 조작

- 본문에 마우스를 올리는 것만으로 전체 조절 테두리를 그리지 않습니다. 해당 모서리에 접근하면 그 모서리만 표시합니다.
- 이동·크기 조절은 OS의 드래그 시작 거리 이후에 시작합니다. 단순 클릭과 미세한 손떨림으로 저장값·폰트·자동 맞춤·배치 이력이 변경되지 않습니다.
- 움직이는 동안의 열린 손/닫힌 손과 모서리 방향 커서를 구분합니다.
- Shift를 누르고 크기를 조절하면 기존 가로·세로 비율을 유지합니다. 자유 변형이 기본이며 기존 원형·캡슐·포스터 및 키덱의 모양 제약은 유지합니다.
- Alt를 누른 채 이동을 끝내면 자동 맞춤을 잠시 건너뜁니다. 멀리 떨어진 위젯 때문에 엉뚱한 축으로 끌려가지 않도록 주변 위젯 맞춤 조건을 제한했습니다.
- 우클릭 메뉴의 `위치·크기 조정`에서 좌표·너비·높이를 입력하고 적용합니다. 취소하면 원래 화면과 설정을 유지합니다. `화면 안에 맞추기`와 `처음 값으로`도 적용 전 초안만 조정합니다.
- 위치·크기 고정은 인스턴스별로 저장합니다. 앱의 전체 상호작용 잠금을 해제해도 개별 배치 고정 설정은 유지합니다.
- 최근 배치 되돌리기는 창 위치·크기와 크기 변경에 수반한 글자 크기를 복구합니다. 키덱은 배율을 복원하며 현재 키 구성을 유지합니다.
- 마우스 해제를 잃어버린 동작은 이전 배치로 돌아갑니다. Esc는 이 앱이 키 입력을 받는 편집 상황에서 진행 중인 조작을 취소합니다. 다른 앱의 키 입력을 가로채는 전역 단축키는 추가하지 않습니다.
- 위젯 전용 화면에도 같은 조정창·고정·배치 되돌리기를 연결했습니다. 크기 조절 모서리는 호버·조작 중에만 표시하고, 다른 배치 유형의 오래된 이력으로 현재 창 크기를 되돌리지 않습니다.

## 설정 및 초기화 경계

- 글꼴·크기·투명도·색상·표시 형식·추가 옵션에서 마우스 휠은 값 변경에 사용하지 않습니다. 클릭/드래그/키보드로 값을 명시적으로 변경합니다.
- 수치 입력은 방향키로 1단계, Shift+방향키로 10단계 조정합니다.
- 문자열 `false`를 저장한 사용자 옵션이 재시작 후 켜지는 문제를 보완했습니다.
- 콘텐츠 초기화의 되돌리기는 현재 실행 중인 해당 위젯에 한 단계 보관합니다. 설정창에서 새 변경을 적용하면 이전 초기화 이력을 폐기합니다.
- 기존 설정 prefix, 인스턴스 JSON, 프리셋 형식, DB 스키마와 사용자 데이터는 변경하지 않습니다.
