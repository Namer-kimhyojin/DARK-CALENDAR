# KeyDeck 비트메이커 (2026-10-19)

## 사용 방법

1. 키덱 우클릭 → **레이아웃**에서 비트메이커의 **Lo-fi Desk / Neon Beat / 8-bit Arcade** 카드를 선택한다. 현재 페이지를 바꾸는 기존 확인 절차를 거친다. 선택 키트의 드럼 패드가 채워지고, 같은 키트의 멜로디 페이지가 없으면 빈 페이지 여유 안에서 함께 추가된다. 다른 페이지는 보존한다. ([2026-10-20 카드 분리](keydeck-beatmaker-gallery-20261020.md))
2. Studio 상단의 **음원 키트 / 연주 종류**에서 Lo-fi Desk, Neon Beat, 8-bit Arcade와 드럼·멜로디를 선택한다. 기존 연주 페이지로 이동할 때 편집한 패드를 다시 생성하지 않는다.
3. 키덱 우클릭 → **비트메이커 → 키보드 연주 시작**을 선택하면 `1234 / QWER / ASDF / ZXCV`로 연주한다. `Esc`로 종료한다. 이 모드에서만 창이 키보드 포커스를 받으며, 다른 앱의 키 입력을 전역으로 수집하지 않는다.
4. 개별 패드 우클릭 → **이 키 효과음 설정…**에서 음원 검색·미리 듣기·WAV 교체·개별 음량을 조절한다. Studio의 **전체 효과음**에서 덱 음량과 음소거를 조절한다.
5. 우클릭 → **비트메이커 → 모든 소리 정지**는 KeyDeck 공용 재생기의 활성 음성과 대기 중인 타건을 정지한다. 음원 캐시는 유지한다.

## 구성과 저장 계약

- 새 배열 ID는 `beatmaker_4x4`이며 기존 배열과 나란히 제공한다. 새 기본 덱 생성 시 드럼·멜로디 두 페이지를 만든다. 최대 12페이지에서는 기존 페이지를 덮어써 새 연주 페이지를 만들지 않는다.
- 각 키트는 드럼 16종과 C장조 펜타토닉 16음(C3~C6)을 포함한다. 총 96개 WAV이며 기존 피드백 효과음 24종을 보존한다. 전체 음원 카탈로그는 120종이다.
- 직접 합성한 mono PCM16/44.1kHz 원샷이며 외부 녹음 샘플을 사용하지 않는다. 생성기는 `scripts/generate_beatmaker_sounds.py`, 공통 음원 ID는 `calendar_app/shared/beatmaker_sound_catalog.py`에 둔다.
- 페이지에는 검증된 `beatmaker={kit, bank}` 메타데이터를 저장한다. 개별 키의 `sound`, `sound_path`, `action`이 실제 연주값이다. 일반 편집·정규화 때 프리셋을 다시 생성하지 않는다.
- 새 `sound` 동작은 외부 앱 실행·단축키 전송·미지정 안내 없이 누르는 순간 키의 음원을 재생한다. 키의 `sound_volume`은 0~100, 기본 100이며 덱 전체 음량과 곱한다.
- 키트 재선택은 현재 페이지 패드·소리를 바꾸는 명시적 프리셋 작업이다. 실제 덱에서는 확인 후 바꾸고, Studio에서는 초안/실행 취소 한 건으로 기록한다. 다른 페이지의 키트는 유지한다.
- 키보드 여러 키 동시 누름, 자동 반복 억제, 키보드·마우스가 같은 패드를 누른 상태의 부분 해제, 포커스 유실·숨김·비활성화·페이지 전환 시 해제를 처리한다. Studio 텍스트 입력에서는 연주하지 않는다.
- 테마 적용 시 연주 패드의 색·평면 모양·라벨을 유지한다. 저장·재시작·단일 페이지/덱 공유에 메타데이터와 개별 음량을 보존한다.
- 한국어·영어 문구와 19개 번들 로케일의 키/placeholder 구조를 맞춘다. 그 외 언어의 새 문구는 영어로 제공한다.
- 두 PyInstaller 스펙의 기존 `('Assets', 'Assets')` 재귀 수집이 신규 WAV 폴더를 포함한다.

## 검증 범위

- 최종 실행 입력의 관련 회귀는 고유 **426 tests / 520 subtests**를 확인했다. 통합 실행에서 기능 425개와 520개 subtest가 통과했고, 번역 canonical 정렬 검사 1개 실패는 19개 로케일의 키·값을 유지한 정렬로 해결했다. 이후 i18n/비트메이커 UI 19개를 다시 실행해 모두 통과했다.
- 전체 인코딩 가드(compileall + 정책/유틸 12 tests), 변경 Python 파일 Ruff, `git diff --check`를 통과했다.
- 음원 96종의 PCM 형식·음정·음량·피크·페이드·바이트 재현성을 검사한다. Native WinMM은 모의 장치로 버퍼 수명과 전체 정지 후 재사용/대기음 폐기를 검사한다.
- 화면: `artifacts/keydeck-beatmaker-20261019/beatmaker-layouts.png`, `studio-{deck,key}-{1100,1260}.png`. Windows 글꼴을 등록한 offscreen Qt에서 확인했다. 800px 가상 화면의 자동 창 크기 제한은 검토용 1800×1100 경계로 분리했다.
- 최종 회귀 드라이버는 INI 설정의 User/System 경로를 작업 산출물 아래로 전환한다. 화면 검토는 음원 재생기를 모의 처리한다.
- 실제 스피커 청음·음악용 지연 측정·실계정·실행 중인 앱 재시작·빌드·설치·Store 배포는 이 검증에 포함하지 않는다. BPM 반복·녹음·시퀀서·8×8 배열은 이번 구현 범위에 포함하지 않는다.
