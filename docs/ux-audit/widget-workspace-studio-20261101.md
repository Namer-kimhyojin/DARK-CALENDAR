## 작업 공간 저장·적용 흐름

1. 필요한 위젯을 추가하고 위치·외관을 정한다. 전용 모드도 원하는 화면·스킨으로 꾸민다.
2. **작업 공간 → 현재 상태 새로 저장**을 누르고 `업무용`, `집중용` 등 이름을 입력한다.
3. 모든 일정 캘린더를 사용할지, 현재 불러온 캘린더 중 일부만 사용할지 선택한 뒤 **저장**한다.
4. 카드를 고르고 **선택 작업 공간 적용**을 누른다. 현재 모드가 열려 있는지 닫혀 있는지는 유지한다.
5. 모드 실행 상태까지 불러오려면 **적용하고 저장 모드로 열기**를 사용한다.
6. 배치·외관·표시를 되돌리려면 **최근 적용 되돌리기**를 누른다. 되돌리기는 한 단계이며 현재 모드 실행 상태는 유지한다.

**선택 구성 수정**은 현재 상태로 해당 저장 구성을 갱신한다. 저장 구성 삭제 시 연결된 규칙도 함께 삭제하며 실제 위젯은 유지한다.

위젯의 본문·목표 시간·실행 중인 스톱워치·날씨 지역·KeyDeck 동작과 파일은 개별 위젯에서 공유한다. 작업 공간은 표시·외관·배치와 전용 모드 설정을 저장한다. KeyDeck은 키 동작·그림·사운드를 복사하지 않고 시각 색상·크기만 복원하며, 비트메이커 사운드 키의 의미 색상을 보존한다.

적용 시 저장 구성에 없는 새 위젯은 숨긴다. 삭제된 위젯은 재생성하지 않고 제외 개수를 안내한다. 저장한 자유 구성 프리셋 목록, 다른 앱 설정, 다음 실행 시 모드 복원 설정은 작업 공간 복원으로 덮어쓰지 않는다.

## 자동 전환·스택 동작

- 자동 전환은 기본적으로 꺼져 있다. 규칙을 추가하고 자동 전환을 켠 뒤 **적용**해야 작동한다.
- 위쪽의 일치하는 규칙을 먼저 적용한다. 시작은 포함하고 종료 시각은 제외한다.
- `22:00–02:00`은 선택한 요일부터 다음 날 02:00 전까지 적용한다. 시작과 종료가 같으면 선택한 요일 하루 전체다.
- 직접 작업 공간을 적용하거나 최근 적용을 되돌리면 자동 전환을 한 시간 쉰다. 모달 편집기가 열려 있으면 전환을 기다린다.
- 자동 전환은 전용 모드를 강제로 열거나 닫지 않는다. 일정 필터는 메인 화면에서 이미 불러온 일정 안에서 적용한다. 업무·지시의 기존 수정·완료·읽기 전용 흐름은 유지한다.
- 스택은 기존 네이티브 위젯 창을 재사용한다. 대기 페이지를 숨겨도 인스턴스의 사용 설정과 본문은 유지한다.
- 자동 순환은 기본 꺼짐이며 켜면 10초 간격이다. 마우스·포커스·팝업·모달 편집 중과 전체 화면 일시정지 중에는 기다린다.
- 잠금 해제된 위젯만 스택으로 묶을 수 있다. 해제하면 처음 위치와 표시 여부로 돌아간다. 위치·크기 잠금은 배치 편집에서도 유지한다.

## 성능·저장 계약

- `calendar_app/domain/widget_workspace.py`: Qt에 의존하지 않는 문서 검증·시간 규칙·배치 계산·캘린더 범위 판단.
- `widget_workspace_runtime.py`: manager가 소유하는 단일 서비스. 기존 인스턴스의 `_get`·`_set`·설정 proxy를 사용하며 설정 키를 직접 추정하지 않는다.
- `QSettings["widget_studio_state"]`: 버전 1의 로컬 문서. 최대 30개 작업 공간, 구성당 128개 인스턴스, 스택 32개, 스택당 2–32개 위젯, 규칙 32개, 문서 크기 5MB를 검증한다. 잘못된 원본은 읽기 시 덮어쓰지 않는다.
- 스택은 위젯당 한 곳에만 속한다. 연속 페이지 전환의 메타데이터 저장은 150ms로 병합하고 종료 시 대기 저장을 마친다.
- 적용 중 실패하면 직전 표시·외관·배치로 복원한다. 편집기 취소는 저장하지 않는다. 기존 DB 스키마와 사용자 일정은 변경하지 않는다.
- 미리보기는 위젯을 다시 생성·표시·리사이즈하지 않고 제한된 크기로 렌더링한다. 화면에 가까운 카드만 갱신하고 캐시 48개를 유지한다. 화면 밖 아이콘 참조를 해제한다.
- 선택 미리보기 움직임은 기본 꺼짐이며 한 개만 250ms 간격으로 갱신한다. 초안 변경은 120ms로 병합하고 숨김·닫기에서 타이머를 멈춘다.
- 관리창은 닫았다 다시 열어도 기존 창을 재사용하고 변경된 테마를 갱신한다. 숨겨진 작업 공간 탭은 변경 신호마다 썸네일 목록을 재생성하지 않는다.
- 전체 화면 감지는 켰을 때 1초, 스택 순환은 10초, 규칙은 30초 간격으로 확인한다. 표시 중인 KeyDeck의 시스템 움직임 정책은 60초 간격으로 확인한다. 공통 조건은 manager의 단일 타이머로 처리한다.
- Windows의 애니메이션·절전 설정과 위젯별 움직임 끔을 함께 따른다. 화면 장식만 정지하고 키 입력·스위치 소리·실행 중인 타이머는 유지한다.
- 세로 공간이 부족하면 관리창 소개를 접고 갤러리를 작게 배치한다. 갤러리와 설정창의 적용·취소는 스크롤 밖에 둔다. 맞춤 옵션은 **더보기**에서도 변경할 수 있다.
- 신규 메시지 107개: 한국어·영어 제공, 나머지 17개 번들 언어는 영어 fallback 적용.
