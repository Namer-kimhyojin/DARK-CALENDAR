# 키덱 스튜디오 테마 갤러리 — 2026-10-06

Studio의 긴 테마 드롭다운을 **테마 갤러리 모달**로 교체했다. 기존 7개를 유지하고 17개를 추가해 총 24개를 제공한다. 테마를 비교하고 확정한 뒤 Studio 초안에 적용하는 흐름이며, Store 설치본은 교체하지 않았다.

## 제공 테마

| 계열 | 테마 |
|---|---|
| 글래스 | 크리스탈 나이트, 플로팅 글래스, 아틱 글래스, 오로라 글래스 |
| 미니멀 | 그래파이트 PBT, 포슬린, 슬레이트, 미드나이트 네이비 |
| 파스텔 | 프로스트 페이퍼, 푸딩 팝, 사쿠라 블룸, 라벤더 미스트 |
| 내추럴 | 월넛 스튜디오, 포레스트 세이지, 데저트 샌드, 오션 블루 |
| 네온 | 스모크 네온, 신스웨이브, 터미널 그린, 사이버 펄스 |
| 레트로 | 코퍼 더스크, 크림 타이프라이터, 올리브 워크숍, 코발트 아케이드 |

색상뿐 아니라 케이스·재질·키캡 프로필·인서트·조명 레시피를 조합했다. 기존 테마 ID·레시피·기본 선택과 저장 스키마 v4는 유지한다.

## 사용자 흐름

1. Studio의 **테마** 버튼으로 갤러리를 연다.
2. 이름·분위기를 검색하거나 6개 분류를 선택한다. 카드에서 고른 테마는 오른쪽의 현재 키 배치로 미리 본다. 카드 썸네일은 동일한 대표 배치로 테마를 비교한다.
3. 덱 전체·현재 페이지·선택한 키 중 적용 범위를 고른다. 선택한 키가 없으면 해당 범위는 비활성화된다.
4. **테마 적용**으로 Studio 초안에 반영한다. Ctrl+Z/Ctrl+Y로 되돌리고 다시 적용할 수 있다. Studio의 최종 **적용**을 눌러야 실제 위젯과 설정에 저장한다.

검색·카드 클릭·더블클릭·취소는 원본을 수정하지 않는다. 이미지·파노라마·키 배치·이름·동작·토글 상태와 사용자 사운드 설정을 유지한다. 페이지/선택 범위는 케이스와 나머지 페이지·키를 보존하고 사용자 지정 테마로 표시한다. 빈 페이지는 테마 비교 예시를 표시하며 키를 추가하지 않는다.

## 구현과 검증

- 갤러리는 공통 다이얼로그 스타일과 의미별 색상 토큰을 사용한다. 19개 로케일에 69개 이름·설명·분류·안내 키를 추가하고 기존 dirty 번역값을 보존했다. 한국어/영어를 제공하고 나머지 언어는 영어 대체값을 사용한다.
- 콤보박스의 휠 입력으로 값이 바뀌지 않는다. 키 실행·새 설정 저장·외부 네트워크 요청 없이 정적 렌더러만 사용한다.
- 썸네일은 보이는 카드만 이벤트 루프에서 하나씩 생성하고 캐시한다. 닫을 때 지연 타이머를 중지한다. 초기 빈 아이콘의 높이 캐시로 잘리던 문제는 카드 크기를 먼저 지정해 수정했다.
- 새 모델 검사 71개 통과 — [JUnit](../../artifacts/keydeck-themes-20261006/catalog-tests.xml). 기존 7개 레시피, 24개 저장 왕복, 이미지/동작 보존, 104키 레이아웃 및 범위 적용을 검증했다.
- 갤러리와 Studio/실제 위젯 적용 검사 19개 통과 — [JUnit](../../artifacts/keydeck-themes-20261006/gallery-tests.xml). 미리보기·취소·범위·휠·실행 취소·다시 실행·최종 저장과 빈 아이콘 상태부터 실제 썸네일 생성 이후까지의 카드 높이·이미지/글자 공간 보존을 검증했다.
- 기존 KeyDeck 모델·렌더·위젯·Studio·레이아웃 회귀 통과 — [JUnit](../../artifacts/keydeck-themes-20261006/regression-tests.xml). XML의 418개 항목은 하위 검사도 포함한다.
- 번역 구조/런타임 15개 통과 — [JUnit](../../artifacts/keydeck-themes-20261006/locale-tests.xml).
- Windows 실제 렌더에서 어두운/밝은 모드, 작은 창, 카드/미리보기/적용 범위/버튼 표시와 취소 시 원본 보존을 확인했다. 작은 창은 논리 좌표 기준 920×약 699px이며 화면 배율 125%의 캡처 픽셀 크기와 구분한다. 후속 갤러리 생성은 약 0.09초(이 환경의 측정) — [결과](../../artifacts/keydeck-themes-20261006/results-native.json).
- 검증은 임시 INI 설정으로 수행하고 사용자 Windows 설정의 실행 전후 동일성을 확인했다.
- 관련 Ruff·diff 공백 검사와 인코딩 가드(인코딩 검사 12개)를 통과했다. compileall의 기존 접근 불가 pytest 캐시 두 곳 경고는 남아 있다. 임시 LOCALAPPDATA의 선택적 codicon 폰트 경고는 갤러리 카드·미리보기 렌더를 막지 않았다.
