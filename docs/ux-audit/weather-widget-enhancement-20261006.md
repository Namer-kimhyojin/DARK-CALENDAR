# 날씨 위젯 디자인과 크기 조절 개선 — 2026-10-06

날씨 일러스트, 정보 배치, 표면 외관과 모양을 함께 비교하는 디자인 갤러리를 추가한다. 기존 사용자 템플릿과 도시·온도 단위·갱신 주기를 보존하면서 그림과 글자가 위젯 크기에 함께 반응하도록 렌더링을 공유한다. 이 문서는 로컬 구현 및 검증 기록이며 Store 설치본의 업데이트 기록과 구분한다.

## 제공 범위

- 디자인 레시피는 글래스·미니멀·에디토리얼·팝/일러스트·네온/디지털·내추럴 6계열의 총 24개다. 각 레시피는 템플릿, 일러스트 팩, 공통 외관 프리셋과 카드·원·캡슐·포스터 모양을 조합한다.
- 일러스트는 기존 4개에 선화·네온·플랫·픽셀·궤도 배지·빈티지를 추가한 10개 팩이다. 그림의 투명 여백을 정리하고 최대 1536px 렌더링 및 64항목 HTML 캐시를 제공한다.
- 기본 표시 형식은 기존 9개 ID와 순서를 유지하고 11개를 추가해 총 20개다. JSON 카탈로그와 코드 fallback의 내용은 동일하다. 기존 기본 형식 중 기본 카드만 그림 64·온도 28·단위 14·도시 12의 기준 크기로 조정한다.
- 추가 표시 형식은 데일리 카드, 가로 바, 와이드 날씨, 대형 아이콘, 야간 카드, 여행 도시, 습도 포커스, 바람 포커스, 날씨 상태 포커스, 온도 배지, 미니 대시보드다.
- 지원하는 값은 도시·기온·온도 단위·날씨 설명·아이콘·습도·바람이다. 현재 데이터가 제공하지 않는 강수량이나 강수 확률을 표시 형식에 추가하지 않는다.

## 사용자 흐름과 저장 경계

1. 위젯 우클릭의 **날씨 디자인 고르기…**에서 갤러리를 연다. 검색과 계열 선택으로 디자인을 좁히고 카드 및 상세 미리보기로 비교한다.
2. 검색, 카드 선택, 더블클릭과 취소는 실제 위젯 설정을 변경하지 않는다. **디자인 적용**을 눌러 확정한 레시피만 해당 인스턴스에 적용한다.
3. 일반 설정 창에서도 같은 갤러리를 연다. 이 경우 확정한 디자인은 설정 창의 일러스트·외관·모양·템플릿 조절부에만 반영한다. 부모 설정 창의 최종 저장 전에는 실제 위젯을 변경하지 않는다.

디자인 선택은 도시, 온도 단위, 갱신 주기, 저장된 날씨와 위치를 변경하거나 새 네트워크 요청을 실행하지 않는다. 기존 그림자·배치 잠금 등 디자인 레시피에 포함하지 않은 사용자 설정도 유지한다. 사용자 템플릿은 명시적으로 새로운 디자인이나 표시 형식을 적용할 때만 교체하며, 카탈로그 조회·위젯 재생성만으로 바꾸지 않는다.

## 렌더링과 크기 조절

`weather_template.py`를 실제 위젯과 갤러리 미리보기에서 공유한다. 텍스트 크기와 `{icon|size=N}`은 공통 24pt 기준을 사용하며, 위젯을 확대·축소할 때 같은 기준으로 계산한다. 그림의 하한·상한을 적용하고 비정상적인 크기 입력은 무시한다. 기본 단위와 크기 힌트가 없는 사용자 변수에도 기본 크기 마커를 적용해 고정 픽셀 스타일 때문에 글자 일부가 크기 조절에서 빠지지 않도록 한다.

일반 템플릿 미리보기에서도 날씨 그림에 렌더 기준 크기를 기록하고 미리보기 상자의 기준 크기로 변환한다. 날씨 값은 HTML escape를 거치며, 날씨 상태와 낮·밤 정보를 사용해 기존 일러스트 팩을 선택한다. 로딩과 오류 상태는 템플릿에 오류 변수가 없어도 별도 안내로 표시하는 기존 흐름을 유지한다.

직접 디자인 적용과 설정 창 저장은 같은 모양 정책을 따라야 한다. 원은 정사각형, 캡슐은 최소 가로 비율, 포스터는 세로 비율을 확보하고 모양 마스크를 갱신한다. 일반 카드로 돌아올 때에는 이전 원·포스터의 고정 상자를 해제한다. 이미 고정된 상자가 있으면 새 콘텐츠에 맞게 글자 크기를 다시 맞춘다.

검토에서 발견한 모양 비율 누락과 비정상 줄 간격 예외는 구현 담당에게 즉시 전달한 뒤 수정본으로 재확인했다. 모양이 이미 원인데 고정 너비·높이가 없거나 한쪽만 있는 복원 상태도 같은 보정 경로에 들어가 정사각형으로 표시됨을 확인했다. 갤러리의 레시피 글자 크기는 대표 미리보기 기준이며, 실제 위젯의 사용자 크기 보존 정책과 구분한다.

날씨·디자인·공통 외관·템플릿·그림자·번역·인코딩의 최종 통합 회귀 367개가 실패·오류·건너뛰기 없이 통과했다. [통합 JUnit](../../artifacts/weather-improvements-20261006/full-regression.xml)에 결과를 보존했다. 설정은 모든 QSettings 생성자를 임시 INI로 격리하고 실행 전후 실제 사용자 Windows 설정이 동일함을 확인했다. 실제 사용자 DB나 Google 계정은 검증에 사용하지 않았다. Ruff, `git diff --check`, 인코딩 가드도 통과했다.

Windows 실제 렌더링에서 210×240, 320×360, 520×600 크기의 그림·온도·단위가 함께 커지고, 어두운/밝은 디자인 갤러리가 표시됨을 확인했다. 네트워크 요청 없이 저장된 예시 날씨를 사용했다. 미리보기에서 빠졌던 밝은 테마 배경을 `WA_StyledBackground`와 스타일 polish로 수정했고, 습도·바람 단위와 정렬 행의 불필요한 간격도 보완했다.
