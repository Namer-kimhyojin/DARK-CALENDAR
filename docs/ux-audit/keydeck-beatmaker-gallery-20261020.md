# KeyDeck 비트메이커 키트별 갤러리 카드 (2026-10-20)

## 문제와 조치

사용자는 Lo-fi·Neon·8-bit를 각각 갤러리 카드에서 선택하기를 기대했다. 기존 구현은 `beatmaker_4x4` 카드 하나에서 시작하고 Studio 안에서만 키트를 바꾸도록 되어 있어, 갤러리에는 기본 Lo-fi 카드만 나타났다. 기존 매크로·넘패드 등 다른 배열이 사라지는 현상은 재현되지 않았다.

- 기본 레이아웃에 **Lo-fi Desk / Neon Beat / 8-bit Arcade** 카드를 각각 제공한다. 기존 일반 배열 10개를 포함한 전체 카탈로그는 13개다.
- 기존 ID `beatmaker_4x4`는 Lo-fi 프리셋으로 유지한다. 신규 ID는 `beatmaker_neon_4x4`, `beatmaker_arcade_4x4`다.
- 카드를 선택해 적용하면 해당 키트의 드럼 패드를 채운다. 같은 키트의 멜로디 페이지가 없으면 최대 페이지 수 안에서 추가한다. 이미 편집한 같은 키트의 멜로디와 다른 키트·사용자 페이지는 보존한다.
- 새 덱 미리보기의 제목과 카드 이름·상세 설명에서 선택 키트를 확인한다. 기존 덱에 적용할 때 사용자의 덱 이름은 유지한다.
- Studio의 키트·연주 종류 선택과 기존 음원·키보드 연주 계약은 유지한다. 번들 19개 로케일에 카드 이름과 상세 문구를 제공하고 canonical 형식을 유지한다.

## 검증

- 갤러리에서 세 카드를 각각 선택한 요청이 선택 키트의 드럼·멜로디 음원으로 적용되는지 검사한다.
- 기존 배열, 페이지 교체·추가, 같은 키트 중복 생성 방지, 다른 키트와 사용자 페이지 보존, 최대 12페이지 제한, Studio 초안·실행 취소를 확인한다.
- 모델/기존 배열 51개, 렌더/위젯/키보드/테마 149개, 갤러리/Studio/키트 UI 74개(36 subtests), i18n 15개, 인코딩 12개를 합쳐 고유 **301 tests / 36 subtests**를 통과했다. 변경 Python 파일 Ruff와 전체 `git diff --check`도 통과했다.
- 첫 구현에서 개별 카드의 sizeHint만 늘리면 `uniformItemSizes`가 일반 배열의 단일 줄 크기를 재사용해 키트 이름이 잘릴 수 있었다. 기본 카드 모두에 같은 셀 크기를 지정하고 비트메이커 캡션을 두 줄로 분리해 해결했다. 1000px·1300px에서 세 카드의 전체 이름과 viewport 노출을 검사하고 캡처를 확인했다.
- 캡처: `artifacts/keydeck-beatmaker-gallery-20261020/gallery-1000.png`, `gallery-1300.png`.
- 검증은 임시 INI 설정·offscreen Qt·모의 오디오로 진행했다. 개인 DB·실사용 QSettings·실행 앱 재시작·빌드·Store 배포는 수행하지 않았다.
