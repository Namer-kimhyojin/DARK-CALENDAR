# 위젯별 디자인 10종 추가 — 2026-11-01

시계·날짜·D-Day·스톱워치·카운트다운·텍스트·날씨·KeyDeck 각각에 추가 디자인 10종을 구현했다. 총 80개 신규 ID이며, 기존 Pure Air / Soft Object / Air Instrument 3종과 함께 각 위젯에서 13종을 선택한다. 개발 소스 변경이며 기존 공개 패키지·설치본·Store는 이번 작업에서 교체하지 않았다.

## 사용법

1. 위젯을 오른쪽 클릭하고 **그래픽 컬렉션**을 연다.
2. 갤러리를 스크롤해 전용 디자인을 고른다. 현재 선택한 항목은 대화상자를 다시 열면 해당 위치로 스크롤된다.
3. 하단에서 움직임·대비 보정·적용 범위를 선택하고 **적용**한다. 적용 옵션과 버튼은 갤러리 밖에 고정된다.
4. **표시 중인 위젯 전체에 적용**은 다른 위젯에도 같은 계열의 전용 디자인을 적용한다. 예를 들어 시계의 아이스 글라스를 고르면 날씨는 클라우드 글라스, 텍스트는 프로스트 노트, KeyDeck은 글레이셔 키캡으로 맞춰진다.

미리보기와 취소는 설정을 쓰지 않는다. **기존 디자인 · 개별 설정 유지**를 적용하면 이전에 컬렉션이 변경한 외관을 조건부로 복원한다. 이후 직접 바꾼 값은 되돌리지 않는다. 원문·목표·위치·크기·폰트·전체 불투명도·키 동작은 보존한다.

## 검증 범위

- 신규 회귀 108건: 등록 수와 ID 중복, 80종의 160/320/480 너비 렌더링, 내용 영역 범위, 원복, 8종 갤러리의 배타 선택·초안 보존, 전체 적용 계열 매핑, 8종 재생성 후 저장 디자인 복원. 날씨 10종은 6시간 예보·최고/최저·큰 카드의 표면 연결과 모서리 투명도도 확인했다.
- `scripts/validate_widget_graphic_collections.py --all-designs`: 8종 × 10개 실제 화면, 선택 대화상자, Windows DPR 1.0/2.0 렌더링. 각 실행에서 원래 사용자 QSettings 보존과 날씨 네트워크 요청 0건을 확인했다.
- 확대 회귀 최종 결과: **38개 파일, 1,449건, 실패·오류·건너뜀 0건**, 모든 프로세스 종료 코드 0. 각 파일을 별도 Qt 프로세스·임시 INI·임시 LOCALAPPDATA로 실행했다. 결과는 `artifacts/widget-designs-20261101/regressions/results.json`과 각 파일의 JUnit XML·로그에서 확인한다.
- Ruff, 인코딩 가드, 변경 이력 누락 검사와 공백 오류 검사를 수행한다. 제품 버전을 올리거나 공개 파일을 교체하지 않는다.
- 한국어·영어 디자인 이름을 정의하고 19개 로케일에 키를 추가했다. 나머지 언어의 새 항목은 영어로 제공한다. 실제 공급자 응답·설치본·Store·장시간 CPU/배터리 사용은 이번 검증에 포함하지 않는다.

핵심 구현: `widget_graphic_catalog.py`의 종류별 카탈로그, `widget_graphic_layouts.py`의 네이티브 배치, 기존 컬렉션의 선택·원복·캐시·움직임 정책을 재사용한다. 신규 상시 타이머·네트워크·DB 스키마·외부 의존성은 추가하지 않는다.
