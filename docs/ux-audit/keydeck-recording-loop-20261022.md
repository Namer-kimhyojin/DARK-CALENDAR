# 비트메이커 연주·녹음·반복 재생

2026-10-22 개발 소스에 반영. 제품 버전은 배포 범위 확정 전까지 4.7.1을 유지한다.

## 사용자 흐름

1. KeyDeck 스튜디오의 비트메이커 행 또는 오른쪽 덱 설정에서 **연주·녹음**을 연다.
   바탕화면 위젯에서는 **우클릭 → 비트메이커 → 연주·녹음**으로 연다.
2. `1234 / QWER / ASDF / ZXCV` 또는 마우스로 패드를 연주한다.
   기존 설정창의 이름·작은 글자 입력은 텍스트 편집이며 소리를 내지 않는다.
3. **녹음**을 누르고 연주한 뒤 **정지**한다. 첫 패드부터 기록하며 정지까지의 쉼도 포함한다.
   연주 종류 목록으로 드럼·멜로디 페이지를 바꾸면서 같은 녹음에 기록할 수 있다.
4. **반복 재생**을 선택하고 **재생**한다. 해제한 상태에서 시작하면 한 번 재생한다.
   재생음은 다시 녹음되지 않는다. 재생 중 직접 연주한 소리는 함께 들을 수 있다.
5. 마지막 녹음 1개를 보관한다. 교체·삭제는 확인을 받으며 빈 녹음 시도는 이전 녹음을 유지한다.
   스튜디오에서는 연주창을 닫은 뒤 **적용**해야 저장된다. 실행 취소/다시 실행도 지원한다.
   바탕화면 위젯에서 연주창을 닫으면 해당 인스턴스에 녹음·음량을 저장한다.

## 저장·실행 계약

- 마이크 또는 시스템 출력 캡처가 아닌 **패드 음원·음량·타이밍 녹음**이다. WAV 내보내기는 포함하지 않는다.
- `deck.beatmaker_recording`은 선택적인 version 1 데이터다. 기존 덱에 필드를 강제로 추가하지 않는다.
  `duration_ms`와 `events[{at_ms,sound,sound_path,volume,key_id}]`만 정규화한다.
- 최대 5분·4,096타, 최소 반복 길이 100ms. 잘못된 버전·순서·수치·경로는 녹음 전체를 거부하고
  나머지 덱 설정은 유지한다. 읽기·정규화가 원본 객체나 사용자 설정을 쓰지 않는다.
- 음원 ID와 개별 음량을 녹음 시점에 보관한다. 키트·패드 동작 변경 후에도 녹음한 소리를 재생한다.
  전체 음량·음소거는 현재 설정을 적용하며 Windows 전체 출력 음량은 변경하지 않는다.
- `.keydeck` **덱 전체** 공유는 사용자 WAV를 녹음과 함께 내장/복원한다. 페이지 공유는 수신 덱의
  기존 녹음을 유지한다. 파일이 사라졌거나 음소거·0%이면 화면에서 안내한다.
- 재생은 음원 경로로만 전달하며 앱 실행·단축키·붙여넣기 동작을 호출하지 않는다. 가져온 녹음을 자동 재생하지 않는다.
- 전용 창만 키보드 포커스를 받는다. 기존 런처 위젯의 `WindowDoesNotAcceptFocus`와 Studio 입력 동작을 유지한다.
- 단조 시계 기준 절대 시각으로 반복해 누적 지연을 피한다. UI가 오래 중단되면 오래된 타격을 건너뛰어
  재개 시 폭발적으로 소리가 재생되지 않게 한다. Qt 타이머 기반이며 오디오 장치 수준의 정밀 시퀀서는 아니다.
- 정지·Esc·창 닫기·숨김·앱 종료 시 타이머와 활성 소리를 정리한다. 확인창이 열린 도중 닫힌 경우도 재시작하지 않는다.

## 검증

- 신규 도메인·UI 검증 및 격리 화면 QA: `artifacts/keydeck-recording-20261022/new-tests.xml`.
- 기존 오디오·비트메이커: `audio-regressions.xml` 364건, 기존 덱·공유·스튜디오·크기 조절: `widget-regressions.xml` 434건 통과.
- 실제 Qt 키 입력/마우스·동시 타격·자동 반복 억제·루프 드리프트·한도·중단 복구·빈 녹음 보존·확인창 종료·
  인스턴스 INI 저장/재로드·사용자 WAV 공유·스튜디오 실행 취소를 검증했다.
- 임시 QSettings/DB와 차단된 외부 네트워크를 사용하는 격리 실행. 오디오는 모의 플레이어/네이티브 API 회귀 검사로 검증했다.
  실제 스피커 청취·설치된 Store 앱의 실행·새 패키지 배포는 이 검사에 포함하지 않는다.
- 한국어·영어 문구와 19개 번들 로케일의 동일 키/placeholder 구조를 제공한다. 나머지 17개 언어의 신규 문구는 영어 fallback이다.
- 화면: `performance-ready.png`, `performance-loop.png`, `performance-compact.png`(520px 폭), `studio-entry.png`.
  재생 직후 상태/버튼이 즉시 전환되는지도 확인했다.
