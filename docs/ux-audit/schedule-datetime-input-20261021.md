# 일정·업무 날짜와 시간 입력 개선 (2026-10-21)

## 적용 범위

- 일정 생성/수정: 기존 숫자 직접 입력과 5분 증감을 유지하면서 30분 간격 시간 목록 추가. Alt+Down/F4로 열고 Enter로 선택, Esc로 취소한다.
- 같은 날은 날짜를 한 번만 표시한다. `여러 날`을 선택하면 종료일을 펼친다. 기존 여러 날 일정은 원래 날짜로 열리고, 자동 종료가 자정을 넘으면 종료일을 표시한다. 자동 확장된 기간이 다시 같은 날이 되면 접는다. 사용자가 명시적으로 펼친 날짜는 유지한다.
- 종료 목록은 소요 시간과 `다음 날`/날짜 차이를 함께 표시한다. 여러 날 일정에서 종료 시각을 골라도 선택한 종료 날짜를 보존한다. 직접 입력한 정확한 분 값은 반올림하지 않는다.
- 일정 길이: 15분/30분/1시간/2시간, 더 보기에는 기존 3시간/6시간. 누적 증가가 아니라 시작 기준 전체 길이 설정이다.
- 지시/협조의 마감기한 및 일반업무 생성/수정에도 공통 시간 목록, 입력 높이, 날짜/시간 행과 접근성 이름을 적용한다. 반복업무의 날짜 중심 설정과 기존 빠른 선택은 유지한다.
- 한국어 요일은 Qt 로케일로 표시한다. 단일 일반업무에서 잘못 표시되던 `반복 종료`를 `날짜`로 정리했다.
- 19개 번들 로케일에 공통 입력 문구 14개를 추가했다.

## 함께 해결한 회귀 위험

- `TimePickerWidget`이 Qt 기본 `timeChanged`를 재정의해 실제 시각 변경을 전달하지 않던 문제를 수정했다. 기본 시그널을 사용해 직접 입력/빠른 선택 후 종료 자동 유지가 갱신된다.
- 기존 데이터 로딩 중 날짜/시간 신호가 중간값에 반응하지 않게 하고, 종료 목록 선택은 날짜와 시간을 함께 반영한다.
- 직접 지정한 7분 같은 짧은 일정도 시작을 옮길 때 길이를 유지한다.
- 좁은 창은 날짜/시간 열을 세로로 배치하고 일정 길이 버튼을 두 줄로 배치한다. 기존 스크롤을 통해 나머지 항목에 접근한다.

## 검증

- 자동 테스트 150개 통과, 추가 하위 검사 15개 통과. 실패/오류/건너뜀 0.
  - 주요 흐름/저장/위젯 94개 + 하위 검사 15개.
  - 기존 공통 편집기 29개.
  - 인코딩 정책/유틸/번역 구조·런타임 27개.
- 새 회귀 36개: 시간 목록 13, 일정 흐름 12, 지시/협조 6, 일반업무 5.
- 실제 다이얼로그 라우터의 생성/수정과 드롭 처리 경로의 이동/복사를 격리 SQLite에서 확인했다. 일정 길이, 종일 포함 일수, 정확한 분, ID와 calendar_id 보존, 반복 메타데이터를 확인했다.
- 인코딩 가드, 변경 파일 Ruff/포맷, diff 공백 검사 통과.
- 별도 QSettings/LOCALAPPDATA/공유 DB 경로와 샘플 데이터로 Qt offscreen 화면을 렌더링했다. 밝은/어두운 화면, 560px 일정 창, 일반업무 생성/수정, 지시/협조, 종일/자정 넘김 및 시간 팝업을 확인했다.
- 최종 자동 확장/접기 보완 후 일정 관련 28개를 재검증했다(위 집계와 중복).

증거: `artifacts/schedule-datetime-ux-20261021/`의 JUnit XML과 PNG.

## 확인 범위

개발 코드와 격리된 Qt 화면 검증이다. 실제 사용자 DB/계정/설정은 변경하지 않았다. 실제 Windows 배율별 조작, 설치된 Store 앱, 패키지 빌드/배포는 이번 작업 범위에 포함하지 않았다. 제품 버전은 4.6.9를 유지하고 변경 이력만 등록한다.
