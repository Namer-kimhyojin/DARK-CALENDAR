# 위젯 프리셋 진행 경과 및 보완 — 2026-10-07

## 반영 결과

내용 프리셋 76개와 7종 위젯의 기본 모양을 점검하고, 오류와 비교 화면을 보완했다.
이름·번역 키·프리셋 개수 및 사용자 프리셋 저장 계약은 유지했다.

| 위젯 | 내용 프리셋 | 주요 보완 |
|---|---:|---|
| 시계 | 8 | 오전·오후와 12시간 형식, 한국어 요일, 기본 retro 표시 |
| 스톱워치 | 8 | 소수 중복, 숫자 자릿수·분리자 크기, 색상과 상태 아이콘 |
| 카운트다운 | 7 | 목표 미설정·손상값 표시, 자릿수·분리자, 목표 시간 형식 |
| D-Day | 8 | art 검증, 그림 크기, 날짜·이름, 미설정 표시, Compact 줄바꿈 |
| 날짜 카드 | 13 | art 검증·비율, 요일·월 지역화, 내일 날짜에 오늘 요일이 섞이던 표시 |
| 텍스트 | 12 | 스타일이 붙은 변수 치환·갱신, HTML 문자 표시, 위젯 참조와 시간대 예외 |
| 날씨 | 20 | 깨지는 문자·단위, 미리보기 크기 문맥과 썸네일 렌더러 호환 |

KeyDeck의 배치·테마는 별도 카탈로그이며 이번 회귀 검사에 기존 테마 목록·갤러리·배치·렌더링을 포함했다.

## 미진 사항으로 발견해 추가 수정한 부분

- D-Day 기본 `{art}`는 실제 렌더러에 있지만 검사기가 거부하여 미리보기가 차단됐다.
- 텍스트의 `{task_count|size=32}` 같은 스타일 변수는 그대로 남거나 자동 갱신 대상에서 빠졌다.
- 시계의 분리된 `%I`·`%p`는 실제 12시간 값을 만들지 못했다. 일반 요일·월도 C 로케일 문자열을 사용했다.
- 스톱워치 소수 프리셋의 소수점 중복·작은 분리자·지원되지 않는 상태 아이콘을 보완했다.
- 일러스트는 기준 24pt에 맞춰 글자와 함께 조정한다. 그림 없는 팩은 그림 전용 빈 행을 제거한다.
- 미설정 카운트다운·D-Day는 완료된 `0`처럼 보이지 않게 한다. 기존 숫자 조건 판단 계약은 유지한다.
- 사용자 이름·일정 제목·사용자 정의 변수의 `<`, `&` 등을 HTML로 해석하지 않는다.
- 손상되거나 극단적으로 큰 크기·줄 간격은 렌더러에서도 방어한다. 숫자 연산의 infinity·overflow로 타이머가 중단되지 않는다.
- 고급 설정 프리셋 목록에 실제 모양 썸네일을 제공하고 저장·수정·이름 변경·삭제를 한 행에 배치했다.
- 공통 입력창의 높이 제한으로 썸네일이 잘리는 문제를 해당 콤보박스에만 보완했다.
- 오류 위치와 원인을 줄바꿈 가능한 일반 텍스트로 안내하며 예외가 발생해도 편집 화면을 유지한다.
- 밝은 설정창에서는 위젯 배경과 공통 데스크톱 샘플을 합성해 흰 글자의 가독성을 확보했다.
- 명시적으로 비운 템플릿은 기본 표시 모드로 전환한다. 새 위젯의 설정 키가 없는 경우만 기본 템플릿을 제공한다.
- 날씨의 개별 미리보기 메서드도 공통 `base_size` 계약을 따르며 아이콘과 글자를 같은 기준으로 조정한다.
- 날씨의 오래된 프리셋 이름 9개에 누락된 번들 번역 키를 추가하여 한국어 표시를 통일했다.
- 일러스트 설정 초안은 미리보기에서만 읽는다. 확인·취소·예외 후 필드 참조와 미리보기 타이머를 해제하여 실제 위젯에 취소한 값이 남지 않게 했다.

## 검증

아래 네 보고서의 테스트 ID를 합쳐 중복을 제거한 **1,022개가 통과**했다. 실패·오류·건너뜀은 없다.
추가 인코딩 정책·유틸 검사 12개와 compileall, 수정 범위 Ruff, diff 검사를 통과했다.

보고서는 `artifacts/widget-presets-audit-20261006/`에 저장했다. 썸네일 검사는 76개 전부를 실제 렌더러로 생성하고 설정 변경이 없는지 검사한다.
그림·텍스트 크기 문맥, 공백 있는 변수·조건식, 미설정·손상값, 한국어·영어, 큰 크기값을 포함한다.
초기 디자인 검사에서 발견한 번역 파일 canonical 저장 형식 실패는 공식 serializer로 수정한 뒤 전체 디자인 검사를 재실행해 해결했다.
19개 번들 언어의 키·구조·placeholder는 일치한다. 신규 오류 안내는 한국어·영어로 제공하며 나머지 17개 언어는 영어 fallback이다.

실제 QLabel·레이아웃·외관 코드로 83개 모양을 100%와 150%에서 각각 렌더링했다.
최종 보고서에서 미치환 변수·색상 별칭은 0건이다. 기본 D-Day 설정창과 드롭다운은
Windows Qt에서 어두운 테마 100%·150%, 밝은 테마 100%로 확인했다.
날씨 설정창은 밝음·어두움과 100%·150% 네 조합에서 20개 썸네일 및 프리셋 선택 미리보기를 확인했다.
사용자 QSettings는 모든 생성자를 앱 모듈 import 전에 격리했고 원본 설정이 같음을 확인했다.
미리보기 취소도 위젯 설정을 변경하지 않는다.
