# 공통 디자인 정밀 재검토

2026-11-05, 개발 소스 4.9.2 기준. 이전 점검의 통과 판정을 그대로 사용하지 않고 현재 코드에서 실제 Qt 화면을 새로 실행했다. 공통 스타일이 연결되어 있어도 일부 전용 스타일과 기본 Qt 팔레트가 이를 덮는 문제가 남아 있었다. 확인한 가독성·배치·설정 반영 문제를 수정하고 같은 조건으로 다시 검토했다.

## 검토 과정과 결과

| 단계 | 사용자 흐름 | 검토 결과 |
| --- | --- | --- |
| 1 | 메인 달력 → 일정 입력·수정 → 기본 확인창 | 네이비·라일락 계층과 기존 입력 기능 유지. 본문 크기 토큰과 부분 색상 전달을 보완했다. |
| 2 | 외관 설정 → 밝음·어두움·사용자 색상 → 고급 토큰·글꼴 | 선택 글자 대비, 초기 프리셋, 실제 글꼴 미리보기, 시스템 자동 테마의 배경·강조색 조합을 수정했다. |
| 3 | 체크리스트·업무 관리 → 반복 설정·도움말·인쇄 | 흰 교차 행, 어두운 아이콘, 읽기 어려운 키 표시, 인쇄 배경, 반복 날짜 누락, 작은 화면의 버튼 잘림과 하단 버튼 스타일을 수정했다. |
| 4 | 일정 알람 → 긴 내용 스크롤 → 집중 전환·기록 | 긴 제목·장소를 끝까지 읽을 수 있게 했고, 버튼 대비와 알림 초기 불투명도, 열려 있는 집중 기록창의 자동 테마 전환을 보완했다. |

캘린더 연결 설정은 Google의 각 메뉴, 관리 허브 탭, Outlook·CalDAV·ICS를 네이비·밝음·사용자 색상과 작은 화면에서 다시 수집했다. 대표 상태에서 제목·카드·입력·버튼의 계층과 스크롤 중 닫기 접근을 확인했다. 위젯 관리자·꾸미기·라벨·이모지·실행창도 새로 렌더링했다. 기존 독립 위젯 스킨, 저장된 배치와 사용자 색상·투명도는 유지한다.

## 확인한 문제와 보완

P1은 실제 내용을 읽거나 동작을 이용하는 데 지장을 준 항목, P2는 일관성·설정 반영·조작 명료성의 결함으로 분류했다.

| 항목 | 확인된 문제 | 보완 결과 |
| --- | --- | --- |
| P1 · 선택 글자 | 밝은 배경에서 테두리 색상만 바꾸면 선택 목록·탭 글자가 밝은 노랑으로 변했다. | 관련 원인 토큰이 바뀔 때만 파생 색상을 갱신한다. 목록 대비 1.01:1 → 17.64:1, 탭 1.19:1 → 17.23:1. |
| P2 · 강조 버튼 | RGBA나 부분 배경값을 주면 이전 흰 글자가 남았다. 알람도 공통 창과 다른 대비 알고리즘을 사용했다. | 실제 바탕과 합성한 색으로 글자·테두리를 파생한다. RGBA 노랑 버튼 1.07:1 → 17.33:1. 알람의 문제 라일락 사례는 3.74:1 → 4.97:1. 명시적 사용자 글자색은 유지한다. |
| P1 · 자동 테마 조합 | 시스템이 밝음이어도 공통 API가 저장된 어두운 배경을 명시값으로 전달해 밝은 글자 모드와 어두운 바탕을 섞었다. | 미지정 색상은 공통 테마 스냅샷이 밝음·어두움 가족 색상 쌍으로 결정한다. 설정을 다시 저장하지 않는다. |
| P2 · 열린 집중 기록 | 시스템 테마 전환 후 메인은 밝아졌지만 열린 기록창은 이전 스타일이었다. | 실제 라우터의 모달 실행에서 테마 갱신을 확인했다. 기록 행·ID·선택을 유지하며 스타일만 갱신한다. |
| P1 · 체크리스트 표 | 교차 행의 기본 Qt 바탕이 흰색인데 글자는 밝은 색이라 두 번째·네 번째 행을 읽기 어려웠다. | 공통 표·목록·트리의 일반/교차 표면을 모드별 토큰으로 지정했다. Qt 실제 픽셀 검사와 다시 찍은 체크리스트에서 확인했다. |
| P2 · 기본 글자 크기 | 기본 크기를 22로 해도 본문 13px·입력/버튼 14px가 남았다. | 실제 본문·입력·버튼이 22px를 사용한다. 제목·설명과 전용 미리보기 역할은 별도로 유지한다. |
| P2 · 글꼴 미리보기 | Courier New 24pt·Times New Roman 18pt를 골라도 Segoe UI 13px가 남고 큰 글자 영역도 잘렸다. | 선택한 가족·크기·굵기·스타일을 명시하고 내용 높이를 확보했다. 다른 두 글꼴·크기의 실제 렌더링을 확인했다. |
| P2 · 반복 미리보기 | 흰 글자/연녹색 글자가 라일락 위에서 흐렸고 ‘다음:’ 뒤 날짜가 없었다. | 중립 글자와 부드러운 강조 표면을 사용하고, 접두사/날짜 템플릿 모두 실제 다음 날짜를 표시한다. |
| P2 · 고급 프리셋 | 처음 열면 색상 프리셋 목록이 비어 있었다. | 초기 모드와 현재 드래프트에 맞는 목록·설명을 즉시 채운다. |
| P2 · 인쇄 설정 | 어두운 카드 사이에 Qt 기본 밝은 스크롤 바탕이 노출됐다. | 본문과 뷰포트의 기본 자동 채우기를 제거했다. |
| P2 · 도움말 | 밝은 배경의 키보드 단축키 표시에 연한 파랑 글자가 고정됐다. | 현재 테마의 글자·테두리·키 표면을 사용하며 HTML 이스케이프는 유지한다. |
| P2 · 체크리스트 아이콘 | 어두운 도구 버튼의 아이콘이 검정이었다. | 실제 버튼 글자 역할에 맞는 중립·위험 색상을 사용한다. |
| P2 · 작은 관리창 | 1024×768에서 하단 한 줄 작업 버튼이 눌리고 글자가 잘렸다. | 작업 도구를 두 줄로 배치해 라벨과 동작 접근을 유지했다. |
| P2 · 저장/닫기 영역 | 라벨·체크리스트에서 공통 footer 뒤의 오래된 개별 스타일이 버튼 크기·채움을 덮었다. | 실제 모달 footer는 공통 강조/보조 역할과 크기를 사용한다. 맥락 작업 도구는 작은 크기를 유지한다. |
| P1 · 긴 알람 | 유효한 200자 제목과 긴 장소에서 대부분의 글자가 잘리고 전체를 볼 방법이 없었다. | 본문만 스크롤하고 헤더·동작을 고정했다. 좁은 320px 창에서도 마지막 장소까지 접근한다. |
| P2 · 집중 전환 알림 | 초기 효과 불투명도 0.7에서 표시하다가 페이드 시작 때 1.0으로 잠깐 밝아졌다. | 처음부터 1.0이며 기존 3초 표시·800ms 페이드·참조 해제를 유지한다. |

## 검사와 범위

- 임시 SQLite·INI·공유 DB를 사용하는 격리 실행이다. 외부 통신과 Python 레지스트리 쓰기를 차단했다. 최종 캡처와 검사에서 사용자 설정의 읽기 비교에 차이가 없었다.
- 공통 색상·글자·자동 테마, 실제 표 픽셀, 프리셋·도움말·인쇄·관리·반복, 큰 글꼴, 긴 알람, 타이머·신호·완료 결과, 생성·수정·이동·복사 관련 회귀 검사를 실행했다. 저장한 XML은 [이번 검토 폴더](../../artifacts/dialog-consistency-audit-20261105/)에 있다. 서로 겹치는 검사 수를 합산하지 않는다.
- 변경한 소스의 Ruff, 인코딩 정책·컴파일 검사를 통과했다. 변경 이력은 제품 번호를 올리지 않고 작업 범위만 등록했다. 전체 저장소 294개 테스트 파일을 하나의 프로세스에서 모두 통과했다고 주장하는 결과는 아니다.
- 선언된 59개 다이얼로그가 공통 기반에 연결된다는 정적 근거와, 이 보고서에서 실제로 본 실행 상태를 구분했다. 수집한 모든 탭 상태나 모든 사용자 드래프트 조합을 직접 조작해 검토한 것은 아니다.

## 남은 확인 범위

실행 중인 Windows 앱 연결 도구가 응답하지 않아 사용자 창을 직접 조작한 검토는 완료하지 못했다. 위 근거는 현재 제품 소스의 실제 Qt 클라이언트 렌더링이며, 이전 캐시 화면이나 그림으로 대체하지 않았다.

Google 숫자 입력의 플랫폼 화살표가 offscreen에서 빈 영역처럼 보이는 상태는 [해당 화면](../../artifacts/dialog-consistency-audit-20261105/notifications-providers/providers-expanded-after/light-google-tab-2.png)에 보관했다. 실제 Windows에서도 재현되는 결함인지 추가 확인이 필요하다. 물리적 여러 모니터·DPI, 바탕화면 투명 합성, OS 제목 표시줄·시스템 토스트, 화면 읽기 프로그램 전체 조합은 이번 검사 범위가 아니다.

일반 재사용 다이얼로그는 테마 재적용 시 `keep_existing_stylesheet=False`를 쓰는 기존 갱신 계약을 따른다. 실제로 재현한 집중 기록창은 보완했으며, 모든 특수 창의 열림 중 시스템 전환을 일괄 검증한 결과로 확대하지 않는다. 확인한 기능·설정·데이터를 유지한 상태에서 보완했고, 설치 패키지 빌드·배포는 수행하지 않았다.
