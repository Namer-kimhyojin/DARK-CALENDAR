# 캘린더 중복 표시 점검 — 2026-10-07

## 첨부 화면의 확인 결과

같은 공휴일이 로컬 저장 일정과 Google의 `대한민국의 휴일`에서 각각 표시되고 있다.

| 날짜 | 제목 | 로컬 저장 | Google 공휴일 |
|---|---|---:|---:|
| 2026-10-05 | 쉬는 날 개천절 | 1개 | 1개 |
| 2026-10-09 | 한글날 | 1개 | 1개 |

로컬 두 항목은 소속 캘린더가 지정되지 않은 `local_owned`이며 Google 이벤트 연결이 없다.
Google 두 항목은 `대한민국의 휴일`의 `remote_mirror`이며 각기 고유한 Google 이벤트 ID를 갖는다.
해당 캘린더는 `is_active=0`(가져오기 중지), `is_visible=1`(화면 표시)이므로 이미 저장된 일정은 계속 보인다.
`기본` 로컬 캘린더와 `이차전지산업팀`은 숨김 상태이며, 무소속 로컬 공휴일은 이 두 캘린더에 속하지 않는다.

한 출처만 보려면 캘린더 관리에서 `대한민국의 휴일`의 **일정 화면에 표시**를 끄면 된다.
이번 점검에서는 표시 설정이나 저장된 일정을 변경하지 않았다.

## 추가 중복 후보

- 저장 DB 전체에서 동일 Google 이벤트 ID의 복수 저장 그룹은 0개다. 캘린더와 원격 ID를 함께 비교한 그룹도 0개다.
- 같은 캘린더·제목·시작·종료·종일 여부가 일치하는 그룹은 1개다. 로컬 일정끼리의 동일 기준 그룹은 0개다.
- 후보는 `이차전지산업팀`의 `[아카] 5기 교육과정 홍보`(2026-09-15~2026-10-05) 두 항목이다. 서로 다른 Google 이벤트 ID가 저장돼 있고 현재 숨김 상태다. 제목과 기간만으로 의도한 별도 일정인지 판단하지 않았으며 실제 Google의 최신 이벤트 내용은 조회하지 않았다.
- 10월에 시작하는 일정의 동일 제목·기간 그룹은 5개다. 공휴일 4개 그룹은 로컬/Google의 서로 다른 출처이고, `[아카] 5기 교육과정` 그룹도 서로 다른 소속이다.

현재 개발 소스의 기간 조회·월간 렌더에서 동일 DB 행이 두 번 표시되는 경로는 확인되지 않았다.
Google 중복 판정은 캘린더 identity와 이벤트 ID를 사용하며, 등록된 Google 캘린더는 과거 직접 가져오기 경로에서 제외된다.
같은 제목만으로 서로 다른 소속 일정을 합치거나 로컬 일정을 Google 미러로 전환하지 않는다.

## 확인 방법과 범위

기존 개인 앱 데이터 DB와 WAL을 파일 읽기로 연속 두 번 비교한 뒤 안정된 사본에서 SQLite `query_only`를 사용했다.
사본 `quick_check`는 `ok`였고 검사 전후 원본 DB/WAL 바이트의 동일성을 확인했다. 사본 DB와 WAL/SHM은 점검 후 제거했다.
원본 DB, 사용자 설정, 실제 Google 계정에는 쓰기를 수행하지 않았다.

이 결과는 현재 알려진 개인 앱 데이터의 저장 상태와 개발 소스 검토 기준이다. Store 패키지 프로세스·별도 앱 데이터 매핑과 원격 Google의 현재 상태는 검증하지 않았다.
