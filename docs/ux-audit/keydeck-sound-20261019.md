# KeyDeck 전체·개별 효과음 수정 (2026-10-19)

## 원인과 수정

- 전체 소리 켜기/끄기와 음량은 덱 인스펙터 아래쪽에만 있었다. Studio 상단 `전체 효과음`, 위젯 우클릭 `전체 효과음 설정…`을 추가하고 소리 설정을 인스펙터 맨 위에 배치했다.
- 개별 키는 우클릭 `이 키 효과음 설정…`에서 해당 키의 `모양·소리` 탭을 바로 연다. 전체 음소거와 음량 0% 원인을 개별 설정에도 표시한다.
- `DarkCalendar.spec`와 `Standalone.spec`는 Qt Multimedia를 제외하는데 재생기는 그 모듈의 `QSoundEffect`에만 의존했다. 모듈이 없는 배포 경로에는 Windows WinMM PCM WAV 재생기를 연결했다. 기존 빌드 제외 정책은 유지한다.
- Windows 재생기는 파일 읽기·PCM 음량 계산·장치 호출을 전용 작업 스레드에서 수행한다. 소리별 음량과 겹침을 지원하며 유휴 시 큐에서 대기한다. 버퍼는 재생 완료 후 준비 해제하고 종료 시 장치와 캐시를 정리한다.
- 클릭형 스위치의 개별 효과음은 물리 이벤트까지 기다리지 않고 누르는 즉시 한 번 재생한다. 명시적 미리 듣기는 애니메이션·캔버스 표시 상태에 의존하지 않으며 다른 키를 잠시 음소거 해제하지 않는다.

## 설정 계약

- 인스턴스의 `keydeck_data` 안에 덱 전체 `sound`/`sound_path`를 추가한다. 기존 덱의 기본값은 `auto`/빈 경로로 기존 소리를 유지한다.
- 키의 기존 `sound=auto`는 `전체 설정 따름`으로 표시한다. 전체 기본음이 `auto`이면 기존 스위치·키캡·케이스 물리 타건음을 사용한다.
- 개별 키의 `switch`는 전체 기본음과 독립적인 실제 타건음이며, `none`/내장음/`custom`도 개별 지정값을 유지한다.
- 전체 켜기/끄기와 음량은 모든 페이지·개별 키에 적용한다. 미리 듣기는 꺼짐·음량 0%에서도 최소 25%로 재생하며 설정값을 바꾸지 않는다.
- 덱 파일에는 전체 사용자 WAV도 내장한다. 페이지 공유는 복사본의 상속음을 구체화해 사용자 WAV를 함께 내장하고 수신 덱의 전체 설정을 보존한다.
- 내장 효과음은 기존 12종을 보존하고 우드 탭·뱀부 톡·로우 톡·펠트 키·타자기·세라믹 탭·마림바·워터 드롭·디지털 블립·레트로 삡·웜 플럭·더블 탭을 추가해 24종이다. 고정 시드 생성기와 WAV 바이트 재현성을 검사한다.
- 한국어·영어 문구를 추가하고 나머지 번들 언어에는 신규 키의 영어 값을 제공한다.
