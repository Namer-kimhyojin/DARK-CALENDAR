# Night Signal

Night Signal은 어둠을 공백이 아니라 정보가 드러나는 매질로 취급한다. 깊은 청흑색 공간 위에 차가운 청색 신호와 작은 상태 점을 배치해, 중요한 변화만 선명하게 떠오르게 한다. 화면은 장식보다 관찰에 가깝고, 각 요소는 오랜 시간 정밀하게 조정한 마스터 수준의 결과처럼 보여야 한다.

형태는 큰 직사각형 관찰창과 얇은 경계, 제한된 둥근 모서리로 구성한다. 스크린샷은 증거 표본처럼 넓게 호흡하고, 주석은 가장 필요한 지점에만 붙는다. 정렬과 여백은 수없이 반복해 다듬은 듯 정확해야 하며, 시각적 리듬 자체가 문제와 개선의 관계를 설명해야 한다.

색은 거의 검정에 가까운 배경, 안개 낀 회청색 본문, 전기적인 청색 강조로 제한한다. 성공 상태에는 낮은 채도의 녹색을 한 번만 사용한다. 색마다 단 하나의 역할을 부여하고, 전문가가 고통스럽게 보정한 듯 명도 차이와 대비를 세심하게 유지한다.

크기 대비가 위계를 만든다. 실제 화면은 크게, 문제 표식은 중간 크기로, 메타데이터는 속삭이듯 작게 둔다. 텍스트는 짧은 제목과 한 문장 메모만 허용하며 설명문으로 화면을 채우지 않는다. 정보는 문단이 아니라 공간, 스케일, 반복되는 프레임의 차이로 전달한다.

전체 구성은 개선 전의 마찰에서 개선 후의 흐름으로 시선이 자연스럽게 이동해야 한다. 마지막 결과물은 즉흥적인 대시보드가 아니라, 최고의 실무자가 수많은 시간을 들여 완성한 정밀한 관찰 기록처럼 보여야 한다. 모든 간격과 모서리, 이미지 크롭은 의도적이며, 무엇도 겹치거나 캔버스 밖으로 밀려나지 않는다.
