# 위젯 글자 그림자 — 2026-10-06

시계·스톱워치·날짜 카드·카운트다운·D-Day·텍스트·날씨의 글자와 템플릿에 공통 그림자 효과를 추가했다. KeyDeck의 자체 그림자는 유지한다. 소스 변경이며 Store 설치본은 교체하지 않았다.

## 사용 흐름

- 위젯 우클릭 → 외관 → 글자 그림자 사용으로 바로 켜고 끈다.
- 같은 메뉴의 그림자 설정에서 끄기/은은하게/선명하게를 선택하거나 진하기·흐림·거리·색상을 조절한다.
- 일반 위젯 설정의 외관 탭에서도 동일한 조절 UI와 미리보기를 제공한다.
- 미리보기는 설정창 안에서만 바뀐다. 저장할 때 실제 위젯에 적용하고 취소하면 원래 설정을 유지한다.

## 저장과 렌더링

기본값은 꺼짐이다. `text_shadow_*` 다섯 개 키를 기존 인스턴스 설정 프록시로 저장한다. 외관 프리셋과 독립적이며 재시작·복제 시 유지된다. 잘못된 저장 값은 기본값 또는 허용 범위로 처리한다.

배경·테두리·투명 입력 표면 대신 자식 콘텐츠에 효과를 적용한다. 월간 날짜 표의 직접 그리기 경로도 포함한다. 효과 객체를 재사용하고 같은 값은 재설정하지 않으며 별도 타이머를 만들지 않는다. 내부 여백을 확보해 그림자가 창 가장자리에서 잘리지 않도록 한다.

## 검증

- 공통 외관 프리셋·배치·콘텐츠 편의·템플릿·항상 위 표시 회귀 51개 통과 — [JUnit](../../artifacts/widget-shadow-20261006/regression-tests.xml).
- 그림자 전용 검사 26개 통과: 일반 7종, 리치 텍스트 유지, 기존 효과 보존, 효과 재사용, 인스턴스 복원/복제 독립성, 저장·취소, 모양 마스크와 배치 보존, 투명 렌더 차이와 가장자리 잘림 확인 — [그림자·번역 JUnit](../../artifacts/widget-shadow-20261006-tests.xml).
- 19개 로케일에 한국어/영어 안내와 다른 언어의 영어 대체값을 추가하고 기존 번역·레거시 키·현재 dirty 변경을 보존했다. 번역 구조/런타임 검사 15개 통과.
- Windows 네이티브 투명 시계와 오프스크린 렌더, 실제 공통 그림자 설정 UI 검증 — [Windows 결과](../../artifacts/widget-shadow-20261006/results-native.json).
- 검증은 임시 INI 설정으로 수행했고 Windows 사용자 설정의 실행 전후 동일성을 확인했다. 사용자 DB와 동기화 계정은 사용하지 않았다.
- 관련 Ruff, diff 공백 검사와 인코딩 가드 통과. compileall의 기존 접근 불가 pytest 캐시 두 개 경고는 남아 있다.
