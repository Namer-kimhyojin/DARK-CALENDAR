# 날씨 위젯 프리미엄 UI·애니메이션 — 2026-10-31

사용자가 요청한 세 가지 대표 디자인·반응형 정보 배치·시간별 예보·애니메이션·렌더링/요청 최적화를 기존 Air Calendar 안에 통합했다. 기존 24개 디자인과 10개 에셋 팩, 템플릿과 외관·모양·위치·온도 단위·갱신 간격·그림자·원본 사용자 설정을 유지한다. 제품 번호는 변경 이력만 등록하며 배포 버전 예약은 별도로 수행한다.

## 사용 순서

1. 소스 실행 버전에서 날씨 위젯을 우클릭 → **날씨 디자인 고르기…**를 연다.
2. 처음 나오는 **Air Atmosphere / Soft Object / Editorial Mono**를 선택하고 **디자인 적용**을 누른다. `프리미엄 · 애니메이션` 분류에서도 찾을 수 있다.
3. 위젯 가장자리를 드래그해 크기를 조절한다. 작은 카드는 그림·온도·지역, 보통 카드는 날씨 설명·습도·바람, 폭 300px·높이 330px 이상에서는 시간별 예보를 함께 표시한다.
4. 우클릭 → **움직임 (프리미엄)**에서 끔/은은하게/풍부하게를 선택한다. 일반 날씨 설정에서도 움직임·시간별 예보 표시·사용자 애니메이션 폴더를 저장하거나 취소할 수 있다.

기존 위젯에는 새 디자인을 자동 적용하지 않는다. 프리미엄 카드의 템플릿을 직접 편집하거나 원·캡슐·포스터를 선택하면 기존 렌더러로 전환한다. 프리미엄 디자인을 다시 선택하면 카드로 돌아온다.

## 그래픽과 움직임

- Air Atmosphere는 맑음·흐림·비·눈·안개·밤에 따라 하늘 배경을 바꾼다. Soft Object는 밝은 표면과 입체 오브젝트, Editorial Mono는 종이빛 표면과 또렷한 그래픽을 사용한다.
- 기존 내장 날씨 에셋을 재사용한다. 내장 움직임은 구름의 부드러운 이동, 햇빛의 명암, 비·눈·별·안개와 약한 번개 표현이며, 날씨 그림 변경에는 짧은 전환을 적용한다.
- 프레임 타이머는 20fps다. Windows의 애니메이션 끄기와 배터리 절약 모드에서는 멈춘다. 표시 중에는 정책을 60초마다 다시 확인하며, 숨김·비활성화·종료 시 재생과 정책 타이머를 중단한다.
- 사용자 WebP/GIF 파일은 16MiB와 디코딩 픽셀 수를 제한하고, 전체 프레임 캐시를 켜지 않는다. 빠른 사용자 파일은 재생 속도를 낮춘다. 누락·손상 파일은 내장 에셋으로 대체한다.

사용자 폴더에는 아래 이름을 사용한다. 확장자는 `.webp` 또는 `.gif`이며 같은 상태에 두 형식이 있으면 WebP를 먼저 선택한다. 일부 상태만 넣어도 된다.

```text
clear_day          clear_night
partly_cloudy_day  partly_cloudy_night
cloudy             fog
drizzle            rain
heavy_rain         snow
heavy_snow         thunderstorm
hail               unknown
```

## 예보와 성능 처리

- MET Norway의 실제 타임스탬프로 현재에 해당하는 예보와 앞으로 6시간 안의 최대 6개 시점을 선택한다. 위치의 GeoNames 시간대로 시간을 표시하며, 없는 시점을 임의로 만들어 채우지 않는다.
- `남은 오늘`은 같은 현지 날짜의 남은 예보 범위다. 하루 전체의 관측 최고·최저로 표시하지 않는다. 강수량은 다음 1시간 필드가 있을 때만 표시하고, 6시간 합계를 1시간 값으로 나누지 않는다.
- 예보 기준 시각과 서버 갱신 시각을 구분한다. 네트워크 실패·만료 시 이전 예보임을 알리고, 새 위치로 바꾸면 이전 도시의 보조 정보를 비운다.
- 같은 좌표의 원본 요청과 응답을 공유하고 섭씨/화씨는 개별 변환한다. 한 위젯이 닫혀도 다른 위젯의 요청은 유지한다. 캐시 만료와 조건부 요청, 기존 디스크 캐시를 유지한다. 이는 [MET Norway 클라이언트 안내](https://docs.api.met.no/doc/locationforecast/HowTO.html)의 만료·조건부 요청 방식을 따른다.
- 프리미엄 화면은 배경·글자·시간별 예보를 캐시하고 그림 영역만 다시 그린다. 아트 캐시는 표시 크기와 DPR을 구분하고 최대 24MiB로 제한한다. 크기 조절은 HTML 글꼴 이진 탐색을 우회한다.

## 검증과 확인 범위

- 기존 날씨 회귀와 신규 시간대·단위·공유 요청·조건부 응답·취소/객체 종료·설정 보존·사용자 WebP 재생·숨김/절전·부분 갱신 검증을 수행했다.
- 최종 관련 검증은 482건, 실패·오류·건너뛰기 0건이다. 공통 시계의 경계 맞춤 테스트는 통합 실행에서 1px 차이가 발생해 해당 파일 17건을 별도 Qt 프로세스와 임시 INI로 다시 검증했다. 공통 배치 코드는 수정하지 않았고 원래 실행 결과는 `combined-state-variation.xml`, 최종 파일별 결과는 `full-regression.xml`과 `verification-summary.json`에 보존했다.
- 한국어/영어 신규 문구를 추가했다. 나머지 번들 로케일에는 같은 구조의 영어 대체값을 추가했으며, 전체 언어의 신규 번역 완료를 의미하지 않는다.
- `scripts/validate_weather_premium.py`는 모든 QSettings를 임시 INI로 격리하고 실제 사용자 설정이 실행 전후 동일한지 확인한다. 예시 날씨로 렌더링하며 외부 날씨 요청과 사용자 DB 접근을 하지 않는다.
- 캐시 렌더링 시간은 로컬 네이티브 카드 이미지 생성 시간이다. 실제 설치본 CPU·메모리·배터리 소비, 장시간 동작, 실제 날씨 서버 연결·배포·Store 검증과 구분한다.
- Windows 기본 배율과 `QT_SCALE_FACTOR=1.25/1.5/2`에서 별도 프로세스로 그림·글자·배치·설정 보존을 확인했다. 기본 배율의 캐시 렌더링은 중앙값 약 5.8ms·95백분위 약 7.3ms, 200%는 약 10.3ms·11.2ms였다. 측정 부하에 따라 달라지는 단일 PC의 렌더링 수치이며 이전 구현 대비 향상률을 의미하지 않는다. 20fps·60프레임의 움직이는 미리보기를 별도로 저장했다.
