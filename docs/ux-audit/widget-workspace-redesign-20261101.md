# 위젯 전용 모드 스킨·화면 형태 재설계 — 2026-11-01

위젯 전용 모드에서 기존 단일 목록과 색상 선택에 더해 업무 유형을 나란히 비교하고, 목적에 맞는 화면을 빠르게 고를 수 있도록 개선했다. 기존 6종 스킨·5종 배치를 유지하면서 스킨 10종과 화면 형태 6종을 추가했다. 최종 기본 카탈로그는 **스킨 16종·화면 형태 11종**이며 자유 구성과 저장한 배치도 계속 사용한다.

## 추가한 화면 형태

| 화면 | 용도와 구성 |
|---|---|
| 일간 브리핑 | 유형별 항목 수, 주간 날짜 선택, 검색과 선택일 목록 |
| 월간 집중 | 월간 달력과 넓은 선택일 목록 |
| 좌우 플래너 | 왼쪽 월간 달력, 오른쪽 검색·목록, 위쪽 요약 |
| 주간 탐색 | 넓은 주간 날짜 선택과 목록 중심 구성 |
| 일정·업무 보드 | 일정·업무·지시 3개 목록을 병렬 표시. 좁아지면 세로로 배치 |
| 집중 도크 | 날짜·필터·검색·목록을 좁은 세로 창에 집중 |

기존 세로 집중형·좌우 대시보드형·일정 우선형·매거진 보드형·미니멀 리스트형을 유지한다. 선택한 형태는 창을 줄여도 저장된 ID가 바뀌지 않는다. 새 월간 화면은 폭 520px 미만에서 주간 날짜 선택으로 줄여 표시하고 넓히면 월간 달력으로 돌아온다. 좌우 플래너는 폭 700px 미만에서 세로 배치로 전환한다.

## 추가한 스킨과 표면 표현

포슬린, 리넨 페이퍼, 세이지, 아틱 라인, 라일락 글라스, 미드나이트 스튜디오, 그래파이트, 포레스트 저널, 애머시스트, 명확한 대비의 10종을 추가했다. 밝은 계열과 어두운 계열을 각각 5종 제공한다.

스킨은 색상뿐 아니라 부드러운 카드·종이·테두리·글라스·컴팩트 표면을 함께 정의한다. 글라스는 둥근 표면과 색조, 기존 배경 불투명도 설정으로 표현한다. 기존 스킨의 표면 방식은 `legacy` 기본값으로 유지한다. 색상 스킨과 화면 형태는 독립적이며, 기존 글꼴·글자 크기·제목 굵기·글자/배경 불투명도 설정도 유지한다.

스킨 갤러리의 작은 그림은 색상과 표면을 간단히 보여주는 도식이다. 오른쪽 큰 미리보기는 실제 위젯 렌더러로 그린 예시다. 선택된 썸네일은 운영체제의 아이콘 강조색으로 다시 칠해지지 않도록 원래 그림을 제공한다.

## 사용 방법

1. 위젯 전용 창 상단의 **꾸미기**를 연다.
2. **화면 형태**에서 배치를 고른다. **전체 배치 보기**를 누르면 기본 11종을 모두 볼 수 있다. **내 배치**와 **구성 편집**도 그대로 사용한다.
3. **스킨·글꼴**에서 갤러리의 스킨을 고르고 글꼴·크기·불투명도를 조절한다. 미리보기에서는 실제 설정을 쓰지 않는다.
4. **표시 항목**에서 기존 표시 옵션을 조절한 뒤 **적용**한다. **취소**는 원래 설정을 유지한다.
5. 이후 상단의 **보기**에서 화면 형태를 바로 바꿀 수 있다. 좁은 창에서는 더 보기 메뉴의 기존 배치 선택과 꾸미기를 이용한다.
6. 검색창 또는 **Ctrl+F**로 선택한 날짜의 제목·시간을 검색한다. 검색어를 지우면 즉시 목록을 복원한다. 검색어는 설정에 저장하지 않는다.
7. 브리핑·플래너·보드의 항목 수 버튼을 누르면 기존 일정·업무·지시 필터가 적용된다. 숫자의 도움말은 선택한 날짜 전체의 항목 수임을 안내한다.

상단 **보기**에서 기본 화면을 선택하면 자유 구성 보기에서 기본 배치로 전환한다. 저장한 자유 구성 데이터와 사용자 프리셋은 삭제하지 않는다. 창 위치·크기, 달력 접기 상태는 기존 레이아웃별 저장 방식을 따른다.

## 구조와 검증

- `widget_workspace_catalog.py`: 추가 스킨·배치 정의. 기존 등록 API로 발견되며 UI에 개별 항목을 하드코딩하지 않는다.
- `WidgetModeLayout`: 달력 표시 방식·좁은 화면 전환·목록/보드 표현·요약·검색 옵션을 정의한다. 기존 저장 데이터에는 기본값을 적용한다.
- `WidgetModeSkin.surface_style`: 기존 표면 또는 새 표면 표현을 선택한다. 실제 CSS는 `widget_workspace_styles.py`에서 의미 기반 색상 토큰으로 만든다.
- `widget_workspace_ui.py`: 요약과 보드를 담당한다. 보드 목록은 기존 `FreeAgendaPanel`과 `AgendaItemWidget`을 재사용하여 원래 ID·읽기 전용·수정·완료 처리기를 유지한다. 숨겨진 기존 목록을 중복으로 다시 만들지 않는다.
- 검색은 현재 위젯의 캐시된 항목을 120ms로 모아 갱신한다. 별도 DB 조회나 외부 요청을 추가하지 않으며 검색어 지우기는 즉시 반영한다. 숨길 때 검색 타이머를 중단한다.
- 신규 회귀 24건: 6종 화면의 좁은/권장 크기, 선택일 보존, 3개 목록의 원래 수정·완료 호출, 검색과 데이터 보존, 검색 결과 없음, 필터·기존 목록 복귀, 신규 스킨 기본 대비, 꾸미기 취소, 자유 구성 전환을 확인한다.
- 신규 10개 스킨은 기본 불투명도에서 주/보조 글자와 패널, 선택 날짜 글자와 합성 배경의 대비를 4.5:1 이상으로 검사한다. 모든 사용자 불투명도와 바탕화면 조합에 대한 접근성 인증은 아니다.
- 확대 회귀 최종 결과: **31개 파일, 476건, 실패·오류·건너뜀 0건**, 모든 프로세스 종료 코드 0. 파일마다 별도 Qt 프로세스·임시 INI·임시 LOCALAPPDATA로 실행했다. 최종 로그와 JUnit XML은 `artifacts/widget-workspace-20261101/regressions-complete/`에 보관한다. Ruff와 Python 인코딩 가드도 통과했다.
- `scripts/validate_widget_workspace_redesign.py`는 변경 전/후 실제 소스 화면과 16종 스킨을 100%·200% DPR에서 캡처하고 원래 사용자 QSettings가 유지됐는지 비교한다. 테스트는 합성 데이터와 기존 처리기 호출 검증이며 실제 계정·실제 DB 저장·설치본·Store 검증과 구분한다.
- 한국어·영어 문구를 정의하고 19개 로케일에 키를 추가했다. 나머지 언어의 새 문구는 영어로 제공한다.

제품 버전은 이번 구현으로 올리지 않는다. 공개 패키지·Store·설치본은 이번 작업에서 교체하지 않았으며 이후 배포 범위에 포함해 검증한다.

변경 기록 `widget-mode-workspace-redesign-20261101`은 제품 번호 4.8.0을 유지한다. 최종 전역 `scan --strict`에는 이번 범위 밖의 `calendar_sync/repository.py`, `outlook_settings_dialog.py`, `caldav_sync_controller.py`, `calendar_sync_coordinator.py`, `outlook_sync_controller.py` 5개가 미등록으로 표시되었다. 이번 기능의 실행 입력 누락은 없으며, 별도 동기화 작업은 변경하거나 이번 기록에 흡수하지 않았다.
