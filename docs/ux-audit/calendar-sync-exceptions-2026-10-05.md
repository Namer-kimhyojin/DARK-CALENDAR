# 캘린더 동기화 기능·예외 점검 — 2026-10-05

Google·Outlook·iCloud·네이버·ICS 통합 이후, 재현 가능한 일정 손실/덮어쓰기 위험과 오류 복구 문제를 수정했다. 테스트와 앱 실행 검증은 임시 DB·설정 및 모의 서비스로 수행했다. 실제 계정의 인증·원격 저장 및 배포 패키지 검증은 남아 있다.

| 발견 사항 | 사용자 영향 | 수정·재현 근거 |
|---|---|---|
| ICS 일부 DB 저장 실패를 무시하고 나머지 변경·삭제를 커밋 | 일정 누락을 성공으로 표시 | 저장 오류 하나라도 전체 스냅샷 롤백. 이전 일정·성공 시각·다른 미커밋 작업 보존 |
| 유효한 빈 ICS 피드에서 삭제 동작 누락 | 서비스에서 모두 지운 일정이 계속 표시 | 해당 구독의 remote_mirror만 정리. 다른 캘린더/로컬 일정 보존 |

| 원격 변환 중 로컬 이동/선택 해제 또는 오래된 충돌 해결 | 다른 캘린더로 옮긴 일정 덮어쓰기·이전 서비스로 전송 | 저장 직전 내용·캘린더·연결·선택 상태 검증. 이동한 충돌은 적용 거절 |
| 이동을 복구해도 이전 오류 잔존, 삭제 재시도 후 즉시 실행 누락 | 해결했는데 확인 필요 상태 지속 | 내용 일치 시 오류 제거. 선택한 서비스에서 즉시 재시도/내 변경 전송 |
| 종료 후 로그인 결과/오류 수신, 일부 캘린더만 커밋한 뒤 실패 | 계정 설정 변경 또는 새 일정 화면 미반영 | 종료 결과 무시. 부분 실패 시 먼저 저장된 일정도 패널 갱신 |

재현 근거는 `artifacts/sync-exceptions/before-fixes.xml`(초기 13개 실패)과 `lifecycle-before.xml`(후속 12개 실패)에 기록했다. 회귀 테스트 43개를 추가했다. CalDAV 설정 테스트의 모의 충돌 데이터도 실제 서비스 계약에 맞게 일정 ID와 저장된 로컬 캘린더를 포함하도록 보완했다.

검증 결과:

- 동기화 엔진·서비스 응답·ICS 스냅샷: **154개 통과** (`backend-tests.xml`).
- 설정/통합 버튼·워커 생명주기·종료 UI: **166개 통과** (`ui-tests.xml`).
- 일정 생성/수정/이동·Google 전송 대기: **31개 통과** (`task-tests.xml`).
- Google 시작·인증 UX: **7개 통과** (`startup-tests.xml`, 별도 프로세스).
- 인코딩·동기화 번역·기타 언어 검사: **38개 통과, 1개 기존 실패** (`policy-tests.xml`). 실패는 17개 언어의 기존 날씨 키 9개 누락이다. 동기화 키 누락은 없다. 이 작업에서는 진행 중인 다른 날씨 변경을 수정하지 않았다.
- 합계 **396개 통과, 1개 기존 번역 실패**. 파일/중간 재실행의 중복 결과는 합산하지 않았다.
- 인코딩 가드, 변경 파일 Ruff, diff 공백 검사 통과. compileall에서는 기존 접근 불가 pytest 캐시 폴더 두 개에 경고가 있었다.
- 실제 OverlayApp을 임시 데이터로 생성해 Google 비활성화 상태에서 iCloud 공통 버튼 전달, 통합 캘린더 목록 및 정상 워커 종료 확인 (`smoke-results.json`).

전체 프로그램이나 모든 외부 서비스를 오류 없이 검증했다고 보지는 않는다. 실제 Outlook 앱 등록·계정, iCloud/네이버 연결 호환성, 재시작 후 인증 복구 및 패키지·Store 설치판 검증은 후속 항목이다. 네이버와 권한 없는 캘린더는 읽기 전용을 유지했다. CalDAV 증분 조회와 서버 URL 변경 시 UID 재연결은 기존 후속 계획이다. 이번 작업은 개발 폴더에 적용했으며 릴리스·Store 제출·설치 업데이트는 수행하지 않았다.

## 후속 확인에 따른 정정

같은 날 후속 점검에서 이전 앱 실행 스크립트의 QSettings 격리 오류를 발견했다. 앱 DB는 임시 경로였으나 Windows 실제 앱 설정에 테스트 값이 기록되었다. 따라서 위 앱 실행 검증의 설정 격리 주장은 정정한다. 알려진 임시 iCloud 식별자를 제거했고 기존 스크립트도 안전한 명시적 INI 실행으로 교체했다. 사전 원본이 없는 표시·Google 설정은 임의 복원하지 않았다. [후속 기록](calendar-sync-followup-2026-10-05.md)에 영향과 복구 범위를 명시했다.

후속 작업에서 날씨 번역 누락, ETag 변경분 다운로드 및 UID 주소 복구도 보완했다. 이 기록의 검사 수는 당시 결과이며 최종 후속 검증은 419개 통과다.
