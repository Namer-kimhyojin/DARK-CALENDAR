# 주간 시간표 일정 관리 구현·검증

검증일: 2026-10-07. 사용자 요청과 첨부한 Todoist 화면·영상의 시간표, 드래그 이동, 기간 조절을 기준으로 구현했다.

## 사용 방법과 범위

- 주간보기(1주)에 시간표를 기본 표시한다. 상단 **시간표** 버튼으로 기존 날짜별 보기와 전환하고 설정을 저장한다.
- 요일·종일 영역을 고정하고, 00:00~24:00 시간표는 세로로 스크롤한다. 마지막 스크롤 위치를 복원한다.
- 빈 시간을 클릭하면 15분 일정의 기존 생성창을 연다. 빈 영역을 드래그하면 선택한 시작·종료 시간을 생성창에 채운다.
- 일정 블록을 드래그하면 날짜·시간을 이동하고, 아래 가장자리를 드래그하면 종료 시간을 조절한다. 15분 간격을 사용한다.
- 종일 일정은 시간표로 드래그하면 15분 시간 일정으로 바뀌며, 이후 길이를 조절할 수 있다.
- 겹치는 일정은 나란히 배치한다. 좁은 블록에는 시작 시간을 표시하고 마우스 안내에 전체 시간 범위를 표시한다.
- 여러 날에 걸친 시간 일정은 날짜별로 나누어 표시한다. 이동은 원래 전체 기간을 유지하고 마지막 구간에서 종료 시간을 조절한다. 기존 짧은 일정과 초 단위 기간도 이동 시 유지한다.
- 일정 클릭, Enter, 우클릭 메뉴는 기존 편집창을 연다. 방향키로 일정을 선택하고 Esc로 드래그를 취소한다. 창 비활성화·화면 제거도 진행 중 제스처를 취소한다.
- 읽기 전용·ICS 일정은 상세 조회만 허용한다. 반복 일정의 직접 이동·길이 조절은 차단하고 기존 상세 편집 흐름을 사용한다.
- 검색, 캘린더 표시 여부, 주말 숨김, 월요일·일요일 시작, 캘린더 색상을 기존 데이터 흐름에서 이어받는다. 시간표에서는 지원하지 않는 Ctrl 다중 선택 안내를 숨긴다.
- 월간 및 2·3주 보기의 기존 날짜별 렌더러는 유지한다.

## 저장과 통합

- `week_time_grid.py`는 화면·포인터·키보드 처리와 요청 신호를 담당한다. 원본 일정 딕셔너리를 변경하지 않는다.
- `week_planner_usecases.py`는 시간대 정규화, 날짜별 구간 계산, 전체 기간 생성과 저장 전 권한·반복 여부 재확인을 담당한다.
- `week_planner_controller.py`는 기존 생성·수정 다이얼로그, `task_repo.update_unified_task`, 공통 동기화 깨우기와 Google push queue를 연결한다.
- 이동·길이 조절은 새 DB 스키마 없이 시작·종료·선택 날짜를 한 번의 UPDATE로 저장하고 `calendar_id`를 유지한다. 저장 실패나 권한 변경 시 저장된 데이터로 다시 렌더링한다.
- 드래그 중 배경 갱신을 기존 `_is_dragging` 가드로 지연한다. 모달 편집창은 포인터 처리 후 Qt queued connection으로 연다.
- 새 설정 `cal_week_layout`은 앱 초기화에 포함했고, 렌더 캐시 서명에도 포함했다. 시간표 UI 문자열 11개를 19개 로케일에 추가했다. 한국어·영어를 작성하고 나머지는 영어 fallback을 제공한다.

## 검증 결과

- 관련 테스트 **152개 및 subtest 7개 통과**. 신규 시간 계산·저장 50개, Qt 위젯 24개, 실제 주간 렌더러·임시 DB 통합 12개와 기존 날짜 생성·이동·수정 다이얼로그·인코딩 회귀를 함께 실행했다.
- 통합 검사는 자정·자정 넘김 입력, 캘린더 소유권, 동기화 호출, 변경된 읽기 전용 권한, 반복 일정, DB 실패 복원, 보기 저장, 검색·캘린더 숨김, 주말·시작 요일, 드래그 중 갱신 지연, 모달 이벤트 지연, 날짜만 저장된 종일 일정을 포함한다.
- 시간표의 밝음·어두움, 기존 날짜별 보기 및 760px 좁은 창을 실제 `month_renderer.render_calendar`로 렌더링해 확인했다. 일정 겹침, 종일 일정, 한국어 글꼴, 시간 라벨, 스크롤바와 도구 모음 배치를 확인했다.
- 수정 Python 파일의 Ruff lint·format 검사와 19개 번역 파일의 신규 키 일치 검사 통과.
- `scripts/run_encoding_guard.py` 통과. 기존 접근 불가 pytest 캐시·임시 폴더 두 곳의 compileall 경고는 있었으며, 파일 컴파일과 인코딩 테스트의 최종 종료 코드는 0이다.
- 테스트 결과: `artifacts/week-planner-20261007/pytest-results.xml`. 재현 스크립트: `artifacts/week-planner-20261007/render_preview.py`.

자동 검증과 화면 렌더링은 임시 SQLite DB·별도 INI 설정으로 수행했다. 사용자 DB·Google 계정으로 실제 일정 변경은 수행하지 않았다. 개발 소스 구현 완료이며 릴리스 패키지·Store 제출·설치판 검증은 이번 작업에 포함하지 않았다.
