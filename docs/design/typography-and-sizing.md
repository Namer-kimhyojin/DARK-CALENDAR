# Air Calendar 글자·컨트롤·모달 크기 가이드

2026-11-05~06. 이 문서는 메인 화면, 서브 탭, 설정, 일정 입력, 안내창의 글자와 크기를 결정하는 공통 기준이다. 화면마다 임의 크기를 추가하지 않고 역할과 사용자 기본 글자 크기에서 계산한다.

## 글자 계층

새 기본값은 **11pt**다. 이미 저장한 `font_size`와 글꼴은 보존한다. 아래에서 `B`는 해당 사용자의 기본 pt 크기다.

| 역할 | 기준 | 기본 11pt에서 논리 px | 용도 |
|---|---|---|---|
| 본문·입력·버튼 | B | 15 | 일정명, 표, 입력값, 버튼, 체크박스 |
| 보조 설명 | max(9.5, B−1) | 14 | 날짜, 상태 설명, 도움말, 하단 안내 |
| 섹션 제목 | B+2 | 18 | 그룹 제목, 카드 제목 |
| 모달 제목 | B+5 | 22 | 창 안의 단일 제목 |
| 주요 날짜·화면 제목 | B+7 | 24 | 월 제목, 주요 화면 제목 |

일반 본문은 보통 굵기 400, 제목·동작은 600을 기본으로 한다. 크기만 크게 하거나 여러 줄을 모두 굵게 만들지 않는다. 본문과 버튼의 중요도는 같은 크기 안에서 굵기·배경·간격으로 구분한다. 설명을 작게 줄여 억지로 한 줄에 넣지 않는다.

숫자가 주목적인 시계·타이머·날짜 위젯과 사용자가 직접 꾸미는 텍스트는 해당 기능의 크기 설정을 유지한다. 디자인 축소 미리보기, 코드 편집, 인쇄 문서는 화면 본문과 목적이 달라 별도 계약을 따른다.

## 단위와 배율

저장된 `font_size`는 pt다. QSS와 레이아웃에서 사용하는 px는 논리 px이며 `ceil(pt×96/72)`로 변환한다. Windows 125% 배율을 글꼴 크기에 다시 곱하지 않는다. 기존 `base_font_pt`, `title_font_pt`, `subtitle_font_pt`라는 전문가 metric 키는 호환성을 위해 이름을 유지하되 **값의 단위는 논리 px**로 통일한다. 사용자가 저장한 전문가 오버라이드를 임의로 변환하지 않는다. [Windows 단위 변환](https://learn.microsoft.com/en-us/windows/win32/learnwin32/dpi-and-device-independent-pixels), [Qt 글꼴 단위](https://doc.qt.io/qt-6/qfont.html).

Windows 지침은 같은 앱 안에서 일관된 글꼴과 계층을 사용하고, 본문·설명의 최소 읽기 크기를 확보하도록 권고한다. 이 프로젝트의 값은 한국어 일정·설정 화면의 밀도를 고려한 자체 기준이다. [Microsoft Windows Typography](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/typography).

## 버튼과 입력

일반 버튼과 한 줄 입력의 기본 외곽 높이는 약 38px, 하단 주요 버튼은 약 44px를 목표로 한다. 글꼴이 커지면 실제 글자 높이와 padding·테두리를 포함해 늘린다. QSS content 높이에 외곽 높이를 그대로 넣어 이중으로 커지지 않게 한다.

텍스트 버튼 폭은 번역된 글자와 `sizeHint()`를 따른다. 작은 고정 폭으로 글자를 자르지 않는다. 아이콘만 있는 버튼은 작은 도구 영역에 사용할 수 있지만 접근성 이름과 tooltip을 제공한다. 주요 동작의 크기를 강조하려고 같은 하단 줄의 버튼 높이를 제각각 만들지 않는다.

## 모달과 정보 밀도

모달은 제목 → 탭/설명 → 본문 → 하단 동작 순서를 유지한다. 내용과 관계없이 전체 화면을 채우지 않고 실제 작업 영역에 맞춘다. 긴 설정과 큰 사용자 글꼴은 본문을 스크롤하며, 하단 저장·취소와 닫기는 계속 접근할 수 있어야 한다. 제목과 버튼을 숨기는 대신 폼의 흐름과 스크롤 영역을 조절한다.

고정 표 행·단축 버튼·날짜 배지·체크리스트는 글꼴 metrics에 필요한 높이를 확보한다. 일반 화면의 과도한 큰 제목은 주요 날짜·화면 제목 역할 이내로 제한한다. 사용자 지정 창 크기·위젯 배치·읽기 표면·색상·투명도 정책은 함께 유지한다.

모양 설정에서 큰 글꼴을 선택하면 스타일 카드를 한 열로 배치하고 보조 동작과 저장 동작을 나눈다. 미리보기는 접어 둔 상태로 시작하며 필요할 때 펼칠 수 있다. 설정 본문의 스크롤 공간을 확보하면서 적용·취소 버튼은 고정한다. 24pt와 실제 Windows 125% 조합에서도 이 흐름을 확인한다.

## 변경 검증

역할별 실제 QFont 크기, 사용자 글꼴 변경, metric 기본값·리셋·저장, 긴 버튼명, 큰 사용자 글꼴, 모달 하단 접근성을 확인한다. Windows 100%·125%에서는 앱 배율을 강제로 덧씌우지 않고 실제 실행 캡처로 본문·입력·표·서브 탭을 비교한다. 캡처는 디자인 시안과 구분한다.
