# 위젯 전용 모드 개선 계획 — 정리·편의성·심미성·통합

> 작성: 2026-11-22 · 상태: 계획 수립, 구현 미착수
> 범위: 위젯 전용 모드 창(`UnifiedWidgetWindow`)과 꾸미기·구성 편집, 그리고 바탕화면 위젯·위젯 관리자·작업 공간과의 용어·진입점·메뉴 통합. 바탕화면 위젯 자체의 외형 체계는 제외합니다(9장).

## 1. 목적과 기준

사용자는 위젯 전용 모드를 주로 **바탕화면에 띄워 두고 하루 일정을 흘끗 보는 용도**로 씁니다. 이번 작업은 새 화면을 만드는 개편이 아닙니다. 지금 있는 위젯 전용 모드를 사용하기 쉽고 보기 좋게 다듬습니다. 순서는 이렇습니다.

1. 작동하지 않거나 겹치는 선택지를 걷어냅니다.
2. 같은 설정은 한 곳에서 한 이름으로 바꾸게 합니다.
3. 화면 마감을 테마 토큰으로 통일합니다.
4. 다른 위젯 기능과 용어·진입점·메뉴 모양을 맞춥니다.

**목표**
- 꾸미기에서 고른 값이 모두 화면에 실제로 반영됨(반영되지 않는 선택지 0개).
- 한 설정을 바꾸는 곳은 창 안의 빠른 조작 1곳, 꾸미기 1곳을 넘지 않음.
- 위젯 창 파일에 하드코딩한 모서리·여백·색 값 0개.
- 한 개념에 한 용어(4.4절 용어표).

**하지 않을 것**
- 2026-11-22 대화에서 그린 타임라인·요약판 개편 시안(`artifacts/widget-mode-renewal-20261122/`). 이번 계획은 시안을 구현하지 않습니다.
- 바탕화면 위젯의 색·모서리·투명도 체계 통일.
- DB 스키마, 동기화, 일정·업무·지시 처리 로직 변경.

**실패로 보는 것** (기능이 돌아가더라도)
- 기존 사용자의 저장 설정, 창 위치·크기, 자유 구성, 내 배치를 잃음.
- 예전 작업 공간 스냅샷을 복원하면 위젯 창이 깨지거나 기본값으로 돌아감.
- 2026-11-09 가독성 하한(배경 불투명도 95% 이상, 글자 대비 7 / 5.5 / 4.5:1)이 낮아짐.
- 메인 테마 연동이 풀려 위젯 색이 앱 테마와 달라짐.

**적용 기준**: [AGENTS.md](../AGENTS.md), [위젯 규칙](../rules/overlay_widgets.md), [UI 지침](../rules/dialog_ui.md), [테마 계약](../rules/theme_token_completion_process.md), [i18n 규칙](../rules/i18n.md), [글자·크기 가이드](design/typography-and-sizing.md), `.ux-profile.md`(Linear 기준, 강조색 하나, 이모지 금지, WCAG 2.1 AA).

## 2. 현재 상태 진단

2026-11-22 현재 소스를 읽기 전용으로 조사했습니다. 핵심 주장 두 가지(스킨 색 무시, 투명도 고정)는 코드에서 다시 확인했습니다. 줄 번호는 조사 시점 기준입니다.

### 2.2 겹치는 배치

기본 배치 11종(`widget_mode_skins.py:367-465`, `widget_workspace_catalog.py:5-64`) 중 실제로 다른 구성은 4가지입니다.

- 세로(달력 위·목록 아래): `stacked`, `day_brief`, `month_focus`, `week_navigator`, `agenda_first`(달력만 아래)
- 좌우: `dashboard`, `side_planner`, `magazine`(달력만 오른쪽)
- 보드: `work_board`(같은 세로 구성에 3열 목록)
- 목록만: `minimal`, `focus_dock`

나머지 차이는 달력 형태(주간·월간), 요약 줄, 검색창 같은 표시 옵션이 배치에 묶여 있는 것뿐입니다(`widget_layout_calendar_mode()`, `widget_mode_skins.py:150-155`).

### 2.4 화면 마감

- 내부 이름이 화면에 나옴: 목록 머리글 `집중 목록`, 사용자 배치 머리말 `집중 위젯`, 자유 구성의 `통합 목록 필터`(`widget_free_layout_runtime.py:251`), 영어 기본값 FOCUS LIST / All / Schedule / Work(`unified_widget_mode.py:1350-1352, 1405, 2606`).
- 아이콘이 섞여 있음: `⋯`는 글자, 날짜 버튼은 Qt 화살표. 나가기 버튼은 CALENDAR 아이콘인데 진입점은 모두 WIDGET_MGR 아이콘을 씀. 꾸미기 아이콘만 18px이고 나머지는 16px(`:2162-2164`).
- 하드코딩 값: 모서리 5·6·7·8·9·10·12px(`unified_widget_mode.py:279, 366, 388, 2112, 2133`, `widget_workspace_styles.py:13-21`), 여백 6종, 글자 7.4–15pt(`:215-401`), 색 대체값(`:673, 1083-1085`). 창 파일들은 `ui_tokens`·`theme_snapshot`을 가져오지 않음.
- 날짜 선택 창이 스타일 없는 기본 `QCalendarWidget`임(`:1631-1641`). 주간 띠에 이전·다음 버튼이 없음.
- 행: 마우스를 올리면 테두리만 바뀜(`:356-359`). 우선순위 메뉴에 현재 값이 표시되지 않음(`:3195-3259`). 처리 결과 문구가 푸터 아래 별도 줄로 나옴(`:2989-2996`).

### 2.5 나가기·돌아오기

- `메인 화면으로`는 항상 메인 창을 엽니다. `트레이로 숨기기`는 다음 실행 복원(resume)을 켠 채로 숨깁니다(`widget_mode_coordinator.py:121-134`).
- 트레이로 숨긴 뒤 트레이를 한 번 누르면 메인 창이 열립니다. 반면 트레이의 `오버레이 표시/숨기기`와 Ctrl+Alt+Shift+F1은 위젯을 다시 엽니다(`infra_wiring.py:510-540`, `window_shell_actions.py:521-530`).
- 트레이 메뉴와 상단 `위젯` 메뉴에 위젯 전용 모드 항목이 없습니다(`top_menus/widgets_menu.py:16-47`). 진입은 화면 ▸ 집중 및 잠금, F12, 상단 아이콘, 명령 팔레트, 위젯 관리자 탭으로 합니다.

## 4. 개선 내용

### 4.1 기능 정리

**배치 11종 → 4종.** 기존 ID 중 4개를 그대로 남기고, 나머지는 같은 구성으로 옮깁니다. 배치에 묶여 있던 달력 형태·요약 줄·검색창은 꾸미기 ▸ 표시의 옵션이 됩니다.

| 기존 배치 | 새 배치 | 달력 | 요약 줄 | 검색창 항상 표시 |
|---|---|---|---|---|
| `stacked` 세로 집중형 | `stacked` 세로형 | 주간 | 끔 | 끔 |
| `day_brief` 일간 브리핑 | `stacked` | 주간 | 켬 | 켬 |
| `month_focus` 월간 집중 | `stacked` | 월간 | 끔 | 켬 |
| `week_navigator` 주간 탐색 | `stacked` | 주간 | 끔 | 켬 |
| `agenda_first` 일정 우선형 | `stacked` (달력이 목록 위로) | 주간 | 끔 | 끔 |
| `dashboard` 좌우 대시보드형 | `dashboard` 좌우형 | 월간 | 끔 | 끔 |
| `side_planner` 좌우 플래너 | `dashboard` | 월간 | 켬 | 켬 |
| `magazine` 매거진 보드형 | `dashboard` (달력이 왼쪽으로) | 월간 | 끔 | 끔 |
| `work_board` 일정·업무 보드 | `work_board` 보드형 | 주간 | 켬 | 켬 |
| `minimal` 미니멀 리스트형 | `minimal` 목록형 | 없음 | 끔 | 끔 |
| `focus_dock` 집중 도크 | `minimal` | 없음 | 끔 | 켬 |

- 좌우형은 지금의 `dashboard` 규칙대로 폭 640px 미만에서 세로로 바뀝니다(`widget_mode_skins.py:163-164`). 검색창이 있는 배치가 폭 520px 미만이면 달력을 주간으로 줄이는 기존 규칙도 유지합니다.
- 사용 중이던 배치가 옮겨지면 그 배치의 창 위치·크기와 달력 접기 상태도 새 ID로 옮깁니다(`unified_widget_geometry_<id>`, `widget_mode_calendar_visible_<id>`).
- 위젯 스타일 만들기로 만든 사용자 배치(`user_layout_*`, `widget_mode_styles.json`)는 배치 모양(`placements`)이 가장 가까운 4종 중 하나로 옮깁니다. 파일 자체는 지우지 않습니다.

**이관 전후에 지키는 것과 바뀌어도 되는 것** (판단: 선택지를 줄이는 목표에 맞춰 위치 옵션은 만들지 않음)
- 지키는 것: 배치 계열(세로·좌우·보드·목록), 달력 형태(주간·월간), 요약 줄·검색창 표시, 저장된 창 위치·크기, 달력 접기 상태.
- 바뀌어도 되는 것: 달력 칸 크기, 영역 여백, 좌우 열 비율, 저장된 크기가 없을 때의 기본 창 크기. 이 값들은 남는 4종의 정의를 따릅니다. `agenda_first`와 `magazine`에서 달라지는 달력 위치(목록 위, 왼쪽)도 허용합니다. '달력 위치' 옵션은 새로 만들지 않습니다.

**스킨 16종 → 표면 모양 4종.** 색은 메인 테마를 따른다는 현재 동작을 화면에 그대로 적습니다. '스킨'이라는 이름은 쓰지 않습니다.

| 기존 `surface_style` | 해당 스킨 | 새 표면 모양 |
|---|---|---|
| legacy, soft, glass | 클래식 등 6종, studio 5종 | 카드(기본) |
| paper | studio 2종 | 구분선 |
| outline | studio 2종 | 테두리 |
| compact | studio 1종 | 촘촘 |

**자유 구성.** 구성 편집기(`widget_free_layout_editor.py`, `widget_layout_editor_canvas.py`, `widget_layout_editor_preview.py`, `widget_layout_editor_io.py`)와 그 진입점을 제거합니다. 진입점은 더 보기 ▸ 구성 편집…, 꾸미기의 구성 편집, 위젯 관리자 탭 2, `.airlayout.json` 가져오기·내보내기, '프리셋에서 다시 시작'입니다. 자유 구성 런타임(`widget_free_layout.py`, `widget_free_layout_runtime.py`)과 내 배치 저장소(`widget_layout_presets.py`)는 남깁니다. 기존 자유 구성과 내 배치는 더 보기 ▸ 배치와 꾸미기 ▸ 배치에서 선택·이름 변경·삭제할 수 있습니다.

작업 중인 자유 구성(`widget_mode_free_layout`)은 내 배치에 저장되지 않은 하나뿐인 사본일 수 있습니다. 편집기가 없어지면 다른 배치로 바꾼 뒤 되돌아올 길이 없습니다. 그래서 이관 때 이 사본이 저장된 내 배치 어느 것과도 같지 않으면 '이전 자유 구성'이라는 이름의 내 배치 항목으로 추가합니다. 항목을 하나 더하는 것이라 JSON 형식은 그대로입니다. 자유 구성을 쓰던 중이었다면 그 상태를 유지합니다.

**함께 제거할 것**
- 꾸미기·편집기의 투명도 슬라이더. 그 자리에는 "색과 투명도는 모양 설정을 따릅니다" 문구와 모양 설정 열기 링크를 둡니다.
- 위젯 스타일 만들기(`widget_style_editor_dialog.py`)와 더 보기의 해당 항목.
- 읽히지 않는 배치 필드와 2.1절의 사용되지 않는 스타일 코드(호출부 재확인 뒤).
- 상단 보기 버튼.
- 명령 팔레트의 '일정 위젯 열기 / 업무 위젯 열기 / 두 위젯 모두 열기'(예전 패널 위젯의 흔적, `command_palette_runtime.py:700-737`). '위젯 전용 모드'만 남깁니다.

### 4.2 편의성

**설정 위치 규칙.** 창에서 바로 바꾸는 값은 창 안에서만, 오래 두는 설정은 꾸미기에서만 바꿉니다. 배치만 예외로, 빠른 전환(더 보기 ▸ 배치)과 꾸미기 두 곳에 둡니다.

| 꾸미기 탭 | 내용 |
|---|---|
| 배치 | 4종 카드, 내 배치(선택·이름 변경·삭제) |
| 모양 | 표면 모양 4종, 글꼴·크기·제목 굵기, 색·투명도 안내와 모양 설정 열기 |
| 표시 | 달력 형태(주간·월간), 요약 줄, 검색창 항상 표시, 시계, 목록 밀도 |

- 달력 형태·요약 줄·검색창은 **배치마다 따로** 저장합니다. 지금 달력 접기 상태와 창 크기를 배치마다 저장하는 방식과 같습니다. 그래서 세로형에서 좌우형으로 바꿔도 좌우형은 자기 설정(기본 월간)으로 열립니다.
- 목록형과 자유 구성에는 달력 형태가 적용되지 않으므로 그 컨트롤을 숨깁니다. 자유 구성은 자기 안에 저장한 달력 형태를 씁니다. 달력을 아예 없애는 선택지는 두지 않습니다. 달력이 없는 화면이 목록형이고, 잠시 숨기는 건 달력 접기 버튼이 맡습니다.
- 달력 접기·펼치기는 창의 버튼에서만, 완료 포함은 푸터 토글에서만 바꿉니다. 꾸미기의 중복 체크박스는 없앱니다.
- 취소하면 아무것도 저장하지 않는 지금의 초안·적용 모델은 유지합니다.

**더 보기 메뉴**

```
날짜 이동      날짜 선택 · 오늘 · 이전/다음 주(월)
업무 관리      지시·협조 관리 · 전체 업무 관리 · 새로고침
보기           꾸미기… · 배치 ▸ (4종 / 내 배치)
창             위치·크기 조정 · 위치·크기 잠금 ✓ · 이전 위치로 되돌리기 · 화면 안으로 이동
               항상 위 ✓ · 트레이로 숨기기 · 메인 화면으로
위젯 관리자…
```

목록 밀도와 모양 스킨 하위 메뉴, 구성 편집…, 위젯 스타일 만들기, 바탕화면 위젯 관리 하위 메뉴는 없앱니다. 바탕화면 위젯 관리는 위젯 관리자로 갑니다. 같은 메뉴를 창의 아무 곳에서나 오른쪽 클릭으로 여는 동작은 유지합니다.

**날짜와 목록**
- 주간 띠와 월간 달력 양쪽에 이전·다음 버튼을 둡니다(키보드로도 이동).
- 날짜 선택 창은 앱의 날짜 선택 스타일을 따릅니다. 일정 다이얼로그 쪽에 재사용할 수 있는 선택기가 있으면 그것을 씁니다.
- 행 메뉴의 우선순위 하위 메뉴에 현재 값을 체크로 표시합니다.
- 처리 결과 문구와 실행 취소는 푸터 안에서 개수 자리를 잠시 대신하고, 별도 줄을 만들지 않습니다. 실행 취소에 포커스가 있는 동안 자동으로 사라지지 않는 기존 계약은 유지합니다.

**나가기·돌아오기**
- 위젯 창에서 `트레이로 숨기기`를 했다면, 트레이를 한 번 눌렀을 때 위젯 창이 다시 열립니다. 위젯 창이 보이는 상태에서 트레이를 누르면 메인 화면으로 가는 현재 동작(`_return_to_main_from_widget_mode`)은 유지합니다.
- 트레이 메뉴와 상단 `위젯` 메뉴에 `위젯 전용 모드`를 추가합니다.
- 트레이의 `오버레이 표시/숨기기`와 전역 단축키 Ctrl+Alt+Shift+F1은 지금 동작을 유지합니다(위젯 창에서 숨겼다면 위젯 창을 다시 엶). 위의 트레이 클릭 동작과 같은 규칙입니다. 메뉴 이름만 하는 일에 맞게 바꿉니다.
- F12는 앱 창(메인 창·위젯 창) 안에서 위젯 전용 모드를 켜고 끄는 단축키로 둡니다. 다른 프로그램의 F12를 빼앗지 않도록 전역 단축키로 등록하지 않습니다.

### 4.3 심미성

- **토큰화**: 위젯 창 파일(`unified_widget_mode.py`, `widget_workspace_ui.py`, `widget_workspace_styles.py`, `widget_mode_theme.py`)의 모서리·여백·글자 크기·색을 토큰에서 읽습니다.
  - 모서리 3단계: 창 바깥, 영역(보드 열·검색창·메뉴), 행·버튼. 기존 `calendar_app/shared/theme_snapshot.py:141-155`의 `panel_*_radius` 계열에서 고르고, 없으면 같은 파일에 추가합니다. 이 값들은 사용자의 모양 프리셋을 따르므로 위젯 창도 메인 창과 같은 둥글기를 따라갑니다.
  - 여백: 4의 배수 간격 체계.
  - 글자: [글자·크기 가이드](design/typography-and-sizing.md)의 역할(제목·본문·보조·캡션).
- **표면 모양**은 4.1절 4종만 둡니다. 카드는 지금 모습, 구분선은 배경 없이 아래 선만, 테두리는 배경 없이 1px 테두리, 촘촘은 작은 모서리와 좁은 행입니다.
- **내부 이름 제거**: `집중 목록` 머리글은 필터 이름(전체·일정·업무·지시·협조)으로 바꾸거나 없앱니다. `집중 위젯`, `통합 목록 필터`, 영어 기본값은 사용자 문구로 바꿉니다.
- **아이콘**은 Font Awesome 6 Solid(`icon_map.py`의 `ICON` 상수)만 씁니다. `⋯` 글자와 Qt 화살표를 아이콘으로 바꾸고 크기는 16px로 맞춥니다. 위젯 전용 모드에는 위젯 관리자와 다른 아이콘을 주고, 진입·나가기에 같은 아이콘을 씁니다.
- **행 위계**: 제목 → 시간·마감 → 상태 순서로 둡니다. 마우스를 올리면 테두리 대신 옅은 배경을 깝니다. 완료 배지·읽기 전용 표시는 색만이 아니라 글자로도 전달합니다.
- **가독성 하한**(`harden_widget_readability`)과 메인 테마 연동은 그대로 둡니다.

**문서**: `rules/overlay_widgets.md:356, 366-367, 410, 415`의 '스킨 색 덮어쓰기 → 사용자 강조색', '독립 투명도' 설명을 현재 동작에 맞게 고칩니다.

## 5. 저장 호환과 이관 규칙

- 이관 함수 하나를 둡니다. 실행 시 위젯 창을 처음 만들기 전과, 작업 공간 스냅샷을 복원한 직후(`widget_workspace_runtime.py:310-332`)에 같은 함수를 부릅니다. 같은 입력에 몇 번을 돌려도 결과가 같아야 합니다.
- **기존 키는 지우지 않습니다.** 새 값은 새 키에 쓰고, 옛 키는 이관할 때 읽기만 합니다. 이전 버전을 다시 설치해도 옛 키가 남아 있어 그 버전은 원래 모습으로 열립니다.
  - 예외는 `widget_mode_layout` 하나입니다. 남는 4종이 기존 ID를 그대로 쓰므로 같은 키를 4종 ID로 다시 씁니다. 옛 값은 `widget_mode_layout_legacy`에 남깁니다. 이전 버전에서는 4종 중 하나로 열리며, 깨지지는 않습니다(4종 ID가 이전 버전에도 있음).
  - 새 키: `widget_mode_surface`(`card` / `line` / `outline` / `compact`), 그리고 배치마다 `widget_mode_calendar_style_<id>`(`week` / `month`), `widget_mode_show_overview_<id>`, `widget_mode_search_pinned_<id>`.
  - 배치별 키 채우기: 사용 중이던 배치의 값(4.1절 표)이 그 새 ID의 값이 됩니다. 나머지 새 ID는 남는 정의의 기본값을 씁니다(세로형 주간·끔·끔, 좌우형 월간·끔·끔, 보드형 주간·켬·켬). 이미 값이 있으면 덮어쓰지 않습니다.
  - 작업 중인 자유 구성은 4.1절대로 '이전 자유 구성' 내 배치 항목으로 보존합니다.
  - 쓰기를 멈출 옛 키: `widget_mode_panel_theme`, `widget_mode_show_week` 미러, `widget_mode_text_opacity`, `widget_mode_background_opacity`, `widget_mode_opacity`, `widget_mode_color_theme`.
- `widget_mode_layout`이 비어 있으면 지금처럼 스킨의 `legacy_layout_id`(`widget_mode_skins.py:216-225`)로 먼저 배치를 정한 뒤 4종 표를 적용합니다.
- 작업 공간 `MODE_KEYS`(`domain/widget_workspace.py:47-70`)에 새 키를 추가하고 옛 키도 남깁니다. 옛 스냅샷에는 새 키가 없으므로 복원 직후 이관 함수가 채웁니다.
- 내 배치 JSON(`widget_mode_user_layout_presets`)과 자유 구성 JSON(`widget_mode_free_layout`)의 형식은 바꾸지 않습니다.
- `WidgetModeLayout`에서 필드를 지우면 `asdict`로 저장된 사용자 배치를 다시 읽을 때 `TypeError`가 나고 조용히 건너뜁니다(`widget_mode_skins.py:276-277, 360`). 필드를 지우려면 읽기 쪽에서 모르는 필드를 걸러야 합니다.

## 7. 검증

- **테스트 정리**: 사라지는 배치·스킨·편집기를 고정하던 테스트는 이관 테스트로 바꿉니다. 대상은 `test_widget_main_theme.py`, `test_widget_workspace_redesign.py`, `test_widget_mode_ux.py`, 편집기·프리셋 테스트, `scripts/validate_widget_*.py`입니다. 스킨별 대비 검사처럼 결과가 스킨과 무관해진 검사는 표면 4종 × 테마로 바꿉니다.
- **새 회귀 테스트**
  - 배치·스킨 이관표의 모든 행.
  - 이관을 두 번 돌려도 결과가 같음.
  - 예전 작업 공간 스냅샷 복원.
  - 편집기 없이 기존 자유 구성·내 배치가 열리고 선택·이름 변경·삭제됨.
  - 더 보기 메뉴의 중복 항목 0개.
  - 위젯 창 파일의 스타일 리터럴 정적 검사.
  - 트레이 복귀 흐름.
- **실행 환경**: offscreen 실행에는 `QT_QPA_FONTDIR="C:/Windows/Fonts"`와 `-o addopts=""`가 필요합니다. 설정은 임시 INI로 격리합니다. `QSettings("kimhyojin", "Dark Calendar")`는 실제 레지스트리에 쓰므로 생성자를 바꿔 끼웁니다. 화면 확인은 화면 캡처가 아니라 위젯 `grab()`으로 합니다.
- **배율·폭**: 폭 320·360·420px와 1280px 창, 배율 100%·200%, 다크·라이트·사용자 테마, 한국어·영어·독일어.
- **마감 전 검사**: `ux-audit`, 인코딩 가드, Ruff, i18n 검증, `manage_version.py record`(단계별 고정 ID)와 `scan --strict`.

## 8. 구현자에게 맡기는 것

계획의 결과를 바꾸지 않는 선택은 구현자가 정하고, 결과 문서에 근거를 남깁니다.

- 모서리 3단계에 쓸 정확한 토큰 이름과 값.
- 날짜 선택 창에 재사용할 기존 선택기.
- 위젯 전용 모드 아이콘(`ICON` 상수 중 선택 또는 추가).
- 이관 함수의 위치. `widget_mode_skins.py` 근처 또는 새 모듈.
- 사용자 배치(`user_layout_*`)를 4종으로 대응할 때의 판정 규칙.
- 트레이 `오버레이 표시/숨기기`의 새 이름(4.4절 용어표 안에서).
- '이전 자유 구성'이 기존 내 배치와 같은지 비교하는 기준(블록 배치·캔버스 크기 등).
