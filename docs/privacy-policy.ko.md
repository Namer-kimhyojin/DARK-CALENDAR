# Air Calendar 개인정보처리방침

**시행일: 2026년 11월 16일**

Air Calendar(이하 "본 앱")는 Zinz-Soft(이하 "개발자")가 개발·배포하는 Windows용 데스크톱 캘린더 애플리케이션입니다. 본 방침은 본 앱이 이용자의 정보를 어떻게 처리하는지 설명합니다. 게시본은 [privacy.html](https://namer-kimhyojin.github.io/DARK-CALENDAR/privacy.html)이며, 이 문서는 같은 내용의 Markdown 사본입니다.

## 1. 핵심 요약

- **개발자는 이용자의 개인정보를 수집하지 않습니다.** 본 앱에는 서버, 계정 시스템, 분석 도구, 광고가 없습니다.
- 이용자가 만든 모든 일정·업무·설정 데이터는 **이용자 PC에 저장**됩니다. 사용자가 외부 캘린더 연동을 켜면 선택한 일정은 해당 서비스와도 동기화됩니다.
- 외부 전송은 이용자가 직접 활성화한 기능(Google·Outlook 캘린더 연동, iCloud·네이버·Yahoo·Zoho·Fastmail CalDAV 연결, 날씨 위젯, ICS 구독)에 한해, 해당 서비스 제공자에게만 이루어집니다.
- 마이크는 루프 믹서에서 이용자가 마이크 트랙을 켜고 녹음을 시작할 때만 사용합니다. 녹음은 이용자 PC에만 저장되며 외부로 전송되지 않습니다.

## 2. 로컬에 저장되는 데이터

본 앱은 다음 데이터를 이용자 PC의 로컬 폴더(`%LOCALAPPDATA%\kimhyojin\Dark Calendar`)에 저장합니다.

| 데이터 | 용도 |
|---|---|
| 일정·업무·체크리스트 데이터 (SQLite DB) | 캘린더 기능 제공 |
| 앱 설정 (Windows 레지스트리 `HKCU\Software\kimhyojin\Dark Calendar`) | 테마·언어·레이아웃 유지 |
| Google 인증 토큰 (`token.json`, 암호화 저장) — Google 연동 사용 시에만 | 재로그인 없이 동기화 유지 |
| Outlook 인증 캐시, CalDAV 인증 파일 — 해당 서비스 연결 시 | 현재 Windows 사용자 계정의 DPAPI로 암호화한 인증 정보 |
| 선택 캘린더의 일정 캐시·연결 기록·충돌 및 삭제 대기 기록 | 서비스별 동기화, 변경 비교와 안전한 재시도 |
| 루프 믹서 프로젝트와 녹음 WAV 클립 (`loop-mixer` 폴더, 또는 이용자가 저장·내보내기로 지정한 위치) | 루프 믹서 작업 저장·복원 |
| 진단 로그 파일 | 오류 확인 |

이 데이터는 개발자에게 전송되지 않으며, 개발자는 접근할 수 없습니다.

**마이크**: Microsoft Store 패키지는 루프 믹서 녹음을 위해 마이크 권한을 선언합니다. 본 앱은 루프 믹서를 열기만 해서는 마이크를 열지 않으며, 마이크 트랙을 켜고 녹음을 시작한 경우에만 마이크 입력을 받습니다. 녹음 내용은 위 루프 믹서 프로젝트 파일로 PC에 저장되고 어떤 서버로도 전송되지 않습니다. 마이크 접근은 Windows 설정의 개인 정보 보호 항목에서 차단할 수 있습니다.

## 3. 제3자 서비스로의 전송 (이용자가 활성화한 경우에만)

### 3.1 Google Calendar 연동
- 이용자가 Google 계정으로 로그인하면 본 앱은 Google Calendar API를 통해 일정 데이터를 읽고 씁니다.
- 전송 대상: Google LLC ([Google 개인정보처리방침](https://policies.google.com/privacy))
- 인증 토큰은 이용자 PC에만 Windows DPAPI로 암호화되어 저장되며, 개발자 서버로 전송되지 않습니다.
- 연동 해제 시 본 앱은 Google에 토큰 취소(revoke)를 요청하고 로컬 토큰을 삭제합니다.
- 본 앱의 Google API로부터 받은 정보의 사용은 **제한적 사용(Limited Use) 요구사항을 포함한 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)을 준수합니다.**

### 3.2 날씨 위젯
- 이용자가 입력한 **도시 이름은 앱에 포함된 GeoNames 도시 데이터에서 로컬로 검색**되며 외부로 전송되지 않습니다.
- 검색된 위도·경도(소수점 4자리)와 일반적인 웹 요청 정보(IP 주소 등)는 날씨 조회를 위해 노르웨이 기상청 MET Norway([api.met.no](https://api.met.no/))에 전달될 수 있습니다. MET Norway는 API 접근 로그를 노르웨이 오슬로의 자체 데이터센터에 저장합니다.
- 날씨 데이터는 MET Norway의 CC BY 4.0/NLOD 2.0 데이터이며, 도시 데이터는 GeoNames의 CC BY 4.0 데이터입니다.
- GPS 등 기기 위치정보는 수집·사용하지 않습니다.

### 3.3 ICS 캘린더 구독
- 이용자가 직접 입력한 ICS 주소(URL)에 접속하여 일정을 가져옵니다. 해당 URL의 운영자에게 일반적인 웹 요청 정보(IP 주소 등)가 전달될 수 있습니다.

### 3.4 Outlook · Microsoft 365
- 이용자가 로그인하고 권한을 승인하면 Microsoft Graph를 통해 선택한 캘린더의 일정과 기본 계정 정보를 조회하고 쓰기 가능한 일정을 수정합니다. 사용 권한은 Calendars.ReadWrite와 User.Read입니다.
- 인증 캐시는 현재 Windows 사용자의 DPAPI로 암호화해 PC에 저장합니다. 연결 해제는 로컬 인증 캐시를 지우고 해당 연결을 비활성화합니다. 서버의 앱 접근 권한 철회는 Microsoft 계정·조직의 앱 관리 화면에서 별도로 수행합니다.

### 3.5 iCloud · 네이버 · Yahoo · Zoho · Fastmail CalDAV
- 이용자가 입력한 계정·인증 암호와 캘린더 요청은 선택한 서비스(Apple iCloud, 네이버, Yahoo, Zoho, Fastmail)의 CalDAV 서버에 HTTPS로 직접 전달됩니다. iCloud·Yahoo·Fastmail은 앱 전용 암호를 사용하고, Zoho는 2단계 인증을 사용하는 경우 앱 전용 암호를 사용합니다. Zoho는 이용자가 선택한 계정 데이터센터 서버로 연결합니다. 네이버는 읽기 전용이며 연결 가능 여부는 서비스 정책에 따릅니다.
- 인증 정보는 현재 Windows 사용자의 DPAPI로 암호화한 별도 파일에 저장합니다. 설정 레지스트리에 암호를 평문으로 저장하지 않습니다. 일정 본문·ETag·연결 기록은 로컬 동기화 캐시에 보관됩니다.
- 연결 해제는 해당 로컬 인증 파일을 삭제하고 캘린더를 비활성화하며 원격 원본을 삭제하지 않습니다. 서비스 계정의 앱 전용 암호도 필요하면 해당 서비스에서 별도로 취소할 수 있습니다.

## 4. 데이터 보관 및 삭제

- 모든 데이터는 이용자가 삭제할 때까지 로컬에 보관됩니다.
- **Google 연동 해제**: 앱 내 Google Calendar 설정에서 연동 해제 시 토큰이 취소·삭제됩니다. [Google 계정 보안 설정](https://myaccount.google.com/permissions)에서도 언제든 접근 권한을 철회할 수 있습니다.
- **전체 삭제**: 앱 제거 후 `%LOCALAPPDATA%\kimhyojin\Dark Calendar` 폴더를 삭제하면 모든 데이터가 완전히 제거됩니다.
