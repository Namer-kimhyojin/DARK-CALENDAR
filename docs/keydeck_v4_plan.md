> 문서 역할: 설계·감사 기록입니다. 당시 진단과 검증 결과는 현재 상태를 보장하지 않습니다. 현재 진행 상태는 TASKS.md, 구현 규칙은 rules/를 우선 확인합니다.


> 대상: 오버레이 위젯 `launcher_deck` (`OverlayLauncherDeckWidget`)

## 1. 기존 구현 진단

| 영역 | 문제 | 영향 |
|---|---|---|
| 위젯 구조 | 키마다 `QAbstractButton` + 40ms `QTimer` + 롱프레스 `QTimer` + `QMovie` | 키 12개 = QObject 수십 개, 애니메이션 중 타이머 난립 |
| 페인트 | `paintEvent`마다 `QPixmap(path)` 로드·스케일, qtawesome 아이콘 재생성, `QFileIconProvider` 호출, 모자이크 crop 복사 | 호버/애니메이션 프레임마다 디스크·래스터 비용 |
| 사운드 | 누를 때마다 `QSoundEffect` 새로 생성 | WAV 재디코딩, 첫 소리 지연 |
| 갱신 | 설정 변경·리사이즈 종료마다 키 위젯 전체 파괴/재생성, 토글 저장마다 JSON 전체 파싱→정규화→직렬화 | 불필요한 할당·레이아웃 패스 |
| 리사이즈 | 베이스의 글꼴 이진 탐색(`_fit_font_to_size`)이 그리드 레이아웃을 수십 회 재측정 | 드래그 리사이즈 끊김 |
| 포커스 | 덱 클릭 시 창이 활성화되어 단축키 전송이 작업 중인 앱이 아닌 덱으로 감 | 단축키 액션이 사실상 동작하지 않는 구조적 결함 |
| 디자인 | 평면 타일 + 그림자, 키 이동량·스위치·케이스 개념 없음 | "버튼" 느낌, 물리 키보드 감각 부재 |
| 편집기 | 배열/디자인/인터랙션 모달 3개 왕복, 캔버스는 스타일시트 근사치(실제 렌더와 다름), 드래그는 swap만, 크기 1U~3U 콤보, 실행 취소 없음 | 전문 도구 느낌 부족, 반복 작업 불편 |

## 2. 제품 콘셉트

**"투명 2피스 키캡(relegendable keycap) 매크로 패드"**

실물 매크로 패드처럼 **케이스 → 플레이트 → 스위치 → 투명 키캡 → 키캡 안에 끼운 인서트 아트** 계층을 그대로 렌더링한다. 사용자는 투명 키캡 안에 종이를 끼우듯 이미지를 넣고, 위치·확대를 직접 드래그로 맞춘다.

- 누르면 키캡이 실제로 **내려가고**(스프링 물리), 옆면(스커트)이 줄고, 그림자가 좁아지고, 스위치 종류별로 **촉감 곡선과 소리**가 다르다.
- 투명 키캡 너머로 **스위치 하우징과 스템 색**(적/갈/청축)이 비치고, **LED 언더글로우**가 캡을 통과해 번진다.
- 토글 키는 래칭 스위치처럼 **반쯤 눌린 채 고정**되고 LED가 켜진다.
- 덱은 창을 활성화하지 않아(`WindowDoesNotAcceptFocus`) **단축키·텍스트 붙여넣기가 지금 작업 중인 앱으로 전달**된다 — 실물 매크로 패드와 같은 동작.

  studio.py     — KeyDeck Studio 편집기(대화상자 조립, 실행 취소/다시 실행)

  studio_inspector.py — 인스펙터(동작/인서트 아트/레전드/키캡&피드백 탭)

### 3.1 성능 설계 (시스템 부하 절감)

1. **단일 캔버스 렌더링** — 키별 위젯 없이 하나의 `QWidget`이 모든 키를 그리고 좌표로 히트 테스트.
2. **레이어 캐시** — 정적 레이어를 픽스맵으로 캐시하고 프레임마다 합성만 한다.
   - 배경 레이어(케이스·플레이트·스위치 하우징): 페이지/크기/편집 시에만 재생성
   - 키캡 윗면(인서트 아트·레전드·글리프·유리 효과): 키 시그니처+크기+DPR 키
   - 그림자·LED 글로우 스프라이트: 크기/색 키
3. **단일 애니메이션 드라이버** — 캔버스당 16ms 타이머 1개. 스프링이 정지하고 피드백/LED 페이드가 끝나면 **즉시 정지 → 유휴 CPU 0**. 창이 숨겨지면 정지.
4. **부분 갱신** — 애니메이션 중인 키 영역만 `update(rect)`.
5. **공유 리소스** — 이미지·글리프·사운드는 프로세스 단위 캐시(여러 덱 인스턴스 공유). 사운드는 최초 1회 로드 후 풀에서 재생.
6. **움직이는 이미지** — GIF/WebP는 해당 키에만 `QMovie`, 재생 정책(항상/호버/정지), 숨김 시 일시정지, 프레임 변경 시 해당 키만 다시 그림.
7. **저장 디바운스** — 토글 상태 등 런타임 변경은 메모리에서 반영하고 400ms 디바운스로 한 번만 직렬화.
8. **리사이즈 = 줌** — 모서리 드래그는 덱 배율만 바꾼다(글꼴 이진 탐색 제거). 드래그 중엔 캐시를 변형 합성, 놓으면 한 번 재래스터.

### 3.2 렌더링 파이프라인 (키 1개)

```
배경 캐시(케이스/플레이트/스위치 하우징+스템)
 → LED 언더글로우 (재질 투과율 × 밝기 × LED 레벨)
 → 캡 그림자 (이동량에 따라 오프셋/크기/농도 감소)
 → 스커트(옆면): 이동량만큼 앞면 높이 감소, 투명 재질은 굴절 테두리
 → 윗면 캐시 블릿 (y += 이동량)
      ├ 투명 테두리(인서트가 닿지 않는 캡 두께 영역)
      ├ 인서트 아트: 색/그라데이션/패턴/이미지/파노라마 조각 + 줌·이동·회전
      ├ 레전드·글리프 (가독성 그림자)
      └ 유리 효과: 디시(곡면) 그라데이션, 스펙큘러 광택, 림 하이라이트, 재질 확산(프로스트/스모크)
 → 상태 오버레이: 호버 광택, 포커스 링, 실패 흔들림, 비활성 감쇠
```

재질 파라미터: 크리스탈(투과 1.0) · 프로스티드(확산) · 스모크(어두운 투과) · 푸딩(불투명 윗면+투명 옆면) · 솔리드 PBT(불투과).
프로필: 플랫(DSA) · 실린드리컬(체리) · 스페리컬(SA).
케이스: 아노다이즈드 · 실버 알루미늄 · 아크릴 · 월넛 · 플로팅(케이스 없음).

### 3.3 스위치 물리

| 스위치 | 스템색 | 곡선 | 소리 |
|---|---|---|---|
| 리니어 | 적 | 부드러운 가속, 약한 반동 | 소프트 클릭 |
| 택타일 | 갈 | 25~45% 구간 저항 범프 후 통과 | 메커니컬 |
| 클리키 | 청 | 50% 지점 스냅 임펄스 + 클릭음 | 크리스프 클릭 |
| 사일런트 | 흑 | 과감쇠, 반동 없음 | 없음 |

반-암시적 오일러, dt ≤ 1/30s 클램프, 정지 판정(|x−목표|<0.002 ∧ |v|<0.02).

## 5. 기능 명세

### 5.1 런타임 덱
- 키 동작: 앱·파일·폴더 실행(스크립트 확장자 차단 유지), 웹 주소(http/https만), 단축키 전송, **텍스트 스니펫(복사/붙여넣기)**, Air Calendar 명령(화이트리스트 8종), **페이지 이동**.
- **길게 누르기 보조 동작**(550ms) — 보조 동작이 없으면 일반 탭.
- **페이지(레이어)** 최대 12개: 헤더 점 클릭, 마우스 휠, 페이지 키. 전환 시 짧은 크로스페이드.
- 피드백: 성공=LED 녹색 펄스, 실패=LED 적색 + 미세 흔들림, 비활성=감쇠.
- 키에 이미지 파일을 드롭하면 인서트 아트로 설정, 빈 곳에 파일/URL 드롭 시 새 키.
- 우클릭 메뉴: 스튜디오 열기, 이 키 편집, 페이지 이동, 테마, 크기(75~175%), 사운드, 항상 위, 위치/크기 초기화, 복제, 숨기기, 삭제.
- 모서리 드래그 = 덱 줌(비율 유지).

### 5.2 KeyDeck Studio (편집기)
- 상단 툴바: 페이지 탭(추가/이름변경/삭제/순서), 레이아웃 템플릿, 테마, 실행 취소/다시 실행, 그리드(단위/간격), 케이스 설정.
- 중앙 캔버스: **실제 렌더러로 WYSIWYG**. 클릭/Shift·Ctrl 다중 선택, 러버밴드 선택, 드래그 이동(0.25u 스냅), 우/하 핸들로 크기 조절(0.25u), 방향키 이동, Delete, Ctrl+D 복제, Ctrl+C/V 스타일 복사/붙여넣기, 파일·이미지 드롭.
- 인스펙터 4탭 (다중 선택 시 변경한 필드만 일괄 적용)
  1. 동작 — 이름/보조 이름, 동작 유형별 입력, 탭/토글, 길게 누르기 보조 동작, 실행 테스트
  2. 인서트 아트 — 종류, 이미지 불러오기/드롭, **큰 키캡 미리보기에서 직접 드래그(이동)**, 확대 슬라이더, 맞춤, 회전, 농도, 색/그라데이션, 패턴 갤러리, 파노라마
  3. 레전드 — 배치 6종, 크기, 굵기, 색, 글리프 검색, 그림자
  4. 키캡 & 피드백 — 재질, 프로필, 캡 색, 스위치(촉감+소리), 사운드 선택/미리듣기, LED 모드/색
- 실행 취소 스택 80단계(슬라이더 연속 변경은 병합).

### 5.3 레이아웃 템플릿 7종
매크로 3×3 · 스트림 5×3 · 크리에이터 혼합 · 넘패드 · 커맨드 바 · 편집 클러스터(역T 방향키) · 사이드 독

### 5.4 테마 갤러리 24종 (2026-10-06)
기존 7종을 유지하고 17종을 추가했다. 글래스·미니멀·파스텔·내추럴·네온·레트로 각 4종이며 Studio의 테마 버튼은 검색/분류/실제 미리보기/적용 범위를 제공하는 모달을 연다. 구현·검증 기록은 [테마 갤러리 개선 기록](ux-audit/keydeck-theme-gallery-20261006.md)을 참조한다.
