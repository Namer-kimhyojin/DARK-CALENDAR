# Air Calendar 5.5.1

- 월간 달력을 키보드로 탐색할 수 있습니다. 방향키로 날짜를 이동하고 Enter로 선택하며 Ctrl+Enter로 일정을 추가합니다.
- 작은 창과 큰 글꼴에서 날짜·일정이 잘리는 문제를 개선했습니다. 필요한 경우 달력을 가로·세로로 스크롤할 수 있습니다.
- 작성 중인 일정을 닫기 전에 저장하지 않은 변경사항을 확인합니다. 일정 입력창을 간결하게 정리하고 메모 펼치기와 버튼 크기를 개선했습니다.
- 다국어 문구, 날짜·요일 표시, 도움말 메뉴 경로와 긴 문구 표시를 개선했습니다.
- KeyDeck의 입력·오디오 반응과 루프 믹서의 재생·녹음 처리를 개선했습니다.
- 외부 캘린더 동기화와 빈 구독 피드·삭제 충돌 처리, 반복 루틴·체크리스트·집중 모드, 창 표시 단축키의 안정성을 개선했습니다.

대상: Windows x64, MSIX 5.5.1.0. 게시 상태는 배포 확인표에서 별도로 추적합니다.
