# Dark Calendar 3.6.9

Dark Calendar 3.6.9는 트레이 자동 실행 메뉴의 일관성을 높이고, 종료·재실행 뒤 화면 레이아웃과 위젯 상태가 더 안정적으로 복원되도록 개선한 GPL-3.0-only Windows 데스크톱 릴리스입니다.

## 주요 변경 사항

- 트레이의 `윈도우 시작 시 자동 실행` 항목을 다른 메뉴와 동일한 아이콘 체계로 통일했습니다.
- 상단 메뉴와 트레이 메뉴의 자동 실행 체크 상태가 실제 Windows 등록 상태와 함께 동기화됩니다.
- 독립 실행본의 자동 실행 등록이 현재 실행 파일 경로와 정확히 일치하는지 확인해, 이동된 이전 경로를 활성 상태로 잘못 표시하지 않습니다.
- 정상 종료 시 메인 창 위치와 도크 레이아웃을 즉시 디스크에 반영합니다.
- 모든 오버레이 위젯의 설정과 개별 위치를 종료 직전에 다시 저장하며, 통합 위젯 창의 위치와 크기도 숨김·종료 시 보존합니다.
- 같은 종류의 위젯을 여러 개 추가했을 때 겹치지 않도록 배치하고, 삭제한 인스턴스의 오래된 설정을 정리합니다.
- 모니터 구성이 바뀐 뒤에도 위젯을 화면 안으로 복원하고 위치 초기화 기능을 제공합니다.
- 숨긴 시계·스톱워치·날짜·카운트다운·D-day·날씨 위젯의 불필요한 타이머와 네트워크 갱신을 중단합니다.
- 카운트다운 장기 표시, 스톱워치 재시작 복원, 텍스트 위젯 조건식과 갱신 주기를 보강했습니다.
