# Air Calendar 5.1.1

**Date:** 2026-11-09

- 새 루프 믹서 위젯에서 여러 KeyDeck과 직접 켠 마이크 입력을 6개 레이어로 쌓고, 프로젝트를 PC에 저장할 수 있습니다.
- 겹쳐 녹음을 중간에 멈춰도 녹음하지 않은 구간의 기존 오디오를 보존하도록 보완했습니다.
- 모양 설정과 세부 모양 조정을 미리보기·검색 중심으로 재구성하고, 적용 전 변경사항을 취소할 수 있도록 다듬었습니다.
- 라이트·다크 모드의 글자 대비, 색상 선택창의 배치·투명도 저장, 설정 아이콘과 모달 사방 그림자를 개선했습니다.
- 위젯 전용 모드의 색상·테두리·모서리와 위젯 메뉴를 정리하고, 배치 편집기에서 메인 테마의 투명도 연동을 명확히 했습니다.
- 배율이 다른 모니터 사이에서 창을 이동할 때 크기·위치가 비정상적으로 바뀌는 문제를 보완했습니다.
- Windows 첫 실행의 글꼴 초기화 작업을 줄여 시작 과정을 개선했습니다.

## English

- New Loop Mixer widget: combine multiple KeyDecks and opt-in microphone input across six layers, and save projects locally.
- Improved overdubbing to preserve existing audio in unrecorded sections when recording stops mid-loop.
- Redesigned Appearance and Detailed appearance settings with previews, search and changes you can cancel before applying.
- Improved light/dark contrast, color-picker layout and alpha storage, settings icons and four-sided modal shadows.
- Refined widget-mode surfaces and menus, and clarified linked main-theme opacity in the layout editor.
- Improved window sizing and placement when moving between monitors with different DPI scales.
- Reduced initial Windows font setup work during startup.

키덱 호환 화면을 포함한 전체 모듈 패키징을 보강했습니다.

Packaging now retains all KeyDeck modules, including compatibility screens.
