# 위젯 자유 구성 및 주간 보기 개선 결과

> 2026-10-01 · 로컬 구현과 관련 자동 검증 완료

이 문서는 최초 자유 구성 구현 기록입니다. 현재 편집 화면과 추가 검증은 [WYSIWYG 구성 편집기 결과](widget_layout_editor_advanced_results.md)를 참조합니다.

## 사용 방법

위젯의 더 보기 메뉴 → **구성 편집…**에서 시작합니다. 꾸미기 창의 **구성 편집…** 버튼으로도 이동할 수 있으며, 이때 꾸미기의 미적용 초안은 취소됩니다.

- 날짜·시계·달력·통합 목록 필터·통합 목록·일정·업무·지시 목록을 각각 선택합니다. 전체를 끄거나 원하는 요소만 표시할 수 있습니다.
- 요소를 드래그해 이동하고 오른쪽 아래 손잡이로 크기를 조절합니다. 위치·크기는 숫자로도 입력할 수 있습니다.
- 격자 정렬은 선택 사항입니다. 켜면 8px 단위, Alt를 누르면 자유 이동·크기 조절을 사용합니다. 방향키는 1px, Shift+방향키는 10px 이동합니다.
- 실행 취소/다시 실행, 캔버스 크기 조절, 주간/월간 달력 선택, 프리셋에서 다시 시작을 제공합니다.
- 적용 전에는 실제 위젯과 설정을 변경하지 않습니다. 편집 화면은 구성 예시이며 실제 일정 데이터 미리보기는 아닙니다.

기존 다섯 프리셋과 사용자 프리셋은 유지합니다. 프리셋은 편집의 출발점으로 쓸 수 있고 자유 구성과 각각의 창 크기를 따로 보존합니다. 꾸미기에서 색상·글꼴·달력/시계 표시를 바꾸어도 자유 구성은 유지됩니다.

통합 목록 필터는 통합 목록에만 적용합니다. 일정·업무·지시 목록은 독립적으로 표시하되 기존 데이터와 완료/편집/삭제 처리기를 공유합니다. 통합 목록과 유형별 목록을 함께 표시하면 같은 원본 항목이 두 목록에서 보일 수 있습니다.

## 주간 보기

요일과 날짜를 별도 타이포그래피로 그려 날짜 숫자를 강조하고 일곱 날짜의 너비를 동일하게 맞췄습니다. 선택일은 은은한 배경과 짧은 아래 강조선, 오늘은 작은 점, 키보드 포커스는 윤곽선으로 구분합니다. 글꼴·색상 스킨·글자/배경 불투명도 설정과 기존 날짜 선택 동작을 유지합니다.

## 저장과 검증

- `widget_mode_layout_mode`와 version 1 JSON `widget_mode_free_layout`을 별도 저장합니다. 기존 `widget_mode_layout`을 덮어쓰지 않습니다. 모델은 범위 밖 좌표를 제한하고 잘못된 버전/중복/알 수 없는 요소/비정상 좌표를 거부합니다. 잘못된 외부 설정 읽기는 프리셋 기반 초안으로 복구하며 읽기 자체는 저장하지 않습니다.
- 관련 위젯·자유 구성·주간·번역·인코딩 18개 테스트 파일을 파일별 독립 프로세스로 실행해 **253개 통과**, 실패/오류 0개를 확인했습니다. [JUnit 기록](../artifacts/widget-free-layout-20261001/tests/)
- 새 문구 24개를 19개 번들 로케일에 번역했습니다. 기존 번역값을 보존하며 번역 구조·정규 형식·플레이스홀더 검사를 통과했습니다.
- 수정 Python 파일의 Ruff, 인코딩 가드, Git 공백 검사를 통과했습니다. 전체 프로젝트 테스트·빌드·배포 완료를 의미하지 않습니다.
- Windows Qt에서 QT_SCALE_FACTOR 1 / 1.5 / 2를 각각 별도 프로세스로 실행해 **132개 화면/상호작용 검사 통과**를 확인했습니다(각 배율 44개). 320·420·760·1100px 대표 구성, 원본 항목 동작, 편집기 제스처·취소·적용, 프리셋 전환·재시작 복원을 검증했습니다. 화면 63개와 배경을 포함한 주간 영역 캡처 24개를 남겼습니다.

## 범위와 남은 확인

런타임은 캔버스의 저장 비율을 창 크기에 맞춥니다. 작은 창에서 여러 열을 배치하면 요소 내부 스크롤이 필요하며 날짜/시계는 글꼴을 줄여 맞춥니다. 사용자가 만든 의도적인 겹침은 허용합니다. 자유 배치의 모든 조합에 대한 가독성을 보장하지 않습니다.

화면 검증은 합성 데이터와 격리 설정을 사용합니다. 실제 사용자 데이터·장시간 사용·스크린 리더·물리 혼합 DPI 모니터 이동 확인은 남아 있습니다. 기존 대량 목록 최초 생성 성능 과제는 [이전 개선 결과](widget_only_mode_ux_results.md)에 기록되어 있습니다.
