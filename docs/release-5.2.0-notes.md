# Air Calendar 5.2.0

- 상단 바 자동 숨김·고정과 빠른 이동 단축키를 추가했습니다.
- 개인 DB의 검증된 일일 백업과 손상 시 복구 안내를 추가했습니다.
- 테두리색·글씨 투명도, 오늘의 브리핑, 위젯 가독성과 다중 모니터 이동을 개선했습니다.
- 다국어 번역과 체크리스트 관리를 개선했습니다. 일정 복사 시 체크리스트를 함께 복사하며 자연어 입력의 번호 포함 제목을 보존합니다.
- Microsoft Store 5.0.2 이후 추가된 Loop Mixer와 KeyDeck 오디오 개선을 포함합니다.

빌드 대상: Windows x64 / MSIX 5.2.0.0. Microsoft Store 게시·설치 상태는 심사 결과에 따라 별도로 확인합니다.
