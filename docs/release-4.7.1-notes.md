# Air Calendar 4.7.1

## 한국어

- 일정의 같은 날·여러 날 설정과 날짜·시간 입력을 간소화했습니다. 시간 목록, 정확한 분 입력, 일정 길이 바로가기를 제공합니다.
- 지시/협조와 일반업무의 세부일정 입력 디자인을 통일하고, 키보드 이동·부분 입력·요일 및 기간 요약 갱신을 개선했습니다.
- 주간 시간표의 방향키 선택과 스크롤을 개선했습니다.
- 외부 캘린더 동기화의 오류 처리와 충돌 대응을 보완하고, 구독·가져오기·진단 정보 보호를 강화했습니다.
- 특정 시각만 지정한 ICS 반복 일정의 처리 속도를 개선했습니다.
- 기존 일정과 설정을 유지하는 업데이트입니다.

## English

- Simplified same-day and multi-day scheduling with time suggestions, exact-minute entry, and duration shortcuts.
- Unified date and time controls for schedules, directives, and routine tasks, with improved keyboard navigation and live weekday and duration updates.
- Improved keyboard selection and scrolling in the weekly timetable.
- Improved external calendar synchronization, conflict handling, and protections for subscriptions, imports, and diagnostic information.
- Improved processing of ICS recurrence rules restricted to specific times of day.
- Preserves existing events and settings.

## Distribution

Windows x64. The matching corresponding-source archive and third-party license information are included with this release. Microsoft Store certification and availability are tracked separately from the GitHub release.
