# Air Calendar 4.8.0

## 한국어

- 비트메이커 전용 연주창에서 키보드·패드로 연주하고, 연주 타이밍을 녹음해 루프로 재생할 수 있습니다. 녹음 저장·복원·공유를 지원합니다. 마이크 녹음 기능은 아닙니다.
- 날씨 위젯에 새 카드 3종, 앞으로 6시간 예보와 지역 시간대에 맞춘 표시를 추가했습니다. 날씨별 움직임과 사용자 WebP/GIF를 지원하며 숨김·절전·시스템 애니메이션 설정에 맞춰 동작합니다.
- Google Calendar의 일시적 연결 오류와 실제 재인증 필요 상태를 구분하고, 기존 인증 정보를 유지한 재시도 흐름을 개선했습니다.
- 완료 항목을 복사할 때 복사본의 완료 표시를 초기화하고 원본 상태는 유지합니다.
- 자연어 입력의 날짜 경계 처리와 일정 미리보기·저장 기본 시각의 일치를 개선했습니다.
- 시스템과 앱 테마가 다를 때 명령 검색창과 모양 설정의 아이콘을 더 또렷하게 표시합니다.
- 기존 일정·계정·설정·위젯 배치와 사용자 프리셋을 유지합니다.

## English

- Added a dedicated beatmaker performance window with keyboard and pad input, timed performance recording, looping, save/restore, and sharing. Recording captures pad events, not microphone audio.
- Added three weather card designs, forecasts for the next six hours, local-time-zone displays, weather animations, and custom WebP/GIF artwork. Hidden state, power-saving mode, and system animation settings are respected.
- Improved Google Calendar recovery by distinguishing temporary connection errors from cases that require sign-in, while preserving existing credentials for retries.
- Copies of completed items now start incomplete while preserving the original item.
- Improved natural-language date boundaries and consistency between previewed and saved default times.
- Improved command-search and appearance-setting icon contrast when system and app themes differ.
- Preserves existing events, accounts, settings, widget layouts, and user presets.

## Distribution

Windows x64. New weather labels are provided in Korean and English, with English fallback text in other interface languages. The matching corresponding-source archive and third-party license information accompany the release. GitHub publication, Microsoft Store certification, availability, and installed updates are tracked separately.
