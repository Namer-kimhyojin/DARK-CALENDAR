# Air Calendar 3.7.4

Air Calendar 3.7.4는 최근 이틀간 완성한 사용성 개선을 실제 배포판에 통합한 Windows 데스크톱 릴리스입니다.

## 주요 변경 사항

- F1 도움말을 검색, 빠른 시작, 작업 흐름, 화면 복구, 전체 단축키로 구성된 도움말 센터로 고도화하고 19개 언어의 안내 문구를 보강했습니다.
- Windows 시작 앱 등록이 사용자 또는 정책에 의해 차단된 경우 원인을 구분하고, 시작 앱 설정을 바로 열어 변경 상태를 자동으로 다시 확인하도록 개선했습니다.
- 위젯 전용 모드의 일정·업무·지시/협조 필터, 빠른 작업 메뉴, 접기/펼치기 레이아웃, 선택 날짜 전달과 읽기 전용 일정 보호를 개선했습니다.
- 밝은 테마와 사용자 지정 색상에서 메뉴, 상단 바, 다이얼로그, 입력 영역과 보조 텍스트의 대비 및 일관성을 높였습니다.
- 집중 작업 선택과 뽀모도로 설정의 저장·취소·오류 피드백을 보강했습니다.
- 일정 상세 표시와 캘린더 패널 렌더링을 정리하고 비활성 Google 캘린더가 오늘 패널에 노출되는 회귀를 방지했습니다.
- 앱 아이콘과 Store용 시각 자산을 최신 디자인으로 갱신했습니다.
