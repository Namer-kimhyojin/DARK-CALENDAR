일정과 업무

위젯 모드와 전체 업무 관리

바탕화면 위젯으로 오늘 일정을 확인하고, 전체 업무 관리에서 일정·일반업무·지시·협조사항을 목록으로 정리하세요.

패널을 따로 옮기거나 붙이기

달력과 오늘 일정·업무 패널을 원하는 자리에 놓으세요. 자석 모드에서는 분리한 패널을 달력 창 가장자리로 가져가 한 창으로 정리할 수 있습니다.

작업 공간 저장과 전환

자주 쓰는 구성을 저장해 다시 불러오고, 직접 정한 시간·요일 규칙으로 자동 전환할 수 있습니다.

여러 개를 띄우거나, 스택으로

같은 종류의 위젯도 여러 개 만들고, 선택한 위젯은 스택으로 묶어 같은 자리에서 전환합니다.

위젯마다 다른 디자인

글자·배경·테두리의 색과 투명도를 위젯별로 조절하고, 디자인 프리셋과 모양을 고르세요. 텍스트 위젯은 시간·D-Day·다음 일정 같은 값을 템플릿으로 조합할 수 있습니다.

KeyDeck

앱·폴더·웹사이트·단축키를 키 하나에 연결하세요. 비트메이커나 가상악기로 연주하고, 루프 믹서에 연결해 소리를 섞을 수 있습니다.

필요할 때, 필요한 연결만

여러 캘린더를
하나의 바탕화면에.

연결한 서비스의 일정을 함께 확인하고, 편집 가능한 캘린더에는 변경 내용을 동기화하세요. 연결할 서비스와 표시할 캘린더는 직접 선택합니다.

Google Calendar

양방향 일정 · 데스크톱 OAuth 인증 파일 필요

Outlook · Microsoft 365

양방향 일정 · 최초 캘린더용 Microsoft 앱 등록 필요

iCloud

개인 일정 양방향 · Apple 앱 전용 암호 사용

NAVER

읽기 전용 · 서비스의 CalDAV 연결 정책에 따름

ICS

읽기 전용 구독 · 공휴일과 공개 일정 피드

외부 서비스는 계정 준비와 권한이 필요하며 호환성은 서비스 정책에 따릅니다. 네이버·ICS·권한 없는 캘린더와 반복/초대 일정의 편집은 제한됩니다. 로컬 캘린더는 계정 없이 사용할 수 있습니다.

달력과 실행 목록 사이의 거리를 없앴습니다.

월간 캘린더 오른쪽에 이번 주 일정, 루틴, 디렉티브가 이어집니다. 날짜를 확인한 자리에서 해야 할 일을 바로 선택할 수 있습니다.

  • 멀티데이 일정과 드래그 범위 선택
  • 오늘·이번 주 패널 전환
  • 루틴과 실행 항목 분리 관리

일정을 담는 방식

적는 일은 가볍게. 확인할 일은 또렷하게.

날짜를 고르고, 시간을 정하고, 저장할 캘린더를 선택하세요. 월간 달력과 일정 목록이 나란히 있어 약속의 흐름과 하루의 세부 내용을 함께 볼 수 있습니다.

  • 날짜를 드래그해 여러 날의 일정 등록
  • 일정·할 일·반복 업무를 함께 확인
  • 문장으로 날짜와 시간을 빠르게 입력

일정 관리에서 업무와 집중까지.

  1. 문장과 드래그로 일정 입력

    날짜 범위를 드래그하거나 한국어·영어 문장으로 일정을 빠르게 등록하세요.

  2. 반복 업무와 체크리스트

    루틴·할 일·지시·협조를 구분하고, 우선순위와 체크리스트로 실행 항목을 관리합니다.

  3. 집중 시간과 기록

    집중 모드와 Pomodoro를 시작하고 완료한 세션과 누적 시간을 확인하세요.

설치와 데이터

시작하기 전에.

일정은 기본적으로 내 PC에.

일정과 설정은 로컬에 저장합니다. 외부 캘린더·날씨·ICS는 연결한 기능에 한해 해당 서비스와 통신합니다. 앱에는 개발자 분석 서버가 없습니다.

어떤 운영체제를 지원하나요?

Air Calendar는 Windows 데스크톱 환경에 맞춰 설계되었습니다. 정확한 최신 요구 사항은 Microsoft Store 제품 페이지에서 확인할 수 있습니다.

외부 캘린더 연결은 필수인가요?

아닙니다. 로컬 캘린더만으로 사용할 수 있으며 필요한 서비스만 선택해 연결합니다. 외부 서비스는 계정과 권한이 필요합니다.

무료 프로그램인가요?

Microsoft Store에서 판매되는 유료 앱입니다. 현재 가격과 구매 조건은 Store에서 확인하세요. 소스 코드는 GPLv3 조건에 따라 공개됩니다.

어떤 위젯을 사용할 수 있나요?

시계, 스톱워치, 날짜 카드, 카운트다운, D-Day, 텍스트, 날씨, KeyDeck, 루프 믹서를 지원합니다.

내 데이터가 외부 서버로 전송되나요?

기본 데이터는 로컬에 저장됩니다. Google Calendar, 날씨, ICS 등 사용자가 활성화한 외부 기능만 해당 제공자와 직접 통신합니다.
