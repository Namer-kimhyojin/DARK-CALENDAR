# Air Calendar 3.8.1

- 추가 계정 연결에 Yahoo Calendar, Zoho Calendar, Fastmail을 추가했습니다.
- Zoho 계정의 데이터센터 서버를 선택할 수 있습니다.
- 새 서비스의 캘린더 필터, 동기화 상태, 수동·자동 동기화와 일정 저장 후 동기화를 연결했습니다.
- 암호는 Windows 사용자 보호 저장을 사용하고, 서비스별 HTTPS 서버 제한 및 실제 캘린더 쓰기 권한을 확인합니다.
- 위젯 모드 열기에 실패했을 때 남은 로딩 타이머와 전환 상태를 정리해 다시 열 수 있도록 수정했습니다.

CalDAV 연결은 쓰기 권한이 있는 일반 개인 일정을 양방향 동기화합니다. 반복·초대 일정은 읽기 전용이며, Yahoo! JAPAN 계정은 이번 Yahoo 연결 대상에 포함되지 않습니다. 서비스당 연결 계정 하나를 유지하는 현재 방식입니다.

이 릴리스는 현재 개발 소스의 기존 동기화 안전성, 캘린더 관리, 주간 보기 및 위젯 개선도 포함합니다. 새 서비스의 인증에는 각 서비스에서 발급한 앱 암호 또는 해당 계정에 허용된 인증 암호가 필요합니다. Zoho는 웹 설정에서 사용할 캘린더를 CalDAV 대상으로 먼저 선택해야 합니다.

검증 상태는 배포 기록에서 별도로 관리합니다. 모의 서버 및 격리 회귀 검사는 실제 사용자 계정의 연결 성공을 의미하지 않습니다.
