# Air Calendar 5.0.1

캘린더와 위젯, 설정·관리·알림 창의 디자인을 하나로 정리한 5.0 릴리스입니다.

- 네이비·라일락과 라이트 테마, 다양한 포인트 색상과 투명도 설정
- 일관된 제목·닫기 동작·글자 크기·버튼 크기·그림자를 적용한 모달 창
- 모든 창에서 마우스 휠에 의한 입력값 변경 방지
- 간결한 주간 보기, 요일 표시 순환 선택과 위젯 전용 모드의 테마 계승
- 일정 관리 더블클릭과 시작·종료 시간 배치 개선
- 비트메이커 4트랙 Loop Deck: 녹음·반복·오버더빙·음소거·트랙 음량
- Python 3.14.10, Qt 6.12.0, SQLite 3.54.1과 의존성 보안 업데이트
- Qt 오버레이 메인 창에서 종료 확인창의 네이티브 소유 관계가 누락되는 문제 수정

설치 패키지, Microsoft Store 업로드 패키지, 대응 소스와 각 SHA-256 파일을 제공합니다. Store 심사·게시 및 설치 업데이트는 GitHub 공개와 별도로 진행됩니다.

## English

Air Calendar 5.0 unifies calendar, widget and dialog design while preserving theme colors and transparency options. This release adds configurable weekday display and a four-track Loop Deck, improves input and task-management usability, updates the bundled runtime, and fixes native modal ownership for overlay windows.

Packages, corresponding source and SHA-256 checksums are included. Microsoft Store certification and availability are tracked separately from the GitHub release.
