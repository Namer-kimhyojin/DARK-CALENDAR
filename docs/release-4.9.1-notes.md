# Air Calendar 4.9.1

## 한국어

- 8종 바탕화면 위젯에 그래픽 컬렉션 3종과 위젯별 디자인 10종을 추가했습니다. 실제 위젯 미리보기에서 디자인을 선택하고 개별 또는 표시 중인 위젯에 적용할 수 있습니다.
- 위젯 관리를 바탕화면·전용 모드 두 탭으로 통합하고 추가 갤러리, 검색, 상태 필터, 찾기와 꾸미기를 연결했습니다.
- 전용 모드의 스킨과 화면 구성을 확장하고 일간 요약, 유형별 보드, 검색과 빠른 보기 전환을 추가했습니다.
- 작업 공간 저장·적용·되돌리기, 모니터별 배치 편집, 일정 범위와 요일·시간 규칙, 위젯 스택과 절전 설정을 지원합니다.
- 19개 번역 파일의 위젯·작업 공간 문구, 공통 버튼, 월·요일, 오른쪽에서 왼쪽으로 읽는 언어와 지역별 언어 처리를 보완했습니다.
- ICS 구독을 해제하면 기존 일정을 숨김 로컬 보관 캘린더로 보존합니다. 재등록 시 중복 표시를 줄이고 구독 재개 시 즉시 갱신하며, 오류 복구 후 안내 상태를 갱신합니다.
- ICS 주소 변경 중 갱신, Outlook·CalDAV 연결 해제와 재인증의 경합 및 실패 복원을 개선했습니다.
- 기존 일정, 계정, 사용자 설정과 위젯의 내용·배치를 유지하는 업그레이드입니다.

## English

- Added three graphic collections and ten dedicated designs for each of eight desktop widget types, with live previews and individual or visible-widget application.
- Unified widget management into Desktop and Dedicated Mode tabs with an add gallery, search, status filters, locate, and customize actions.
- Expanded dedicated-mode skins and layouts, daily summaries, category boards, search, and quick view switching.
- Added workspace save/apply/undo, monitor placement editing, calendar scopes, weekday/time rules, widget stacks, and power-saving controls.
- Improved widget and workspace translations across 19 locale files, common buttons, month and weekday names, right-to-left startup, and regional language handling.
- Unsubscribing from ICS now preserves events in a hidden local archive. Resubscribing avoids displaying the archive by default; resuming refreshes immediately, and successful recovery updates feedback.
- Improved refresh coordination during ICS URL edits and disconnect, reauthentication, and rollback handling for Outlook and CalDAV.
- Preserves existing events, accounts, settings, widget content, and layouts.

## Distribution

Windows x64. GitHub publication, Microsoft Store certification/publication, and the installed app are tracked separately in the release checklist.
