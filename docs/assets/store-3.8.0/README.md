Art was generated with the built-in image generation tool, then exported to exact pixel dimensions without adding text or app UI. Generated originals are retained. The homepage uses a copy of the hero art.

Prompt set: create restrained, modern calendar synchronization promotional art on a pale gray background, using a central mint calendar glyph connected to five smaller coral, blue, violet, green and apricot calendar glyphs. Add a subtle shield/check motif to suggest careful change handling. Use soft studio light, generous negative space and no titles, letters, brands, device frames or screenshots. The square variation repeats this identity in a centered composition.
