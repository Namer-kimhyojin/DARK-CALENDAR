현재 Store API 인증과 브라우저 로그인은 유효하지 않아 사용자 로그인을 요청했다. 기존 5.2.0 Store 체크포인트는 새 제출 상태를 확인할 때까지 보존한다.

확인 결과: GitHub 5.5.1 공개 및 공개 파일 6개 재다운로드 해시 검증 완료. 빌드 commit `106661905f524d50d7432cce4f63328678d6f35c`, native CI `43524534524`, 제품 입력 741개 및 MSIX payload 1,896개 일치. Linux 검사 환경 보완은 제품 입력을 바꾸지 않는 별도 QA 커밋으로 추적했다.

Store는 Partner Center 로그인 대기 상태이며 새 제출·업로드·심사 접수는 아직 수행하지 않았다. 로컬 Store 설치는 5.2.0.0으로 남아 있다. 18개 언어 변경 안내와 동일 5.5.1.0 업로드 파일은 준비돼 있다.
