# Air Calendar 3.8.0

캘린더 서비스의 연결·동기화·관리를 하나의 흐름으로 통합했습니다. 개발 폴더의 현재 `run.bat` 실행 입력 전체를 기준으로 배포합니다.

- Google, Outlook·Microsoft 365, iCloud·CalDAV, 네이버, ICS의 상태와 설정을 통합 화면에서 관리합니다.
- 캘린더 표시·이름·색상·기본 선택, 수동·자동 동기화, 충돌·실패 확인을 연결했습니다.
- 서비스별 연결 기록과 삭제 대기를 분리하고 동시 수정·읽기 전용 권한·부분 응답·종료 중 작업의 예외 처리를 강화했습니다.
- CalDAV의 변경 본문 다운로드, 재시작 후 캐시 재사용, UID 검증을 통한 주소 변경 복구를 추가했습니다.
- 현재 KeyDeck·위젯 편집기 개선과 새 아이콘·스플래시 리소스를 포함합니다.
- 홈페이지의 서비스별 연결 안내, 개인정보 안내, 실제 설정 화면과 Store 홍보 이미지를 갱신했습니다.

Google은 데스크톱 OAuth 파일, Outlook은 관리자 등록 클라이언트 ID, iCloud는 앱 전용 암호가 필요합니다. 네이버·ICS는 읽기 전용이며 연결 가능 여부는 서비스 정책에 따릅니다. 반복·초대 일정과 서비스 간 편집에는 제한이 있습니다. 실제 서비스 계정 및 Store 설치판 검증은 별도 확인 대상입니다.

설치 패키지: x64 MSIX 3.8.0.0. 기존 사용자 데이터와 설정을 초기화하지 않습니다.
