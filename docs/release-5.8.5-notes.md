# Air Calendar 5.8.5

오류·성능을 고친 patch 배포입니다.

- 검색창에 한글을 입력하는 동안 화면 전체를 다시 그리지 않습니다. 음절마다 생기던 버벅임이 사라지고, 입력을 멈췄을 때 한 번만 결과를 보여 줍니다.
- 오늘 일정·일반업무·지시/협조 패널이 각자 테두리를 가져, 패널 사이 경계가 다시 또렷해졌습니다.
- 앱을 오래 켜 두면 패널을 다시 그릴 때마다 숨은 화면 요소가 쌓이던 문제를 고쳤습니다.
- 패널을 다시 그릴 때 설정을 한 번만 읽어 갱신이 빨라졌습니다.
- 시작할 때 달력을 한 번만 그려 첫 화면이 약 0.5초 빨리 뜹니다.

대상: Windows x64, MSIX 5.8.5.0. 게시 상태는 배포 확인표에서 별도로 추적합니다.
