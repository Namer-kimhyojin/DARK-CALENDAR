여러 캘린더를
하나의 흐름으로.

시스템 메뉴의 캘린더 및 동기화 → 캘린더 통합 설정에서 서비스 연결, 캘린더 관리, 확인할 문제를 함께 관리합니다. 로컬 캘린더는 외부 계정 없이 사용할 수 있습니다.

GoogleOutlookiCloud네이버ICS문제 해결

연결 → 선택 → 동기화 → 확인

  1. 서비스 카드에서 연결 설정을 엽니다.
  2. 인증을 마친 뒤 가져올 캘린더를 선택하고 저장합니다.
  3. 지금 동기화로 확인한 후 자동 동기화를 켭니다. F5로 연결된 서비스를 함께 동기화할 수 있습니다.
  4. 캘린더 관리에서 표시·이름·색상·기본 캘린더를 정하고, 확인할 문제에서 충돌과 실패를 처리합니다.

Google Calendar

일정 조회·생성·수정·삭제를 지원합니다. 현재 배포판은 사용자가 준비한 데스크톱 OAuth 인증 파일을 사용하는 방식입니다.

  1. Google Cloud에서 Calendar API를 활성화하고 데스크톱 앱 OAuth 클라이언트를 준비합니다.
  2. Google 연결 설정에서 인증 JSON 파일을 선택하고 브라우저에서 로그인·권한 승인을 마칩니다.
  3. 동기화할 캘린더를 선택하고 저장합니다.

홈페이지의 Google 인증 준비 상세 안내

Outlook · Microsoft 365

개인 Microsoft 계정과 회사·학교 계정의 일정 조회·생성·수정·삭제를 지원합니다. 현재 공용 로그인 앱 등록 전이므로 관리자가 준비한 캘린더 연동용 클라이언트 ID가 필요합니다. Store 제출 자동화 앱의 ID·비밀 키를 넣지 않습니다.

  1. 관리자가 Entra에 개인 계정·모든 조직 계정을 지원하는 앱을 등록합니다.
  2. 모바일·데스크톱 플랫폼에 http://localhost를 추가하고 Microsoft Graph 위임 권한 Calendars.ReadWrite, User.Read를 설정합니다. 비밀 키는 필요하지 않습니다.
  3. Outlook 연결 설정에 클라이언트 ID를 입력하고 Microsoft 로그인 후 캘린더를 선택합니다. 조직의 관리자 동의·MFA 정책이 적용될 수 있습니다.

Microsoft 앱 등록 안내

iCloud · CalDAV

쓰기 권한이 있는 개인 일정의 조회·생성·수정·삭제를 지원합니다. Apple 계정 이메일과 앱 전용 암호를 사용합니다.

  1. 이중 인증이 설정된 Apple 계정에서 앱 전용 암호를 발급합니다.
  2. iCloud 연결 설정에 이메일과 앱 전용 암호를 입력하고 연결 확인 · 캘린더 찾기를 누릅니다.
  3. 캘린더를 선택하고 저장한 뒤 동기화합니다.

Apple 계정의 기본 암호를 변경하면 앱 전용 암호도 취소되어 다시 발급해야 할 수 있습니다. Apple 앱 전용 암호 안내

네이버 · CalDAV

읽기 전용 연결입니다. Windows에서의 연결 가능 여부는 네이버 서비스 정책에 따릅니다. 양방향 쓰기를 보장하거나 플랫폼 제한을 우회하지 않습니다.

  1. 네이버 연결 설정에 ID와 인증용 암호를 입력합니다. 2단계 인증을 사용하는 개인 ID는 애플리케이션 비밀번호를 사용합니다.
  2. 연결 확인 후 가져올 캘린더를 선택합니다.
  3. 일정 수정·삭제는 네이버 원본 서비스에서 수행합니다.

2단계 인증을 사용하는 단체 ID는 애플리케이션 비밀번호를 지원하지 않아 연결할 수 없습니다. 네이버 공식 연결 안내

ICS 구독

공휴일·공개 일정 등 ICS 주소를 입력해 읽기 전용으로 가져옵니다. 캘린더 관리에서 구독을 추가하고 표시·새로고침을 관리합니다. 비공개 일정 주소는 비밀번호처럼 보호하세요.

충돌과 실패가 생겼을 때

  • 양쪽에서 일정이 바뀌면 자동으로 덮어쓰지 않고 문제 목록에서 비교 후 선택합니다.
  • 네트워크 오류·권한 거부·잘못된 응답은 정상적인 빈 캘린더로 처리하지 않습니다.
  • CalDAV는 변경된 일정 본문을 우선 내려받고, 일정 주소 변경은 UID와 기존 주소의 삭제 여부를 확인한 뒤 복구합니다.
  • 읽기 전용 캘린더, CalDAV의 반복·초대 일정은 원본 서비스에서 수정합니다. Outlook의 전체 반복 시리즈 편집과 초대 응답, 서비스 간 자동 복사는 현재 지원 범위에 포함되지 않습니다.
  • 연결 해제·캘린더 선택 해제는 원격 원본을 삭제하지 않습니다. Microsoft 서버의 앱 접근 권한 철회는 계정 관리 화면에서 별도로 수행합니다.

서비스별 실제 계정의 인증·서버 정책에 따라 연결 결과가 달라질 수 있습니다. 인증 암호는 앱의 숨김 입력란에만 입력하고 게시판에 올리지 마세요. 오류는 비밀정보를 제거한 화면과 함께 사용자 요청 게시판에 알려주세요.

Connected calendars, one workflow

Open System → Calendars & sync → Unified calendar settings. Connect a service, choose calendars, sync, then review any issues. Google uses a desktop OAuth file; Outlook currently requires an administrator-provided calendar app client ID. iCloud uses an Apple app-specific password. Naver and ICS are read-only; Naver availability depends on its platform policy. Recurrence, invitation and cross-service editing have limits.

Credentials are encrypted for the current Windows user. Disconnecting does not delete events on the remote service. Local calendars work without an external account.
