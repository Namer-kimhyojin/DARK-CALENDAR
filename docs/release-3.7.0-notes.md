# Dark Calendar 3.7.0

Dark Calendar 3.7.0은 위젯 전용모드를 하나의 현대적인 작업 화면으로 재구성하고, 모든 위젯의 외관 프리셋과 종료 안정성을 강화한 GPL-3.0-only Windows 데스크톱 릴리스입니다.

## 주요 변경 사항

- 위젯 전용모드의 상·하단 도구 영역을 하나의 창에 통합하고, 일정·업무 목록을 간결한 카드형 화면으로 개선했습니다.
- 대시보드형은 월간 달력을 왼쪽에, 매거진형은 월간 달력을 오른쪽에 배치해 레이아웃별 정보 흐름을 구분했습니다.
- 월간 달력을 기본 보기로 제공하고 날짜 셀, 선택 상태, 일정 강조 표시를 위젯 색상과 어울리는 반투명 디자인으로 개선했습니다.
- 일정·업무 제목과 본문 글자 크기를 일관되게 조정하고, 글꼴·글자 크기·글자 투명도·배경 투명도를 각각 설정할 수 있도록 했습니다.
- 보조 설명, 완료 업무, 시계와 주간 날짜 등 표시 항목 설정이 미리보기와 재실행 후 상태에 동일하게 반영됩니다.
- 모든 데스크톱 위젯에 공통으로 사용할 수 있는 10종 이상의 전문 디자인 프리셋을 제공하며, 배경과 테두리 없이 글자만 표시하는 프리셋을 추가했습니다.
- 기본 프리셋은 고정 자산으로 보호하고, 사용자 프리셋만 추가·이름 변경·삭제할 수 있도록 구분했습니다.
- 템플릿 문법을 저장 전에 검증하고 잘못된 필드·옵션·중괄호를 사용자에게 명확히 안내합니다.
- 추가 버튼 롤오버, 글꼴 드롭다운, 보조 설명 미리보기, 일정 강조점 위치, 꾸미기 아이콘 표시 문제를 수정했습니다.
- 종료 처리를 하나의 멱등 수명주기로 통합해 타이머·인증/동기화 워커·Google 푸시 큐·위젯 네트워크 작업을 안전하게 정리합니다.
- 정상 종료와 언어 재시작 시 화면 레이아웃, 위젯 전용모드, 개별 위젯 위치와 설정을 저장한 뒤 DB 연결과 단일 실행 잠금을 순서대로 해제합니다.
- 릴리스 빌드의 Python 버전을 검증된 CI 환경과 동일한 3.13.15로 고정해, 지원되지 않는 로컬 ABI로 패키지가 생성되는 문제를 차단했습니다.
