# Air Calendar 3.7.7

Air Calendar 3.7.7은 현재 개발 중이던 위젯 시각 업그레이드와 런처 덱 기능을 통합한 Windows 데스크톱 릴리스입니다.

## 주요 변경 사항

- 런처 덱 위젯을 추가하고 프로그램·파일·폴더·웹 주소·키보드 단축키·Air Calendar 명령 실행을 지원합니다.
- 6가지 런처 배열, 5가지 키캡 스타일, 벡터 아이콘과 21종 데칼, 사용자 이미지 및 전체 이미지 분할 모드를 제공합니다.
- 키별 누름·호버·성공·실패 상태와 번들 피드백 사운드, 토글 및 길게 누르기 동작을 설정할 수 있습니다.
- 날짜 카드와 D-Day에 장면 일러스트 팩을, 날씨 위젯에 상태별 일러스트 팩을 추가했습니다.
- 오버레이 위젯에 카드·캡슐·원형·포스터 모양, 프리셋 미리보기, 복제와 화면 맞춤 기능을 추가했습니다.
- 위젯 전용 모드의 필터를 화면 폭에 따라 한 줄·두 줄·선택값 메뉴로 전환하고, 완료 항목을 배지와 보조 필터로 명확하게 구분했습니다.
- 신규 기능 문자열을 19개 번들 언어 구조에 맞게 동기화했습니다.
