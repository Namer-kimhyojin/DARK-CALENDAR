# 다이얼로그·날짜/시간 입력 UX 점검 및 개선 계획

## 점검 범위

- `calendar_app/presentation/dialogs/`의 QDialog 계열 25개 클래스(21개 파일)
- `QMessageBox`, `QInputDialog`, 파일·색상·글꼴 선택창 등 Qt 표준 팝업
- 일정/루틴/지시사항/일괄 복사/오버레이 설정의 날짜·시간 입력 경로
- 공통 테마 토큰, 밝은/어두운 패널, 강조색, 키보드 포커스, 다국어 길이

## 통합 입력 규칙

- 날짜: `YYYYMMDD` 8자리 연속 입력. 예: `20260804` → `2026-08-04`
- 시간: `HMM` 또는 `HHMM` 연속 입력. 예: `930`, `0930` → `09:30`
- 시간 위/아래 키와 스핀 버튼: 분 구간에서 5분 단위 이동
- 기존 기능 유지: 날짜 달력 팝업, 마우스 휠, 구간 선택, 빠른 오늘/내일/지금 버튼
- 도움말: 툴팁과 접근성 설명에 입력 예시를 제공하고 19개 로케일 구조를 동기화

## 적용 위치

- 일정 생성/수정: 시작·종료 날짜와 시간
- 루틴 생성/수정: 기준 날짜·시간 및 반복 종료일
- 지시사항: 마감 날짜·시간
- 루틴 일괄 작업: 복사 기준일
- 오버레이 위젯 설정: 날짜·시간 유형 필드

## 검증 기준

1. 밝은/어두운 테마와 밝은 강조색에서 본문 텍스트 4.5:1, UI 경계·포커스 3:1을 목표로 한다.
2. Tab/Shift+Tab으로 모든 필드와 버튼에 도달하고, 현재 포커스를 시각적으로 구분할 수 있어야 한다.
3. 숫자열 입력, 달력 선택, 스핀 버튼, 빠른 선택 버튼이 같은 저장값을 만들어야 한다.
4. 125%/150% DPI와 작은 화면에서 버튼·하단 영역이 잘리지 않아야 한다.
5. 스크린리더가 창 제목, 필드 이름, 입력 힌트, 버튼 이름을 읽을 수 있어야 한다.

## 후속 수동 점검

- 실제 Windows 125%/150% DPI에서 일정·루틴·지시사항·GCal 설정창 확인
- 한국어/영어 및 긴 문자열 언어에서 탭 제목·버튼 잘림 확인
- NVDA로 표준 메시지박스와 날짜/시간 필드의 이름·값·힌트 확인
- 네이티브 파일 선택창은 운영체제 테마가 우선될 수 있으므로 Windows 라이트/다크 각각 확인
