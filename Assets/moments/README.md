# Moment illustration packs

Bundled 4 x 4 transparent PNG sprite sheets used by the Date Card and D-Day widgets.

Cell order (left-to-right, top-to-bottom): spring, summer, autumn, winter,
birthday, anniversary, deadline, launch, travel, study, health, celebration,
calm, sparkle, empty, empty.

- `air-moments-sprites.png`: soft 3D clay style.
- `paper-seasons-sprites.png`: layered paper-cut style.

Generated with the built-in image generator as exact sprite sheets with no text,
numbers, logos, borders, or watermark. The final two cells are intentionally empty.
