# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Linear
- **Notes:** Dense desktop calendar on translucent panels. Monochrome surfaces with one accent (theme_color), crisp 1px borders, compact spacing, restrained motion. Colors come only from theme tokens (calendar_app/shared/ui_tokens.py, theme_snapshot); no hard-coded colors.

## Banned anti-aesthetics

- Translucency / glassmorphism without a text-contrast floor and a clear boundary (translucent panels are the product's identity: allowed only when text keeps 4.5:1 over the composited surface and the panel edge is visible)
- Floating pastel pill badges for ordinary metadata
- Arbitrary decorative gradients and neon glowing borders
- Multi-color rainbow gradients on standard actions
- Cartoon empty-state illustrations
- Nested scrollbars and icon bloat inside inputs
- Emoji in menu, button, or label text (use the icon library instead)
- Selector-less Qt stylesheets on container widgets (they cascade into tooltips and children); scope rules with objectName selectors

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** 4.5:1 for normal text, 3:1 for large text, borders, and focus indicators, measured on the composited surface (panel alpha over the reading surface)
- **Touch / focus:** 44×44px click targets where layout allows (top-bar icon buttons are 36px squares inside a 44px-tall bar); visible focus ring in the accent color; every mouse-only gesture (rollover, drag) has a keyboard or menu alternative

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Korean source copy, short and exact ("잠금 해제", "일정 3개 삭제됨"). One term per concept: use the glossary (scripts/i18n_glossary.json); lock-related wording is "바탕화면 고정" for the overlay lock and "자리비움 잠금" for the away lock. All text goes through t() with keys in locales/ko.json and locales/en.json.

## Icon library

- **Library:** Font Awesome 6 Solid via qtawesome
- **Package / path:** qtawesome (`fa6s.*`), mapped in calendar_app/shared/icon_map.py (ICON constants, icon() helper)
- **Notes:** Add icons only as ICON constants in icon_map.py; icon colors are #RRGGBB from theme tokens (rules/dialog_ui.md). No second icon set, no emoji as icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
